Our goal: understand how one row and one column produce one entry.

[2, −1, 3] · [4; 5; −2] = 8 − 5 − 6 = −3.

One entry / its inputs

Take a row and a column.

The row is [2, −1, 3]. The column is [4; 5; −2]. Each has three entries.

In matrix multiplication, this row and this column supply one entry of the answer.

One entry / corresponding positions

Match corresponding entries.

First with first, second with second, third with third: 2 with 4, −1 with 5, and 3 with −2.

The column turns into position. These are the same entries, arranged so we can read each contribution.

Why pair these entries?

A row covector assigns a weight to each coordinate. The column supplies a value for each coordinate in the matching basis. Corresponding positions refer to the same coordinate.

Here the rule is 2v₁ − v₂ + 3v₃. Applying it to v = [4; 5; −2] gives 2·4 + (−1)·5 + 3·(−2).

This is the row-by-column rule for a matrix-product entry. In standard real Euclidean coordinates, it is also the familiar dot product.

One entry / three contributions

Multiply within each pair.

2·4 = 8. (−1)·5 = −5. And 3·(−2) = −6.

Each pair produces a contribution. Keep the signs: the second and third contributions are negative.

Inspect the products

One entry / combine contributions

Now add the products.

The three contributions join into one expression: 8 + (−5) + (−6).

Multiplication happens within each pair; addition combines the contributions across all three positions.

Inspect the sum before evaluation

One entry / the result

Three contributions become −3.

8 − 5 − 6 = −3.

In a matrix product, −3 belongs at the intersection of the selected row and column. Other entries repeat the same rule with different rows or columns.
