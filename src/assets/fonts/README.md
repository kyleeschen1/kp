# Kinetic Press New Computer Modern Mono web subsets

These files are derived from New Computer Modern 8.1.1 by Antonis
Tsolomitis, downloaded from the official CTAN distribution:

https://ctan.org/pkg/newcomputermodern

The complete, unmodified upstream work can be obtained from that page or
from its canonical release directory:

https://download.gnu.org.ua/release/newcm/

The Mono faces are distributed under the GUST Font License. See
`GUST-FONT-LICENSE.txt` in this directory.

## KP modifications

On 2026-08-05, Kinetic Press:

- retained the Regular, Book, and Bold Mono 10 faces;
- subset them to Latin prose, combining marks, punctuation, currency,
  arrows, common mathematical operators, and geometric symbols;
- converted the selected glyphs from OTF to WOFF;
- renamed the files, family, full names, unique identifiers, and PostScript
  names so these derived webfonts cannot be mistaken for upstream files.

The CSS family is `Kinetic Press New Computer Modern Mono`. Regular is the
default reading face and serves 300 through 400, Book serves 500, and Bold
serves 600 through 900.
