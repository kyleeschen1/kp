# TypeScript Public Lesson

Status: approved on 2026-08-13; verification-cost repair approved during phase 4

## Outcome

Publish one static-first learner page for the approved TypeScript free-shipping
refactor at `/learn/code/free-shipping/`. The page proves a compact public
projection without changing the exemplar's semantics, score, trajectories,
renderer authority, or deterministic clock.

## Visual discovery contract

- **Canonical exemplar:** `animation.programming.typescript-free-shipping-refactor`.
- **Acceptance criteria:** searchable source and explanation before enhancement;
  stable stage geometry; a compact video-like scrubber; direct semantic seek;
  reduced-motion truth; readable desktop and phone compositions; numeric
  literals use the normal foreground rather than a green syntax accent.
- **Preservation boundary:** the TypeScript semantic artifact, source compiler,
  motion score, token trajectories, native endpoint ownership, Article v1,
  catalogue host, Python and Scheme language-specific choreography, and the
  user's modified economics files.
- **Rollback unit:** the public page projection and its build entry are one
  removable unit; numeric paint is an independent token-only commit.
- **Promotion criterion:** human approval of the public TypeScript page, then
  pressure the projection with one symbolic and one graph explanation before
  selecting it as Public Web v0.
