# Phase 2: Static Public Publication

## Goal

Create one framework-neutral lesson descriptor and server/build-time HTML
projection containing complete explanatory prose, complete source truth, a
settled initial stage, transcript/checkpoint navigation, and reserved player
geometry before JavaScript enhancement.

## Expected files

- a public lesson source/descriptor under `src/public-web/`
- a static HTML renderer under `src/public-web/`
- route-local public styles
- focused static-publication tests

## Verification

- meaningful lesson text and source exist in raw compiled HTML;
- all authored checkpoint and object references resolve;
- the public projection imports the versioned TypeScript vignette rather than
  recreating its semantic or animation model;
- no catalogue, editor, Python, or Scheme runtime is required by static output.
