# Matrix column animation exemplar

Authorized by the user's request to make the animation discussed in this thread.
One bounded implementation and review packet; not a restart of the paused
symbolic-inspection contract or adoption of the entire proposed math API.

Outcome: watch a column of B lift, pivot into a row, copy to meet both rows of A,
form two authored dot products, evaluate, and settle into a column of C. Repeat
for the second column. Original operands remain visible. Scrubbing/reverse must
sample the same scene, without replay-dependent mutation.

Semantic authority: the existing generated 2x2 matrix fixture and
`createKpMatrixMatrixCompositionChoreography`, which validates authored cell
intermediates and results. The legacy catalogue host remains its own reference.
New candidate host: `/experiments/matrix-column-product/`; candidate presentation
adapter for native KaTeX, using the existing KaTeX renderer, computed-style
material cloning and shared reader timeline clock. This is not certification of
the canonical native compositor or a replacement matrix renderer for the catalogue.

One local, typed chained transform score retains immutable env and scene
snapshots. It implements only this declared matrix presentation; arbitrary
parsing, generic layout inference, arbitrary morphs and a public DSL are excluded.
Unsupported dimensions or malformed cell evidence must fail closed.

Human checkpoint: judge lifting/pivoting/copying, clear row-column pairing,
evaluation and result placement, timing, layout and phone legibility. Preserve
mathematical identity, source/result values, existing renderer routes and the
symbolic inspector. Rollback unit: the candidate host, score and adapter files.
No promotion or second caller before acceptance.

Work package: implement and verify the candidate; focused semantic/negative and
deterministic sampling tests, existing matrix tests, full typecheck, architecture,
scoped production build and a stable Chromium visual packet. Budget repairs are
authorized by standing policy. Target a single working session; stop for review
when the exemplar is concrete, or for a demonstrated scope/authority blocker.
Commit implementation and Theseus evidence together. Existing uncommitted strategy
notes and the earlier matrix test-route fix remain separate from this work.
