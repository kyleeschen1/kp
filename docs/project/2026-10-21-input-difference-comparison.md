## Explanation and medium choice

Assumed reader: understands matrix–vector multiplication as a weighted sum of
columns and ordinary vector subtraction; has not connected dependence to lost
input distinctions. Question: how can two different inputs give the same output?

For the accepted A, u=(3,−1) and v=(5,−2) both map to (1,2). Their difference
v−u=(2,−1) changes the contributions by 2(1,2) and −(2,4). Those vectors cancel.
Linearity connects that cancellation to the comparison: A(v−u)=Av−Au=0. Thus the
output cannot distinguish u from v. A zero output difference does not mean a
zero input difference, and reverse playback is not an inverse transformation.

Static baseline: the two mappings alongside this short subtraction/cancellation
calculation. Keep that complete baseline accessible. The proposed gain from motion
is following the same input entries into the difference and the same matrix
columns into its opposing contributions, without remembering a disappeared result.
Scrubbing should let the reader inspect provenance and undo the display; it is not
itself a learning outcome. Transfer question: predict the output for (7,−3) and
explain why the change (2,−1) can repeat. The reasoning must be on the main path;
the name “kernel” is optional vocabulary, not the explanation.

Cost/limits: familiar numeric 2×2 example, exact safe-integer checks rather than
symbolic theorem certification. More simultaneous context can become busy.
Prefer natural native notation and one changing work area; do not compensate by
shrinking text. Human review must decide whether motion earns its cost over the
static baseline. No learner study is claimed.
