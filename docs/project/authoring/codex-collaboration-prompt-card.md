# Codex Collaboration Prompt Card

The repository protocol should carry most of this burden. These short prompts
remain useful when you want to make the working mode especially explicit.

## Diagnose only

> Compare this with the canonical example phase by phase. Identify the likely
> regression boundary and smallest rollback unit. Preserve the semantic model.
> Do not execute.

## Exemplar first

> State the acceptance and preservation boundaries, then perfect one canonical
> example. Stop for visual review before generalizing.

## Efficient grill-me session

> Use your recommendation for low-impact choices. Batch those decisions and
> stop only for forks that materially affect architecture, behavior, or
> aesthetics.

## Visual long loop

> Put an exemplar checkpoint before broad rollout. Name the rollback unit and
> promotion criteria in the run contract. Generalize only after the exemplar is
> accepted.

## Formalize without universalizing

> Record this as an extensible principle. Do not enforce it globally until a
> canonical exemplar and representative family cohort demonstrate that it
> improves quality.
