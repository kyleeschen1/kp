# Economics

## International, intertemporal and empirical reasoning

### Semantic moves

- [ ] `econ.trade` Compare gains from specialization under stated trade assumptions.
  Example: Production possibilities and consumption possibilities can differ
  Audit: unaudited
- [ ] `econ.tariff` Separate domestic transfers, fiscal revenue and efficiency loss from a tariff.
  Example: World price plus tariff changes domestic incentives in a small-country model
  Audit: unaudited
- [ ] `econ.exchange` Distinguish nominal and real exchange-rate conventions.
  Example: A formula must state which currency is in the numerator
  Audit: unaudited
- [ ] `econ.capital-flows` Relate external balances to financial flows with consistent signs.
  Example: A current-account deficit has a corresponding financing counterpart
  Audit: unaudited
- [ ] `econ.discount` Translate future quantities to a common date.
  Example: Present value = future value/(1+r)^t, r>-1
  Audit: unaudited
- [ ] `econ.intertemporal` Compare consumption today and tomorrow under a budget constraint.
  Example: Saving shifts resources across periods subject to an interest rate
  Audit: unaudited
- [ ] `econ.empirical.coefficient` Interpret a regression coefficient conditional on the model and units.
  Example: A slope describes an association after the included controls
  Audit: unaudited
- [ ] `econ.empirical.logs` Interpret log-level and log-log coefficients differently.
  Example: In log y=α+β log x, β is a local elasticity
  Audit: unaudited
  Uses: alg.log.scale
- [ ] `econ.empirical.counterfactual` Name the missing counterfactual in a causal question.
  Example: A treated person's untreated outcome is not simultaneously observed
  Audit: unaudited
- [ ] `econ.empirical.randomization` Explain what random assignment identifies and what it does not.
  Example: Assignment can identify an average treatment effect under compliance/design conditions
  Audit: unaudited
- [ ] `econ.empirical.confounding` Explain why adding controls does not automatically identify causality.
  Example: Unmeasured common causes can remain
  Audit: unaudited
- [ ] `econ.empirical.difference` Use differences-in-differences with a parallel-trends assumption.
  Example: Compare treated and comparison changes, not only post-treatment levels
  Audit: unaudited
- [ ] `econ.empirical.uncertainty` Separate statistical precision from causal credibility.
  Example: A narrow interval does not repair a biased identification strategy
  Audit: unaudited

### Visual motifs

- [ ] `motif.econ.counterfactual` Keep observed and assumed counterfactual outcomes distinguishable.
  Example: A comparison trajectory is a model claim, not observed history
  Audit: unaudited
- [ ] `motif.econ.time-value` Coordinate dated quantities with their discount factors.
  Example: Amounts are compared only after moving to a common date
  Audit: unaudited
