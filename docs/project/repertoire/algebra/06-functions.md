# Algebra

## Functions, formulas and applied quantities

### Semantic moves

- [ ] `alg.function.evaluate` Evaluate a function at a structured argument.
  Example: f(x)=x²+1 → f(a+1)=(a+1)²+1
  Audit: unaudited
- [ ] `alg.function.domain` Find the real domain of a combined expression.
  Example: √(x-1)/(x-2): x≥1 and x≠2
  Audit: unaudited
- [ ] `alg.function.compose` Compose functions in the correct order.
  Example: f(x)=x², g(x)=x+1: f(g(x))=(x+1)²
  Audit: unaudited
- [ ] `alg.function.inverse` Invert a one-to-one restriction and swap domain/range.
  Example: f(x)=x² on x≥0 → f⁻¹(y)=√y
  Audit: unaudited
- [ ] `alg.function.piecewise` Evaluate and compare piecewise branches at a boundary.
  Example: f(x)=x for x≥0, -x otherwise; both meet at 0
  Audit: unaudited
- [ ] `alg.function.transform` Relate formula changes to graph transformations.
  Example: f(x-2)+3 shifts the graph right 2 and up 3
  Audit: unaudited
- [ ] `alg.function.rate` Interpret a slope as an output change per input change.
  Example: Δy/Δx=3 units of y per unit of x
  Audit: unaudited
- [ ] `alg.formula.rearrange` Rearrange an applied formula for a different variable.
  Example: v=d/t → t=d/v; v≠0
  Audit: unaudited
- [ ] `alg.ratio.proportion` Solve a proportion with nonzero denominators.
  Example: a/b=c/d → ad=bc; b,d≠0
  Audit: unaudited
- [ ] `alg.ratio.variation` Distinguish direct and inverse variation.
  Example: y=kx versus y=k/x
  Audit: unaudited
- [ ] `alg.percent.change` Use the original base for percentage change.
  Example: 80→100 is a 25% increase
  Audit: unaudited
- [ ] `alg.percent.compose` Compose percentage changes multiplicatively.
  Example: +10% then -10% gives 1.1·0.9=0.99 of the original
  Audit: unaudited
- [ ] `alg.units.convert` Convert units by multiplying by a unit ratio.
  Example: 72 km/h → 20 m/s
  Audit: unaudited
- [ ] `alg.units.dimension` Reject addition of incompatible dimensions.
  Example: distance + time is not a physical distance
  Audit: unaudited
- [ ] `alg.scientific` Normalize scientific notation after arithmetic.
  Example: (3·10⁴)(2·10⁻²) → 6·10²
  Audit: unaudited
- [ ] `alg.model.translate` Translate a verbal constraint into a formula with meanings.
  Example: Total cost = fixed charge + rate·quantity
  Audit: unaudited

### Visual motifs

- [ ] `motif.alg.function-map` Coordinate input, rule and output without losing the chosen argument.
  Example: Follow a+1 through f(a+1)
  Audit: unaudited
- [ ] `motif.alg.units` Keep units attached to quantities during conversion.
  Example: Cancel hours and kilometers only through valid unit ratios
  Audit: unaudited
- [ ] `motif.alg.formula-roles` Retain symbol meanings while changing which variable is isolated.
  Example: Distance, speed and time keep their roles through rearrangement
  Audit: unaudited
