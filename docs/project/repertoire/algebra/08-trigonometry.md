# Algebra

## Trigonometry and periodic reasoning

### Semantic moves

- [ ] `alg.trig.radian` Convert angle units and connect radians to arc length.
  Example: s=rθ; 180 degrees = π radians
  Audit: unaudited
- [ ] `alg.trig.unit-circle` Interpret sine and cosine as coordinates.
  Example: θ=π/2 → (cos θ,sin θ)=(0,1)
  Audit: unaudited
- [ ] `alg.trig.reference` Use quadrant signs and a reference angle.
  Example: sin(5π/6)=1/2; cos(5π/6)=-√3/2
  Audit: unaudited
- [ ] `alg.trig.right-triangle` Choose a trigonometric ratio from known sides.
  Example: tan θ=opposite/adjacent; adjacent≠0
  Audit: unaudited
- [ ] `alg.trig.reciprocal` Relate reciprocal and quotient trigonometric functions.
  Example: tan θ=sin θ/cos θ where cos θ≠0
  Audit: unaudited
- [ ] `alg.trig.pythagorean` Rewrite using a Pythagorean identity.
  Example: sin²θ+cos²θ=1
  Audit: unaudited
- [ ] `alg.trig.sum` Expand a sine or cosine of an angle sum.
  Example: sin(a+b)=sin a cos b+cos a sin b
  Audit: unaudited
- [ ] `alg.trig.double` Use a double-angle identity in either useful form.
  Example: cos(2θ)=1-2sin²θ=2cos²θ-1
  Audit: unaudited
- [ ] `alg.trig.half` Choose the sign in a half-angle formula.
  Example: sin(θ/2)=±√((1-cos θ)/2); sign depends on θ/2
  Audit: unaudited
- [ ] `alg.trig.product-sum` Convert products into sums for integration or oscillation analysis.
  Example: sin a cos b=[sin(a+b)+sin(a-b)]/2
  Audit: unaudited
- [ ] `alg.trig.inverse` Respect principal values when using inverse trigonometric functions.
  Example: arcsin(sin(3π/4))=π/4
  Audit: unaudited
- [ ] `alg.trig.solve` Include all periodic solutions to a trig equation.
  Example: sin x=1/2 → x=π/6+2kπ or 5π/6+2kπ; k integer
  Audit: unaudited
- [ ] `alg.trig.wave` Interpret amplitude, period and phase in a sinusoid.
  Example: 2sin(3(t-1)) has amplitude 2, period 2π/3, shift 1
  Audit: unaudited
- [ ] `alg.trig.cosine-law` Relate sides and included angle in a non-right triangle.
  Example: c²=a²+b²-2ab cos C
  Audit: unaudited
- [ ] `alg.trig.sine-law` Handle the ambiguous case in sine-law triangle solving.
  Example: sin B=b sin A/a can yield two feasible angles
  Audit: unaudited
- [ ] `alg.trig.polar` Convert Cartesian and polar coordinates with quadrant information.
  Example: x=r cos θ, y=r sin θ; atan2 distinguishes quadrants
  Audit: unaudited
