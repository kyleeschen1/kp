## Where we are going

**Help authors create extraordinary explanations that teach people what to
notice, then let learners adapt, practice and revisit them.**
The [product charter](strategy.md) owns the durable thesis, quality commitments
and progression: authoring → learner adaptation → practice/retrieval → library.
[The accepted decision](decisions/2026-11-08-authoring-expert-attention.md) records
why this becomes the organizing direction and what it supersedes.

## Current approved commitment

the [twelve-loop progression](2026-11-08-authoring-to-practice-loops.md), starting
with faithful restoration of a saved What counts link. The programme preserves
dependencies and human checkpoints; later scopes sharpen from earlier evidence.
The prior [orientation delivery](2026-11-08-project-orientation-delivery.md) is
accepted and complete, with its history and evidence retained.

What counts now serves as a technical authoring/runtime reference; the user
judges its reasoning clear but its topic unsuitable as the main teaching exemplar.

source now has a separate reasoning reading about choosing moves that preserve
solutions. Review its argument, alternative route and changed-case question next.
The [reading defaults](principles/document-theater-reading.md) preserve rich prose,
give guided theaters an immediate orientation, and keep individual beats concise.
This refines the programme's featured-quality outcome rather than replacing it.

Use the existing authoring path. The parallel agent retains task/editor ownership;
strategic records have one editor at a time.

## First product proof — approved

**One excellent explanation can be substantively revised through the product.**
An author changes reasoning and attention choreography, gets useful feedback
promptly, and preserves a reusable result without custom repository engineering
for each revision. Then pressure one learner-requested adaptation that retains
the important reasoning and exact context.

The editor lane has a native-conversation/website-preview candidate. Reuse it
and KP's registered-manuscript preview; inspect their missing connection first.
See [inspection and handoff](reviews/2026-11-08-project-orientation.md).
A bounded source-only note-and-target revision took about 21 seconds including
editing, checking and saving after the second reader's support was implemented.
The [trial](reviews/2026-11-09-fractional-reading.md) separates that result from
the initial engineering. Fresh explanation generation and integrated workbench
latency remain unproved. Several domains and a large library are not the first finish line.

## What already exists

Accepted reader typography, annotation moments, fades and focus release are
preserved. Two independent algebra readings and a scripted exact-context return
work in that reader. The physics case reused its existing compiler/rail; it did
not establish a new generation capability. See [bounded evidence](reviews/2026-11-08-explanation-first.md).

The proposal to move physics into this reader is **deferred as an automatic next
step**. It earns priority only if it removes a demonstrated authoring/adaptation
blocker. Prior completed architecture and maintenance work stays complete.

## How to stay oriented

- Open `/?view=dashboard#project-vision` for direction, approval boundaries,
  recent evidence, proposed successor and the next human judgment.
- Run `npm run project:orientation` for the same briefing plus a fresh read of
  the explicitly named Theseus contract. A source snapshot is not a live monitor.
- These sources are current in `.worktrees/kp-product`. The parallel checkout
  still has older direction; integration belongs to its owner, not an implicit merge.
- Read this page, [the active thread](threads/co-creative-practice.md), and the
  charter for rationale. Retrieve only the selected task's sources afterward.
- At handoff, state the capability gained, remaining uncertainty and any direction
  change. Reconcile strategic records at milestones/pivots; update tasks through
  Theseus. Do not append slice logs here.
