# Opening motion unit: exact authority binding

P1 result. The new bounded source is not an arbitrary mechanics generator.

- `src/semantic/motion-observation.ts` checks plain observation data, explicit
  interpolation, stable IDs, increasing times, metre/second units and fixed axis.
  It uses shared immutable issuance and a private domain-check receipt. Forged
  or copied records cannot supply mathematical authority. Integer endpoint bounds
  make the recorded difference/sum arithmetic exact; intermediate interpolation
  is ordinary numerical evaluation of the explicitly chosen model.
- `src/authoring/motion-observation-authoring.ts` builds semantic snapshots and
  transformations, declares the bounded project operation pack, and executes
  `compileKpGovernedCanonicalConstruction`. It is deliberately in authoring,
  not an upward dependency from animation runtime into authoring.
- `motion.observe-linear-trip` owns the declared model; it makes no empirical
  force claim. `motion.change-fixed-origin` preserves observation/point identity
  and fixed-unit displacement, not coordinate value. Strict law references are
  backed by the domain checker and executable tests, not supplied by learner prose.
- P2's native 2D owner will consume this checked result and use the existing
  Graph2D lifecycle, focus-card scaffold/control owners and attention projector.
  No equation rewrite animation is necessary; any notation stays static KaTeX.
  No global renderer/motif catalogue promotion is implied before human review.

The P1 capability investigation found no need for a universal compiler or new
clock. The new domain adapter is explicit engineering work, not source-only
reuse. Its visual quality remains unreviewed. The canonical new route is
`/experiments/mechanics-motion/`; it is not yet a working review URL at P1.

Explanation and first-confusion hypotheses are in
`2026-09-12-motion-explanation-draft.md`. Motion between observations and the
apparent pause are labelled as model assumptions. Changing zero is a supporting
comparison, not physical translation symmetry or the whole lesson's purpose.
