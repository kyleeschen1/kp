## Outcome and teaching job

Question: how can two callers share one business rule without changing their
answers? Readers know functions, comparisons and conditional expressions;
brief syntax help remains available. Motivation: independently maintained
thresholds can make the checkout price disagree with its message. The static
baseline contains complete before/after code, the connecting explanation and
bounded evidence. Inspection helps track the condition into its helper and the
helper calls back into their original contexts. It does not prove equivalence.
Transfer check: if the threshold changes, which definition should change?

Canonical source is `examples/programming/shared-rule.article.md`, hosted at
`http://localhost:8000/experiments/code-reasoning/`. Semantic authority remains
the existing TypeScript free-shipping contract, generated compiler evidence,
operation set and declared-case behavior certificate. Native source HTML,
token theater and DOM frame renderer remain canonical. One existing reader
timeline clock owns progress; no code execution/compiler in the browser.
