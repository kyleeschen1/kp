# Code input convergence and cross-browser acceptance

Canonical artifact: the TypeScript refactoring Focus Card on
/experiments/kinetic-figure/supply-tax/, using its existing Article-derived
seven-beat score, verified code runtime, token theater and DOM renderer.

The card now uses the same native transport and revocable travel authority as
tax and gradient. Its old passage pointer flags, RAF sampler, wheel listener,
scrollend listener and 180 ms quiet timer are removed. The shared owner handles
release, interruption and disposal. Code still selects its existing nearest
beat on release, and retains its existing motion-owning adjacent buttons,
keyboard navigation, direct hash semantics and fractional timeline mapping.

Whole-prose projection during control-driven code motion remains intentional.
The shared input owner can reconcile late unowned scroll offsets to a caller's
declared resting projection, without reopening or seeking the semantic clock.
Native owned input still has continuous control and can reverse while held.

Pressure testing exposed an earlier deferred-activation defect: SVG descendants
of icon buttons were not HTMLElements, so their first click could miss the
pending-command queue. The host now queues the nearest actual control. An
explicit delayed-module first-icon-click test protects this failure class.

Evidence:

- 11 focused code, travel capability and deferred lifecycle unit checks pass.
- Full app/node/test/Svelte/domain typecheck passes.
- 13 Chromium code/deferred/four-card keyboard browser cases pass, including
  active edit interruption, native wheel intermediate frames and gradual reverse.
- A five-case representative tax/code cohort passes in Chromium, Firefox and
  WebKit (15 cases): native tax sampling/resize, mouse reversal, wheel release,
  delayed icon-button input and held code travel/reversal/late-scroll rejection.
- Stable command: npm run visual:focus-deck-input; the review config uses the
  existing server 8000. This is browser-engine evidence, not a physical-phone
  or OS history-gesture certification.

No universal renderer, new clock, altered token choreography, or adoption by
unrelated cards was introduced. The two migrated callers retain explicit,
different accepted settlement profiles; shared transport does not imply all
legacy perceptual policy has already been standardized.
