# Tax input ownership convergence

The canonical host remains /experiments/kinetic-figure/supply-tax/, backed by
the generated checked market source, its existing edge-local reader clock,
instruction score, and native tax SVG projector. Neither the clock nor the
960 ms domain edge / 480 ms attention edge was replaced.

The tax entry no longer owns parallel pointer, wheel, scroll, scrollend, quiet
timer, mouse capture, or deferred native-snap restoration machinery. It mounts
the existing shared native input adapter. Revocable travel sessions now support
edge-local clocks through callbacks as well as the existing checkpoint clock.
Unowned derived scroll events cannot acquire navigation authority.

Convergence is not an unapproved interaction redesign: tax retains its .08
displacement and .025 wheel commitment profile, native velocity evidence, and
native-versus-mouse settlement policy. The shared default quarter-page profile
continues to govern its existing caller. The adapter identifies transport kind;
it does not select the tax domain's clock, scene, history, or rendering.

CSS snap stays disabled while this shared semantic input owner is mounted,
removing a competing endpoint authority. Prose remains selectable; blank-space
mouse drag and stage proxy belong to the card. Native touch and vertical
scrolling retain their browser path. Browser history containment is an
implementation boundary, not a claim to physical Safari device certification.

## Verification and discovered regressions

- Three executable travel tests cover revocation, stale sessions, disposal,
  temporal validation, fresh/stale velocity and a caller's declared profile.
- Tax source-ownership tests now require the shared owner rather than the
  deleted listener spellings; static/route/clock assertions remain.
- The existing 13-case tax browser suite exercises eight stops, the real
  domain edge, fractional reversal, held native input, mouse/wheel release,
  resized geometry, reduced motion, URL restoration, lifecycle and phone layout.
- A small-touch regression in the first migration attempt was repaired:
  peak velocity needs two observed offsets, not an assumed interval before the
  first sample. Existing .04-page noncommit evidence caught it.
- A wall-clock midpoint assertion failed under load despite unchanged timing.
  The test now drives the real reader clock through Playwright's controlled
  browser time, retaining its midpoint and minimum-duration assertions.
- Three existing gradient browser cases pressure the shared caller: controls,
  phone/reduced motion, and endpoint wheel reversal.
- Full TypeScript checks pass; the complete release suite remains a later gate.

Stable execution uses npm run visual:focus-deck-input with the existing
focus-deck review config and server 8000. No extra development server is started.
The independently reversible unit is this slice commit; it does not roll back
the earlier lazy activation, semantic issuance, or native renderers.
