# Authoring an explanation through existing matrix motion

Authority: the user approved the next authoring step and asked for concrete
inspection instructions at each finish. The next obstacle is structural:
authors can change numbers and prose, but the player still dictates one forward
calculation. This bounded exemplar lets an author choose named stops and returns.

The canonical source is `content/authoring/linear-algebra/dependent-columns.ts`.
The optional host is `/experiments/matrix-column-combinations/?walk=1`.
`M.product` and its column combinations own mathematical identity; the existing
column presentation and continuity compositor own every glyph and transition.
One shared timeline clock projects a source-authored walk onto those native paths.
No new motion, focus treatment, coordinates or arbitrary timing is authored.

Observable outcome: a reader can inspect weights, pause at contributions, see a
result, rewind to the original equation and inspect the other input. Next stops
at authored checkpoints; direct seeking and reversal produce the same paint.
Changing the stop order requires source changes only, within the demonstrated
native paths. Unsupported cross-column jumps return a typed repair gap, never a
fade or invented bridge. Reverse playback is explicitly not an inverse map.

## Packages and gates

1. `walk`: bounded local source and deterministic checkpoint projection, typed
   repair errors, semantic/reversal/unsupported-transition tests. An initial
   native pose is the only demonstrated handoff between column presentations.
2. `exemplar`: optional lazy host, existing presentation and shared playback
   helpers, top-of-stage prose and checkpoint controls. One Chromium smoke checks
   continuity at the shared initial pose, seek/reversal, resize and cleanup.
   Preserve existing reader and editor paths. Commit checked candidate and evidence.
3. `transfer`: **after canonical human review**, pressure the boundary with one
   different authored order/source. Then decide whether it warrants promotion,
   measure complete reader/runtime/type costs and run affected release checks.

The human gate asks whether the pauses and returns make the argument legible,
whether rewinding feels coherent, and whether separate column results are enough
for comparison. Automated correctness cannot answer those questions. Do not
promote a shared renderer interface, migrate the source-file schema or certify a
new aesthetic before this gate. Initial duplication is bounded to two prepared
native views with one clock; hidden views must not paint or receive accessibility
focus. Runtime cost and maintenance tradeoffs must be reported honestly.

The rollback unit is the optional walk source/host and lazy entry branch. Preserve
accepted typography, geometry, native ownership, semantic references, ordinary
reader behavior and edition/editor boundaries. No calculus polish, broader lesson
catalogue, universal score framework, network service, paid calls or deployment.

Focused verification and affected types before review; production budgets and
supported-browser integration at post-approval transfer. Use the impact planner.
