# Capability-pressure sequencing and arithmetic expansion

Date: 2026-07-23
Status: accepted direction; broader tranche order remains review-gated

## Decision

KP will continue to prioritize architectural pressure over textbook chapter
order while keeping important arithmetic, algebra, pre-calculus, geometry, and
data-explanation gaps as a durable product backlog.

The derivative checkpoint remains current, but its canonical exemplar is now a
pre-calculus-to-calculus bridge: a fully KaTeX-rendered finite difference
quotient synchronized with secant geometry, followed by continuous
secant-to-tangent convergence and exact rewind. The existing moving-tangent
editor sample is reference evidence, not the promotion target.

After that checkpoint, a quadratic equation/graph exemplar is the accepted
first insertion candidate because it pressures solution-set branching,
completing-square regrouping, the `±` split, and equation-to-root
correspondence. Its insertion into executable work must be made through the
Theseus contract rather than by silently renumbering the current run.

Arithmetic becomes a first-class capability-opening lane. It must include:

- exact fractions synchronized with KaTeX and partitioned-circle, bar/area,
  and number-line views;
- multi-digit addition and subtraction synchronized with place-value exchange;
- multi-digit multiplication synchronized with partial products and an area
  model;
- multi-digit division synchronized with grouping, partial quotients, quotient
  digits, and remainder;
- ratios, rates, percentages, units, and scaling after the core exact-quantity
  operations are proven.

The broader recommended order and the complete retained coverage ledger live in
`../reviews/2026-07-23-kp-capability-pressure-domain-order-next-step-review.md`.
That review is durable planning evidence, not advance authorization to
generalize every listed family.

## Reason

KP's durable product is a semantic animation system rather than a sequential
course. Capability-opening exemplars should therefore come before broad
curriculum completion. At the same time, leaving foundational arithmetic and
pre-calculus gaps only in conversation history would make later planning
fragile and would hide important missing motifs.

Arithmetic is especially valuable architectural pressure:

- place-value exchange introduces conserved regrouping across representations;
- exact fraction models introduce partition refinement and coarsening;
- multiplication composes distribution, traversal, and regrouping;
- division introduces iterative consumption, estimation, quotient settlement,
  and remainder;
- ratios and units add typed quantity and scale provenance.

## Consequences

- s27 cannot be promoted by a static derivative label and a moving tangent
  alone.
- All learner-facing mathematical notation must use the shared LaTeX/KaTeX
  rendering path, including dynamic values and graph annotations.
- Partitioned circles are an approved fraction projection, but not the sole
  model; bars and number lines remain necessary where circles obscure ordering,
  improper fractions, or denominator alignment.
- Arithmetic algorithms must explain semantic exchanges and partial results,
  not animate digits as unexplained glyph motion.
- Missing curriculum domains remain visible even when they are not selected
  for the active run.
- Each subjective family still requires one canonical exemplar and human
  checkpoint before generalization.

## Alternatives considered

### Complete pre-calculus before calculus

Rejected as the governing sequence. It would improve curricular completeness
but delay continuous cross-renderer, convergence, and higher-order composition
pressure.

### Finish the current calculus and linear-algebra run before recording arithmetic

Rejected. It would preserve execution simplicity but leave explicitly requested
foundational product work vulnerable to being lost.

### Add every retained domain to the active run immediately

Rejected. It would exceed the reviewed run envelope, conflate backlog with
authorization, and violate exemplar-first promotion.

4. Materialize the arithmetic lane one exemplar at a time after the current
