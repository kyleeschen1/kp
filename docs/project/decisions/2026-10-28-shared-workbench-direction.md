# A shared workbench for experimentation and personal practice

Date: 2026-10-28
Status: accepted user direction; bounded delivery proposal remains under review

The user requests rich experimental evidence, deliberate exposition practice,
GTD, capability discovery, exact conversational references, joint attention to
code and rendered objects, personal spaced practice, and evidence-informed LLM
stewardship. The [intake](../capture.md#2026-10-28-shared-workbench-experimental-judgment-and-personal-practice)
preserves the full request without turning every idea into active work.

This extends the [co-creative practice priority](2026-10-28-co-creative-practice-priority.md).
The workbench should make one complete personal experiment easier to conduct,
discuss, retain and revisit. Personal practice must be included in the first
useful delivery, not postponed until an observability platform is complete.

The existing [proposal](../reviews/2026-10-28-next-step-review.md) owns sequencing;
the [evidence review](../reviews/2026-10-28-workbench-evidence.md) records existing
owners, historical feedback and a first exposition-study seed. No second phase
plan or execution queue is introduced. Existing mathematical, rendering,
review-log, GTD and Theseus authorities remain responsible for their records.

Capture, consideration, selected work and an approved run are different states.
This direction does not launch a background agent, scheduled review, paid model
call or autonomous implementation. Exact references inside a KP-owned workbench
do not imply access to modify an external chat application's interface. A common
reference envelope is proposed; a universal object ontology is not adopted.

Best practices should retain their context, evidence, exceptions and uncertainty.
Mathematical validity, visual acceptance, authoring speed, subjective usefulness
and delayed learning are separate claims. Preserve raw observations when an LLM
proposes a new interpretation or a cleaner organization.
