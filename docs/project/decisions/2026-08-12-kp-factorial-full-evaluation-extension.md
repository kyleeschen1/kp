# Factorial full-evaluation extension

Date: 2026-08-12
Status: accepted for one bounded visual-discovery exemplar

## Decision

The semantically corrected first expansion is approved as the canonical
reference for extending the Scheme factorial vignette through its complete
evaluation. The default route may now project one persistent code expression
from `(factorial 3)` to `6` using the frozen interpreter trace as causal
authority and a compact pedagogical material score as presentation authority.

The interpreter is not replayed event by event. Four trace-certified call
activations compile into repeated procedure expansion, argument binding,
binding projection, branch choice, and either suspension/decrement or base
resolution. Earlier activations compact into waiting multiplication shells so
only the active call opens fully. The return phase resolves deepest-first from
the base value through the three waiting multiplications.

## Acceptance

- one stage and one scrubber carry the complete evaluation;
- source occurrence, activation, binding projection, primitive result, and
  returned-value identities remain distinct;
- descent settles at exact native expressions for arguments `3`, `2`, `1`,
  and `0` without duplicating an earlier glyph as a later activation;
- the base branch resolves to the interpreter's exact `1` value;
- each return replaces only its certified recursive call site and each
  multiplication result uses the trace's exact value ID;
- direct seek, reverse, reduced motion, and exact endpoints remain
  deterministic;
- only the active activation expands; waiting work remains compact and
  readable.

## Preservation and rollback

Preserve the parser, evaluator, generated trace, pedagogical score, legacy
full-story query projection, shared playback clock, route, accessibility, and
framework-neutral publication boundary. The rollback unit is the
factorial-local full-evaluation material compiler, sampler, and default focus
projection. Do not connect CodeMirror, generalize the material grammar beyond
factorial, or promote a shared code renderer before human review.

Automated verification protects trace correspondence, identity, direct seek,
and lifecycle truth. Motion, pacing, readability, and attention remain a human
checkpoint.
