# Canonical Host, Not Asset Id, For Algebra

Date: 2026-08-10
Status: accepted

The first algebra motion-passage checkpoint is rejected. Loading the canonical
fraction-composition asset into a generic editor player does not constitute
reuse of the canonical animation. The canonical representation is the reader
host registered for `/reader/fraction-composition/`, including its descriptor,
structural bindings, certified layout, salience projection, native compositor,
protected transit, and lifecycle.

The recovery run must expose that implementation as a chrome-free embeddable
session consumed by both the reader route and algebra article. Article v1 may
name ranges and instructional focus; it may not select or construct the
renderer. Tests must prove representation and sampled-frame parity rather than
accepting animation-id and endpoint equality as sufficient evidence.

The approved execution plan is
`../reviews/2026-08-10-canonical-algebra-article-recovery-long-loop-proposal.md`.
Its first mandatory terminal is the slice-20 human checkpoint.
