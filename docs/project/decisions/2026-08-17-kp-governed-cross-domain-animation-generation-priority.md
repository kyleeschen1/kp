# Governed Cross-Domain Animation Generation Priority

Date: 2026-08-17
Status: accepted direction; implementation requires an approved Theseus run

## Decision

Make robust animation generation the active repository priority.

The desired authoring experience is:

```text
natural-language explanation or ordered source states
-> proposed semantic operations, roles, identity, and lineage
-> deterministic verification and typed repair gaps
-> registered canonical motifs and domain-local presentation policy
-> one seekable, reversible animation sequence
-> exact URL, catalogue access, review capture, and later reuse
```

For equations, ordered native-LaTeX states are the first reference input.
Natural language may propose the operations and correspondences between those
states, but an LLM does not own mathematical truth, identity, geometry,
timing, renderer selection, or fallback behavior. KP selects executable motifs
from verified semantic intent. Unsupported syntax, operations, roles, or
renderers remain explicit typed gaps rather than silently becoming fades.

The long-term generation envelope also includes matrix notation and spatial
linear algebra, code transformations, Graph2D, and Graph3D. Those domains share
the request envelope, capability discovery, deterministic clock, review, URL,
and host boundaries only where proved. They retain domain-owned parsers,
semantic operations, motif vocabularies, geometry, and renderer packs. This is
not approval for one universal renderer or a comprehensive generator in the
first loop.

## Capability Visibility

Add a separate, deliberately simple **Transformation Coverage** view. It
answers which transformation families are directly generatable, registered
but not directly exposed, available only as specific exemplars, or missing.
It does not replace the asset-first Animation Catalogue and does not become a
second roadmap.

The view is derived from one typed capability plan joined with existing asset,
operation, motif, authoring, promotion, and review evidence. Its primary rows
are mathematical or computational capabilities, not implementation adapters.
Canonical, adapter-backed, static-only, and retirement dispositions remain
available as expanded evidence.

## Immediate Order

1. Establish the capability plan, evidence gates, generated coverage
   projection, and minimal internal Coverage view.
2. Promote the already approved log-product/log-quotient homomorphic crossover
   at its narrowest causal boundary without changing either choreography.
3. Add one governed equation-transform-series request and compiler over the
   existing deterministic runtime.
4. Generalize balanced equation operations, fraction equivalence and
   arithmetic, exponent/root transformations, substitution/collection,
   inequalities/branches, binders, and multi-line derivations in recorded
   order.
5. Add matrix, code, Graph2D, and Graph3D capability declarations and future
   frontend seams without forcing their semantics through the equation
   compiler.

The previously selected function-coordinate graph exemplar is deferred, not
cancelled. It should return as a Graph2D pressure case after the generation and
coverage foundation is honest.

## Internal Studio Requirements

- Keep the Catalogue asset-first and the Coverage view capability-first.
- Put Catalogue/Coverage navigation, a direct theme toggle, and Review access
  in the global development dock.
- Encode view, selected artifact, semantic checkpoint/playhead, theme, and
  applicable presentation settings in URLs without full-page reloads.
- Ensure Review cannot cover the player or scrubber and captures the exact
  URL-backed state and selected view.
- Give every new animation a stable ID, title, catalogue entry, and directly
  copyable link.

## Guardrails

- Do not build a full CAS, theorem prover, arbitrary-code executor, or
  universal graph/scene inference engine.
- Do not let the LLM author DOM, SVG, WebGL, coordinates, paths, timing tables,
  typography, or opacity.
- Do not infer semantic identity from matching glyphs or source text.
- Do not claim natural-language reliability from deterministic fixtures; live
  model evaluation is a separate measured promotion gate.
- Do not add planned-only rows to the concrete Animation Catalogue.
- Do not broaden subjective motion treatments without an exemplar checkpoint.

## Superseded Ordering

The prior post-crossover instruction to implement a function-coordinate
transformation immediately is superseded. Public layout, curriculum, SRS, and
broad tutoring work remain paused. Educator discovery remains an external
product-validation track.
