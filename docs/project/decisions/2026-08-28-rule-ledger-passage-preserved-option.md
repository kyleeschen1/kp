# Rule Ledger Passage Preserved as a Named Option

Date: 2026-08-28
Status: accepted

## Decision

Name and preserve the integration presentation represented by presentation
profile `v12` at commit `6b103580c` as the **Rule Ledger Passage**.

A Rule Ledger Passage combines:

- one concrete mathematical subject in the primary stage;
- one quiet, continuously available rule reference;
- bindings that accumulate as the concrete instance is matched to the rule;
- beat-level prose that explains why each correspondence or rewrite is valid.

This is a named design option, not a newly promoted universal motif. It remains
available for lessons where persistent rule visibility and explicit bindings
are worth the additional visual structure.

The paragraph-level **Kinetic Figure** experiment is a separate projection
option. It does not supersede the Rule Ledger Passage, alter its semantic
authority, or imply that either treatment should be generalized before a
canonical exemplar and a structurally different caller pass review.

## Reason

The current integration candidate is materially clearer than the preceding
correspondence-diagram and layered-template experiments. Giving it a stable
name makes it easy to recover and compare without freezing its provisional
timing, color, spacing, or exact layout as infrastructure.

## Consequences

- “Rule Ledger Passage” is sufficient shorthand for returning to this design.
- The preserved reference remains the integration power-rule catalogue
  exemplar and its `v12` profile at commit `6b103580c`.
- New presentation experiments must remain independently reversible and must
  not silently modify the Rule Ledger Passage candidate.
- Promotion still requires human approval plus pressure from a structurally
  different caller.

## Alternatives Considered

- **Call it template matching:** rejected because the distinguishing design is
  the persistent rule-and-binding ledger within a motion passage, not the
  underlying match operation alone.
- **Promote it immediately as the standard rule-application UI:** rejected
  because the user asked to preserve an option, and the exemplar has not yet
  established a general caller boundary.

## Follow-Ups

- Compare it with the Paragraph Kinetic Figure in a broader lesson context.
- If the Rule Ledger Passage is later approved for promotion, test it with one
  structurally different rule family before extracting shared presentation
  contracts.
