# KP Hybrid Experiment Verification Cadence

Date: 2026-08-10
Status: accepted

## Decision

KP will not use a production certification matrix to discover subjective
visual, motion, or interaction treatments. Discovery and promotion have
different evidence burdens.

During discovery, test durable truth first:

- semantic identities, states, ranges, and endpoints;
- one typed authority for time, lifecycle, and paint ownership;
- deterministic direct seek, reverse, interruption, and restoration;
- accessible and no-JavaScript meaning;
- regressions already observed in the canonical exemplar.

Then build one independently reversible exemplar with only a focused unit
suite and a single-browser smoke check. Human review, not a DOM snapshot or
CSS assertion, selects choreography, timing, composition, emphasis, and visual
language.

Only after the exemplar is approved should KP add motif-specific regression
coverage, pressure the boundary with one structurally different caller, and
run dense viewport, theme, browser, performance, and release matrices.

## Test Value Rule

A test must protect at least one of the following:

1. a learner-visible semantic promise;
2. an architectural authority or ownership boundary;
3. an accessible or static-publication contract;
4. a previously observed regression;
5. an approved visual or interaction invariant.

Provisional spacing, dimensions, DOM arrangement, and unapproved choreography
are not durable test targets. Implementation-detail assertions and duplicate
proof of an already-covered invariant should be removed or avoided.

## Application To The Current Work

The remaining canonical algebra Article slices are promotion work after an
approved parity checkpoint. Their focused range, retained-session, direct-seek,
and lifecycle tests remain warranted; closeout should reuse existing release
gates instead of inventing a larger matrix.

The successor semantic-explanation differentiation proof is visual discovery.
It should reach its first human checkpoint with one fraction-composition
exemplar, cheap semantic and no-JavaScript checks, and one browser smoke test.
Responsive certification, cross-browser pressure, broad reuse contracts, and
generalization remain post-approval work.

## Authority

The operational policy is the repository-level `AGENTS.md` section “Visual
discovery and test timing.” This decision records its application to the
explanation-and-attention workstream without creating a second execution plan.
