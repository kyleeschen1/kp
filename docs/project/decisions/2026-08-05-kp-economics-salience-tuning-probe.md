# Economics salience tuning probe

Status: active visual-discovery checkpoint; not approved for promotion.

The economics two-column tutorial is the canonical exemplar for testing a
smaller attention vocabulary. Its internal bottom controls expose six bounded,
URL-reproducible choices: non-supply graph opacity, low-chroma blue and red
alternatives, prose line height, prose weight, and text-column width. Reducing
the text width gives the remaining width to the animation panel. The existing
line-width, paragraph-gap, text-side, and theme controls remain available.

This probe replaces no shared graph, lesson, or scroll API. Animation math,
semantic checkpoints, scroll clocks, authored prose, and the accepted phone
fallback are preservation boundaries. The abandoned motion-bridge dwell
direction is not promoted by this work; its existing reversible query mode
remains available only as historical comparison.

Normal prose ink returns to black in light mode and white in dark mode. KaTeX
retains its separate gray foreground because mathematical notation has its own
optical role. Font-weight choices use real Source Serif faces rather than
synthetic weight. Palette switches select fixed low-chroma colors instead of
creating color-mix continua. The graph-opacity control composes with animated
reveal opacity while leaving the supply curve at full strength.

Defaults are omitted from the URL. Human review of the economics exemplar is
required before any tuning value, palette, salience rule, control contract, or
layout treatment is generalized to another lesson. The smallest rollback unit
is the single implementation commit for this probe.
