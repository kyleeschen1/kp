# Repeatable row operations: measured delivery boundary

Standing engineering-budget repair authority applies. This records an explicit
policy amendment, not an optimization claim for the added interactive feature.

The previous complete rectangular all-mode union measured 114834 JS / 16316 CSS
gzip bytes. The first repeatable workbench build measured 125476 / 16822 and
failed its 116000 / 17000 gate. Module attribution showed that the domain's exact
rational facade imported the entire protocol public barrel: review and linear
problem schemas initialized even though this reader only requested arithmetic.

The repair adds one declared arithmetic-only protocol public subpath. It
reexports the existing neutral implementation; the domain facade preserves its
names. Existing protocol consumers keep their API, negative deep-import and
dependency-direction tests remain, and cross-boundary arithmetic conformance
still executes. This is a bounded additional public entrypoint, not permission
to deep-import protocol implementation files. The ordinary-animation module gate
now rejects these unrelated schema families. No side-effect suppression,
minification trick, omitted consumer or duplicated arithmetic was introduced.

On the same intermediate workbench revision, that repair reduced the all-mode
union from 125476 to 121724 JS gzip bytes (3752 bytes saved). Subsequent compact
unit-addition, equality-presence and final wording corrections yield 122023 JS / 16832 CSS.
The actual emitted arithmetic chunk now contains only neutral exact arithmetic
and the checked row-operation helper. `npm run build:matrix-interpretations`
and `npm run measure:semantic-cost` reproduce the inventory and full closures.

The all-mode union keeps every dynamic mode, including the old guided view. Its
new ceiling admits the interactive controls, history, exact operations and local
renderer with about 2.5 KB bounded headroom. Separate activation gates prevent
that union allowance from concealing eager delivery. The cold route adds only
171 JS gzip bytes relative to 94667 previously measured. Collection activations
retain their existing limits. No new dependency was added.

Composition's source consumers are unchanged; generated shared-chunk identities
and export spellings changed with the new build graph. Its complete closure
grew 37 compressed bytes from 110998 to 111035, exceeding the old ceiling by 35.
An explicit 500-byte ceiling increase provides bounded build variation headroom;
it does not omit the composed consumer or excuse future unexplained growth.

Alternatives rejected: duplicating rational arithmetic would split authority;
removing the explanatory view would lose a real consumer; importing protocol
internals would weaken the declared boundary; retaining schema fanout and only
raising the ceiling would preserve a measured architectural cost defect.

These are sums of compressed emitted assets, not observed network transfers.
Fonts are excluded under the existing separate accounting policy. This visual
candidate has not been promoted or certified across browsers and matrix shapes.
