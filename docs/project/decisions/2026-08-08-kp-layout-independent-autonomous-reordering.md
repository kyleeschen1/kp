# Defer Layout Promotion While Advancing Independent Infrastructure

Date: 2026-08-08
Status: accepted

## Decision

Revise the active motion-passage run so one bounded economics-local stacked
layout correction happens first, followed by all publication, route-closure,
practical CodeMirror, semantic-TOC, direct-navigation, accessibility, and
performance work that does not require approval of the visual grammar.

The human checkpoint moves to the end of that autonomous tranche. Shared
station-progress extraction, split-projection parity, final floating-TOC
geometry, visual promotion, and release approval remain gated on the user's
return.

## Layout Revision Boundary

The provisional exemplar uses one continuous page and stage background, a
slightly larger gap between stage and progress rail, a statically correct
initial focused passage, dim and slightly reduced upcoming prose, bright
full-scale active prose, and normal readable completed prose. Interface
entrance, retreat, dissolve, and stagger effects are removed so semantic graph
objects and the progress fill own visible transition motion.

Exact opacity, scale, spacing, color, and timing remain provisional. The
revision does not promote a shared treatment or authorize a second caller.

## Reason

Human feedback strongly prefers the stacked eye path but still finds the
current presentation over-animated. The remaining publication, loading,
authoring, and semantic-navigation boundaries are valuable under any later
layout choice. Advancing them avoids idle time without embedding an unapproved
visual grammar into shared infrastructure.

## Preservation And Rollback

Preserve the economics semantic asset, retained SVG session, shared clock,
direct seek and rewind, URL restoration, published source order, themes,
accessibility modes, and framework-neutral runtime authority. The smallest
visual rollback unit is the economics animation-station presenter, local
stylesheet, and focused tests.

Each infrastructure slice remains independently revertible. The editor stores
semantic content and projection-neutral metadata, and navigation resolves
stable semantic IDs before presenter-specific placement.

## Consequences

- The original 30-slice split-first proposal is superseded only in execution
  order; its completed evidence remains valid.
- Practical CodeMirror work may proceed after static publication and route
  closure without waiting for split parity.
- TOC semantic publication, URL/history state, and direct navigation may
  proceed; exact floating placement and responsive visual chrome may not.
- No shared motion-passage visual contract, split port, algebra caller,
  Canvas/WebGL work, 3D parity, SvelteKit, Internal Studio, Public Web, or
  Public Editor enters this run.
