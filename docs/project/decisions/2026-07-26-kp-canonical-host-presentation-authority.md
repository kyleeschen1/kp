# Canonical Hosts Must Not Reinterpret Atom Paint

Date: 2026-07-26
Status: accepted

## Decision

The user approved the radical reader parity repair in
`../reviews/2026-07-26-radical-reader-parity-repair-proposal.md` as the exact
scope of slice 16 in
`run-contract.kp.radical-reader-promotion-kit-v0`.

The native-KaTeX renderer session exclusively owns atom-local position, size,
opacity, and transform. A host may supply semantic layout for parent groups and
retain native endpoint interaction, but it may not reinterpret sampled atom
paint after the canonical session applies it.

The glyph experiment is the accepted radical visual reference. Experiment and
reader must consume the same reusable session construction and local tracks.
Cross-host parity, property-authority, and temporal-continuity gates become
required promotion evidence.

## Scope

This decision authorizes one bounded slice-16 repair and an immediate live
browser checkpoint. It does not authorize:

- promotion-kit extraction or the unit-exponent follower;
- operation-, route-, radical-, glyph-, or KaTeX-class-specific presentation;
- a second renderer, runtime, clock, or durable animation artifact; or
- updates to visual references that merely accept the degraded reader output.

Slices 17–20 remain inactive until the user approves the repaired live parity
surface.

## Consequence For Governed Generation

Governed models continue to choose verified semantic operations, lineage, and
explanation intent rather than pixels. The deterministic compiler/renderer
boundary is strengthened: once KP compiles presentation, host adapters cannot
silently alter its atom-level meaning or motion.
