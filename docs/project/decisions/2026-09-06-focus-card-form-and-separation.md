# Focus Card form ownership and clear separation

Status: accepted direction; revised visual treatment awaits review

The user approved both repairs followed by resumption of the existing structural
authoring loop. This is a bounded amendment, not a new long-run plan.

- Keep slow starts as an attention tool. Shorten ambiguous near-overlap when
  copies separate; preserve continuous motion, semantic grouping and eased
  arrival. Formalizing this principle does not enforce one curve globally.
- Use the authored distribution Focus Card as the reversible motion exemplar:
  `animation.fraction-composition.two-thirds-solve`, verified distribution
  bundles, existing native equation compositor and existing timeline clock.
  Generic copy/fan-out and all other callers retain their previous motion.
- The common Focus Card shell and stylesheet own form and passage typography.
  Use the canonical supply-tax passage's Georgia serif default, with one
  `--kp-focus-card-passage-font` override. Controls, math and code retain their
  own typography. No semantic schema or renderer replacement is authorized.
- The two authored cards share two-endpoint navigation/lifecycle enhancement;
  their native preparation, semantic endpoints and paint remain domain-owned.
  This does not migrate every legacy controller or handwritten card.
- Static and enhanced output share content, shell and styles. Static output
  includes verified native KaTeX endpoints and both passages, with no dead
  controls. Existing published files update through rebuild/redeploy, not
  retroactively. No new publication platform is implied by dev-route proof.
- Resume the existing compiler-cost gate without raising its limits, weakening
  the real consumer fixture or promoting a public hierarchy to escape cost.
  G2 still gates canonical supply-tax migration.

Acceptance: intact fraction arrangement, shorter ambiguous departure, existing
swipe/arrow/scrub performance and reversal, correct shared prose type, legible
static output, isolated native owners, reduced motion and safe disposal.
Motion and card-form changes are separate rollback units. Automated checks do
not approve their subjective appearance or authorize catalogue-wide promotion.
