# Run Objective Work Before The Combined Visual Checkpoint

Date: 2026-08-17
Status: accepted

## Decision

Reorder the remaining governed-animation-generation work so independently
verifiable compiler and capability slices run first. Repair the shared
full-motion readiness failure after that objective foundation, then defer all
subjective motion and Internal Studio presentation judgment to one final human
checkpoint.

## Rationale

The existing continuation reached a visual stop just as human review became
unavailable. Tool-neutral CLI behavior, deterministic corpus coverage, the
model-neutral planner port, and domain-owned frontend gaps do not depend on
accepting the current exponent/log choreography. Running them first preserves
useful autonomous time without waiving exemplar-first review.

The playback defect still precedes URL and exact-state integration because
those surfaces must reproduce a trustworthy renderer state. It also remains a
release blocker: failed or unready full-motion surfaces may not silently pass
as healthy endpoint playback.

## Approved Order

1. Tool-neutral equation-series CLI.
2. Deterministic equation-series corpus.
3. Model-neutral natural-language planner port.
4. Matrix, code, Graph2D, and Graph3D frontend-gap declarations.
5. Shared playback/readiness and canonical exponent/log repair.
6. Coverage, URL, dock, and Review integration.
7. Combined human visual checkpoint.
8. Release closeout only after explicit approval.

## Preservation And Stop Conditions

- Preserve semantic endpoints, stable identities, operation order, one shared
  clock, and approved log-product/log-quotient choreography.
- Do not claim subjective visual approval during unattended execution.
- Stop before release closeout for human judgment.
- Stop earlier if repair requires a second clock, caller-local semantic truth,
  or silent generic fallback.
