# Canonical Fraction Composition Before Quantity Models

Date: 2026-07-27
Status: accepted

## Decision

Before opening the new exact-fraction quantity-model lane, KP will promote one
already verified fraction-composition trace into the canonical learner path:

```text
2/3(x + 6) = 10
```

The trace already proves opaque fraction distribution, schedule-independent
numerator normalization, distributed-sum composition, verified reverse
factoring, and a complete exact solve. The promotion loop must reuse that
semantic authority, the immutable fold projection, the certified equation
stage, the canonical native-KaTeX renderer session, and the single Animation
Library host. It may not invent a second semantic trace or copy the old visual
implementation.

The next capability-opening loop remains:

```text
1/3 + 1/6 = 1/2
```

with exact quantity identity projected through KaTeX, partitioned circles,
bars or areas, and a number line.

## Why

This order first harvests work that is semantically complete but not yet a
canonical learner animation. It gives a sharper amortization test than opening
another capability immediately: a successful promotion should consist mostly
of lesson content, verified motif bindings, fold/layout inputs, descriptor
wiring, and focused evidence. Any pressure for compositor-specific fraction
geometry or a new runtime category is therefore an honest failed invariant.

Static types remain feature-coupled. The promotion will type the exact
fraction-distribution, normalization, reverse-factor, motif, paint-ownership,
and promotion-evidence boundaries required by this exemplar. Repository-wide
ownership, checkpoint, HTML-context, and promotion migrations remain separate
unless the exemplar proves that a bounded type cannot protect the product
boundary.

## Preservation

The completed radical, fraction split/merge, foldable distribution, certified
stage-layout, review-capture, accessibility, export, and production contracts
remain unchanged. Existing user-owned roadmap, thread, atlas, portable
publication, and specification edits are not part of this decision.
