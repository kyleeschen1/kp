# Co-creative spaced practice is the current product priority

Date: 2026-10-28
Status: accepted user direction; implementation recommendations remain proposed

## Authority

The user states: "these spaced rep ambitions and the LLM loop are the most
important thing to me right now" and asks how to steer KP, including ergonomic
API discovery through rapid iteration and maintaining an exemplar library while
the API changes. This accepts a priority, not a new implementation run.

The preceding discussion establishes the following desired experience:

- Question generation is a negotiation with the learner/author about useful
  insights, misunderstandings, context and what a response should demonstrate.
- Practice should support relationships, definitions with multiple conditions,
  proofs, arguments, procedures, contrasts, prediction and alternative modalities.
  A small question can retain a rich context; the useful grain changes as
  understanding develops. These are ambitions, not certified capabilities.
- Mistake records should preserve the situation and actual response. Separate
  observations, learner explanations and revisable model hypotheses. Do not
  infer mastery or a misconception from one response.
- Partial understanding is a legitimate working state. Preserve conceptual
  roles and unresolved questions so later encounters can deepen understanding.
  Cognitive debt is relative to the learner's purpose; deferred proofs and
  unfamiliar details are not automatically obligations to repay.
- The user sees hermeneutic and Neoplatonic inspiration in recurring movement
  between particulars and larger structures. Application and theory should
  inform each other. This is pedagogical direction, not an empirical learning
  result or a mandate for a universal ontology.
- Short explanations and exemplars are experiments that develop reusable
  affordances and pedagogical judgment. A competitive content library is not
  the assumed product destination; LLM collaboration and composition matter.

## Steering consequence

The active direction becomes [co-creative practice](../threads/co-creative-practice.md).
Reader, compiler, semantics and motion work serve this experience. Broad reader
polish, speculative API redesign, curriculum expansion and universal knowledge
modeling do not precede it automatically. Repair measured blockers when needed.

The earlier proof-memory experiment remains useful implementation evidence,
including its unaccepted attentional presentation. This priority does not accept
that presentation, reactivate its old run, or authorize the old remaining slices.

The [next-step review](../reviews/2026-10-28-next-step-review.md) owns proposed
sequencing and API/exemplar policy. No scheduler, learner diagnosis engine,
embedded paid LLM calls, new renderer, publication or autonomous run is approved
by this decision. In particular, reconsidering delayed practice as the lead
product emphasis is distinct from selecting its scheduling implementation.

## Preservation

Keep domain-owned truth, explicit assumptions, stable semantic referents,
deterministic seek/return, accessible static reading and typed repair gaps.
Preserve the accepted fractional reader improvements. Do not equate a compiled
source, a successful interaction, subjective usefulness and delayed learning.
