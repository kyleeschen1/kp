## Migration boundary

This is a source-of-truth migration, not a visual redesign. Preserve the URL,
four-card Focus Deck, existing SVG/native KaTeX owners, reader clock, deep links,
prose meaning, accessibility, and sibling cards. The normal page must run from
the ordinary build without the development-only authoring preview endpoint.
Minimum build-delivery integration belongs to migration; a general publication
workflow does not.

Retire only the obsolete canonical-page wiring whose consumers are migrated.
Keep shared economics constructors, renderer capabilities, and useful regression
fixtures. Do not delete the old domain implementation merely because the new
source consumes it. Keep the cutover independently reversible through Git.
