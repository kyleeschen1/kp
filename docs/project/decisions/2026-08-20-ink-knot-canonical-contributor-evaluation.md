# Ink-Knot Is The Canonical Contributor-Evaluation Motif

Date: 2026-08-20
Status: accepted

## Decision

Use the approved **ink-knot contributor-fusion** treatment as KP's canonical
default when multiple semantic contributors combine into a new arithmetic
result. The currently promoted boundary remains constant product, quotient,
and sum.

This does not make ink-knot a universal evaluation animation. Verified
identity operations such as `2 × 1 → 2` and `x + 0 = 4 → x = 4` continue to
use carrier-preserving simplification because one semantic carrier survives.
Other instructional families remain possible only when their distinct meaning
and evidence justify them.

The provisional punctuated-substitution and result-reception comparison
treatments remain retained review evidence. They are no longer active
promotion candidates and must not compete with ink-knot as default authoring
choices.

## Existing Implementation Evidence

No renderer or runtime change is required to enact this decision:

- `kp.evaluation-family.contributor-fusion.v1` is already `promoted` and maps
  to `compressed-ink-handoff`;
- default family resolution already selects it for constant product, quotient,
  and sum;
- the generic Native KaTeX evaluation adapter already installs the promoted
  ink-knot playback when no development comparison override is active;
- `2 × 3 → 6` and `3/6 → 1/2` provide human-approved horizontal and vertical
  pressure, while `5 + 2 → 7` confirms a third operation without caller-owned
  geometry or timing; and
- carrier-preserving simplification remains a distinct promoted profile with
  nominal identity evidence.

## Canonical Boundary

```text
verified operation semantics
  -> multiple contributors create a new result
  -> contributor-fusion family
  -> compressed-ink handoff
  -> Native KaTeX ink-knot profile
```

Do not select ink-knot from glyph count or operator spelling alone. The
semantic transformation and promoted profile own the choice. Authors and
models may express instructional intent, but they do not author the knot's
geometry, timing, opacity, or renderer nodes.

## Consequences

- Punctuated substitution leaves the active queue; retaining its comparison
  implementation does not make it canonical or planner-visible.
- Existing ink-knot tuning continues to update every promoted caller through
  the shared renderer profile.
- A new evaluation shape may reuse the family only when its semantic
  contributors and compositor mechanism fit the promoted boundary; otherwise
  it requires a typed gap or a separately reviewed family.
- The next useful pressure is the deferred fraction sequence, where the
  visible local product evaluation should use canonical contributor fusion
  without reopening the approved fraction-equivalence choreography.

## Preservation Boundary

This decision does not change semantic endpoints, clocks, Native KaTeX paint
ownership, ink-knot timing or geometry, carrier-preserving behavior, existing
catalogue URLs, or provisional comparison code. The independently reversible
unit is this control-plane decision and its roadmap/thread reconciliation.
