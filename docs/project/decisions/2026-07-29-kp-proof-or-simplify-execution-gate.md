evaluation program to `1 + 2 -> 3`, `5 + 2 -> 7`, and one exact quotient.

- **Pass:** continue exact fraction, then place value, economics, and physics;

  accessibility, and native endpoints; simplify ordinary algebra to a

- **Mixed:** version the capabilities separately instead of forcing evaluation,
  fission, and fusion through one renderer abstraction.

The stable promotion order is unchanged. These paths are policy, not advance
authorization to execute every later slice.
