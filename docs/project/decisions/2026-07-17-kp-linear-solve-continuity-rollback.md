# Linear Solve Continuity Presentation Rollback

Date: 2026-07-17  
Status: accepted  
Scope: canonical `x + 3 = 7` editor animation and its shared descriptor routes

## Decision

Restore the pre-material-primitive presentation for the canonical linear solve:

- cancellation uses the established continuous meet-and-collapse recipe without
  the witnessed-annihilation overlay;
- constant derivation uses the established staggered arcs and overlapping
  source/result handoff instead of successor synthesis;
- persistent equation material continues to interpolate to native target
  positions.

The semantic cancellation witness, material/catalyst annotations, successor
binding, reverse laws, and shared primitives remain in the model. The rollback
is a presentation recipe selected by asset metadata, not a semantic rollback.

## Rationale

The generalized witnessed-annihilation and successor-synthesis policies added
extra phases and visual ceremony that made the canonical example less coherent.
The canonical hand-tuned example is the quality baseline. New generic material
motifs must be refined in isolated fixtures and pass side-by-side visual review
before they replace that baseline again.
