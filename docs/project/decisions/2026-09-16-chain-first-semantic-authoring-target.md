# Chain-first semantic authoring target

Status: accepted product direction; no new implementation run authorized here.

The user wants to author mathematical chains rendered with KaTeX and have an LLM
infer the intended reasoning moves and connect them to semantically correct motifs
with high precision across KP's subjects. This sharpens the purpose of the saved
transfer experiment and proposed fraction family; it does not replace existing
domain authorities or authorize a universal semantic/renderer framework.

The desired author experience is a short chain plus surrounding explanation and
necessary assumptions. The model proposes typed operations, operand/group identity,
correspondence and instructional intent. Existing domain checkers validate the
supported mathematical step and side conditions; approved presentation contracts
then express it through appropriate motifs. KaTeX remains a rendering endpoint,
not the semantic source of truth. Prefer source LaTeX and domain context over
inference from rendered glyphs.

Adjacent equations alone can underdetermine the explanation. Equal endpoints do
not establish the intended derivation, approximation, substitution, model
assumption or identity lineage. Multiple operations may need a checked child
chain. Request a small missing assumption or intent when needed; return a typed
repair gap when no supported operation/presentation path exists. Do not award
authority from model confidence or invent plausible motion to bridge a gap.

Precision and coverage must be measured separately. Evaluate unseen supported
variations, ambiguous chains, invalid steps, missing assumptions and deliberately
unsupported cases. A useful result includes correct abstention and precise repair
diagnostics. Fixture tests are not a live-model inference benchmark. No paid model
calls or new benchmark infrastructure are authorized by this direction.

Across subjects, keep a consistent authoring experience with domain-owned evidence:
algebra laws, mechanics assumptions and dimensions, economic model premises,
probability conditions, and language/interpreter authority for code. An economic
derivation being correct under a model does not validate the model empirically.
Graphs and code remain native artifacts linked through semantic relationships,
not representations forced into KaTeX.

The immediate engineering measure is whether a new supported chain requires only
source plus sparse intent, with renderer work reserved for an identified missing
mechanism. Preserve KP's text/attention philosophy: keep the argument readable,
focus on the changing relationship, retain relevant context, and allow compact
moves to unfold into checked details without losing the reader's place.

Use the existing supported authoring entrypoint, governed construction and typed
repair boundaries. First establish reliable chain compilation and transfer with
explicit intent; inference can propose that same intent rather than creating a
parallel path. The dashboard remains a planning inventory, not an inference
precision score or automatic capability certificate.
