# Linked equation panel: bounded delivery cost

Standing engineering-budget repair authority applies. This is an explicit
feature-cost amendment, not an optimization or a refreshed measurement baseline.

At accepted commit `005888746`, all-mode rectangular closure was 124366 JS /
16914 CSS gzip bytes, against 124500 / 17000 ceilings. The linked equation panel
measures 126214 / 17153 and fails both union ceilings. Its complete workbench
activation grows from 104697 / 15284 to 106545 / 15523: +1848 JS and +239 CSS.

Module inventory attributes the addition to local exact equation projection,
panel adapter, the existing reader semantic-focus service and existing cross-view
attention compiler. Correspondence types erase; no solver, framework, new clock,
unrelated schema family or new dependency enters the closure. Equation rendering
occurs at committed endpoints, not on each animation frame. Two live equation
buttons and static endpoint readings add DOM; this is not a zero-runtime-cost
feature. The new shared focus owner is disposed with the host.

| --- | ---: | ---: | ---: |
| Rectangular all-mode union | 124366 / 16914 | 126214 / 17153 | **128000 / 17600**, amended |
| Cold rectangular default | 94806 / 14686 | 94806 / 14686 | 100000 / 16000, unchanged |
| Row workbench | 104697 / 15284 | 106545 / 15523 | 110000 / 16000, unchanged |
| Guided addition | 112430 / 15571 | 112430 / 15571 | 115000 / 16000, unchanged |
| Matrix composition | 111045 / 14533 | 111045 / 14533 | 111500 / 16000, unchanged |

Only the all-mode union ceiling changes: JS +3500 and CSS +600. This retains
1786 JS / 447 CSS bytes of bounded headroom after the feature. All actual
dynamic consumers, cold-route and individual activation gates, forbidden import
checks, menu closure and DOM/resource gates remain accounted for and unchanged.

Alternatives: removing static equations would weaken script-free access;
reimplementing focus/correspondence would split semantic ownership; lazy-loading
this small panel would add a loading lifecycle but not reduce the all-mode union;
shrinking source formatting or suppressing checks would not reduce delivered
work. Inventory shows no avoidable unrelated import fanout to repair here.

Reproduce with `npm run build:matrix-interpretations` and
`npm run measure:semantic-cost`. Values sum emitted compressed assets; they are
not measured network requests or heap, and fonts retain separate accounting.
This amendment does not promote the visual treatment or admit arbitrary growth.
