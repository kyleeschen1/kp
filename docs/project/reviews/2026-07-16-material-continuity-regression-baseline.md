# Material Continuity Regression Baseline

Date: 2026-07-16

Run contract:
`run-contract.kp.animation.material-continuity-and-artifact-morph-v0`

## Reproduction

The KP editor was sampled at fixed progress values with the development server
running at `http://127.0.0.1:4173`.

Linear solve checkpoints included both transformation boundaries and the
midpoints of balanced introduction, cancellation, and constant derivation.
Radical checkpoints included base reflow, exponent gathering, radical reveal,
native settlement, and release. Organic and restrained styles were compared at
identical normalized progress.

## Linear Solve

The rendered coordinates happen to align at the two operation boundaries, but
the visible material does not persist. Source continuants remain authoritative
until the exact endpoint; the next transformation then mounts state-specific
source tokens. This produces a subtle raster and focus discontinuity even when
the bounding boxes match.

The three transformations also each receive a complete local envelope. The
result repeatedly releases and reacquires attention instead of reading as one
solve with meaningful internal checkpoints.

## Fractional Exponent To Radical

The persistent base reaches the correct radicand coordinates, but ownership
still switches at the endpoint.

More importantly, the exponent fragments and radical do not use one shared
material bundle. Source exponent paths are planned toward the target relation
center while target radical material unfolds from an opposite-corner bundle.
The two events overlap in time without forming one perceptual transformation.

The older dashboard implementation remains the authoritative comparison. It
collapses captured exponent material into a measured bundle and unfolds
radical material from that same bundle.

## Gestalt Contribution

Organic token realization is secondary rather than causal. It adds sub-pixel
translation and bounded deformation after canonical token motion. Because it
currently applies to every motion token, it can visibly disturb fraction rules
and radical structures and amplify the underlying discontinuity.

## Repair Gate

The loop may not close merely because endpoints, phase labels, and opacity
ranges pass. It must prove:

- stable visual-material ownership for continuants;
- bridged attention and velocity across solve operations;
- one measured source/target bundle for representational succession;
- exact native settlement without a final ownership snap;
- structural-notation exemptions from nonuniform gestalt deformation.
