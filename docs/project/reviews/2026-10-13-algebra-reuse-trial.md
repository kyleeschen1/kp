# Distribution then collection: bounded reuse trial

User approved the recommendation to freeze Gaussian elimination and build one
non-LA explanation plus one mathematical source variation. The completed systems
generator and consistency contrast remain references, not an active polish queue.

## Outcome and boundary

Explain `3(x+x) → 3x+3x → (3+3)x → 6x`, then change coefficient and variable
through source alone. Distribution copies the coefficient; collection retains
the common variable; evaluation changes only the coefficient sum. This deliberately
small example tests composition, not general algebra support or teaching efficacy.

Canonical artifact: a checked distribute/collect presentation on the existing
reusable-reasoning host, `?example=distribute-collect`. Renderer: the existing
canonical native KaTeX equation session and composed-algebra focus card.
Semantic authority: structured distributive-law verification, integer-multiple
factoring and contextual constant-sum evaluation. No authored geometry or clock.

Current gap: editable composed algebra fixes collection before distribution;
the richer foldable-distribution lesson is fixture-specific. Add only the bounded
proof-backed bridge needed for this trial. Do not generalize that entire lesson.
Preserve all existing sources, routes and motifs. The new route and its bounded
binding are the rollback unit; no LA code changes.
