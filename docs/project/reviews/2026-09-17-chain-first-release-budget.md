# Chain-first release: measured costs and budget amendment

Standing engineering-budget repair authority permits this bounded amendment.
It changes no mathematics, visual treatment, browser capability or measurement
consumer. It is a policy correction, not an optimization claim.

The complete fraction-composition tutorial closure measured 330,965 gzip JS/CSS
bytes: 217,447 startup plus 113,518 declared activation. Its old 310,616 baseline
with a 5% allowance permitted 326,147, so the gate failed by 4,818 bytes. The
September 12 owner-reconciliation evidence measured 322,805 with the same
complete traversal: growth since that recorded measurement is 8,160 bytes
(startup +1,229, declared activation +6,931). This is a historical comparison,
not a fresh isolated before/after attribution to subtraction alone.

The attribution includes the native compositor (28,107 gzip bytes), native track
projection (10,368), generated algebra fixture (8,789), equation compositor
adapter (7,906), distribution (4,886), successor synthesis (4,823), and existing
linear-solve declaration paths. These remain reachable supported consumers.
Shared reader runtime is 154,058 bytes, below its unchanged 160,087 ceiling.
HTML is 10,548 gzip bytes; authoring leakage is empty. Separate startup, HTML,
activation-increment, shared-reader and leakage checks all pass unchanged.

Amend only the activated baseline to **320,000**, retaining the existing 5%
policy: ceiling **336,000**, measured headroom **5,035** (about 1.5%). This does
not reset the baseline to the measurement or apply 5% more headroom on top of
it. Existing exact-boundary and one-byte-overrun tests remain executable.
Alternatives: dropping declared lazy consumers would undercount; delaying
imports merely shifts startup classification without reducing activated cost;
separating broad existing compilation/renderer dependencies deserves its own
measured implementation pass. None is disguised as a completed speedup here.

The fraction experiment exposes additional debt: its four hosts share 450,628
startup and 492,302 activated gzip JS/CSS bytes. It eagerly imports checked
construction and native presentation machinery; it does not yet share the
physics/scalar lazy activation envelope. Initial HTML is only 4,349–4,563 gzip
bytes. These are artifact closure measurements, excluding fonts, images,
HTTP overhead and parse/paint time—not observed network or latency benchmarks.
No pre-existing fraction-experiment ceiling is claimed or silently invented.

Measurement initially failed because Vite coalesces the identical fraction
entries and omits their HTML manifest keys. The shared collector now derives
actual emitted HTML script/link roots, follows all static/nested dynamic
dependencies, deduplicates files and rejects missing script authority. The
new regression covers coalesced entries, direct CSS, nested dependencies and
missing scripts. Physics/scalar retain their full consumers. This repairs the
measurement boundary rather than omitting the absent-key hosts.

Commands: `npm run check:algebra-fraction-composition-budgets`,
`npm run check:reader-budgets`, `npm run check:canonical-animation-budgets`,
`npm run measure:mechanics-relations-closure -- fraction` (also physics, scalar,
fraction-numeric, fraction-two-sided, fraction-subtraction), and
`node --disable-warning=ExperimentalWarning --test
scripts/check-reader-route-budgets.test.ts tests/html-bundle-closure.test.ts`.
