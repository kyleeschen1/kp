# Operation-evaluation continuity topology selection

Date: 2026-07-30
Status: selected for executable-program compilation
Run contract:
`run-contract.kp.executable-motif-perceptual-continuity-repair-v0`
Slice: `s12`

## Decision

Select **bounded semantic-contact co-presence** for the canonical
many-to-one operation-evaluation program.

The approved `1 + 2 -> 3` reference keeps the two material inputs and the
operator catalyst visibly participating until the result becomes
recognizable. Pair-scoped semantic contact permits the measured source and
target paint to coexist only inside that program-owned recognition interval.
It adds no paint owner, renderer lifecycle, clock, scheduler, path family, or
caller-authored presentation field.

Target-style reverse FLIP remains the correct generic technique for compatible
one-to-one paint lineage. It is not the operation-evaluation topology:
substituting one target-shaped paint carrier for `1`, `+`, and `2` would erase
two material/catalyst roles and produce a large source/target silhouette
change.

A visible motif-owned carrier remains an eligible fallback when certified
co-presence cannot pass. It is not selected for this reference because it
would add a paint owner without improving phase, role, endpoint, geometry, or
raster evidence.

## Generic selection order

Candidates are selected by the following renderer-neutral criteria:

1. retain every executable-program phase and required semantic role;
2. satisfy the operation-evaluation visible-ink, adjacent-frame geometry, and
   adjacent-frame raster budgets;
3. retain total unambiguous ownership and atomic native endpoint transfer;
4. require pair-scoped semantic-contact authority for every co-presence frame;
5. settle to exact source and target paint without native DOM mutation;
6. among otherwise eligible candidates, minimize added paint owners, raster
   delta, geometry delta, and per-frame paint work.

This order deliberately prevents a lower-cost target glyph from replacing
program roles and prevents pixel history from becoming semantic authority.

operation-presentation checks; 5,000 comparisons completed in about 0.27
seconds against a two-second ceiling.

## Preservation boundary

Slice `s12` does not change production animation behavior. It records one
generic decision and development evidence. Slice `s13` may compile this
topology under the existing executable-program phases; it may not change those
phases, infer contact from geometry, add a renderer category, or make
co-presence universal for fission, fusion, or unrelated motifs.
