## What is shared, and what deliberately is not

| Responsibility | Current owner/boundary |
| --- | --- |

| Keyboard and continuous passage/stage input | Shared card-scoped keyboard and native-input owners |
| Playback intent | Existing clock plus typed play, gesture-settle and restore commands; no second clock implementation |
| Beat travel and count | Shared immutable checkpoint mapping and accepted gesture/count policy, demonstrated by uniform equation subranges and unequal code stops |
| Truth, assumptions and correspondence | Separate verified equation and language-owned evidence |
| Reference and return validation | Domain-owned source/revision pins; exact interrupted progress |

No universal knowledge schema, Article syntax revision, CAS, renderer, global
salience store, scheduler or arbitrary-code execution service was introduced.

cannot regain clock ownership. Semantic checkpoints, not prose-page counts,
govern navigation. Typed playback requests keep ordinary animation separate
from short gesture settlement. Native paint and semantic endpoints remain owned
by their established domain/rendering paths.

## Limits that must travel with the handoff

- Equation authoring supports one trusted distribution/normalization/evaluation
  trace and its first one to four operations, not arbitrary coefficients or
  LaTeX chains. Other existing KP operations require their own governed route.
- References and support validate explicit semantic structure; free prose is
  editorial, not automatically proved. This is not arbitrary recursive knowledge
  composition or a universal procedure ontology.
- Code preserves two compiled source revisions and seven pedagogical stages.
  Its certificate covers three declared threshold cases, not universal program
  equivalence. It has no live JSON editor, selected-source publication, compact/
  practice parity, or equation-style URL history yet.
- Equation publication is immutable local static reading. Changing shared form
  affects newly rebuilt editions, not bytes already distributed. No interactive
  publication, deployment, account or scheduler was added.
- Browser automation is not physical iOS Safari/trackpad certification. Rapid
  native wheel-axis switching and learner comprehension remain unclaimed.
- The 368,214-byte gzip static JS/CSS tax closure is a delivery measurement,
  not FPS or total wire cost. Broad tooling/3D chunk warnings remain separate
  from the passing fixed reader budgets.

## Was this the right loop?

Yes, as a bounded integration proof. It showed that semantic structure can
survive authoring edits, disclosure, retrieval and static publication while a
second domain reuses interaction without sharing mathematical truth. The cost
was higher than merely mounting an established animation: new host navigation
exposed timing-baseline, input-ownership, step-count and keyboard-routing bugs.
Their durable repairs belong to the shared owners, not equation-specific motion
exceptions. The existing semantic architecture did not need to be replaced.

The lesson for the next run is to establish the source/clock/semantic-stop
contract early, then review a small working visual exemplar before building a
large certification matrix. Do not turn this successful bounded proof into
permission for catalogue-wide migration or another universal abstraction.

## Recommended next boundary: R3 Bayesian flagship

The accepted horizon still makes Bayes the first new flagship; algebra remains
the integration fixture. **Next action is one bounded R3 proposal, not execution.**
Preserve the minimal-check-in policy: one consolidated scope approval, one early
coherent visual packet, then autonomous nonvisual hardening within that scope.

Recommended proposal shape:

1. Audit the existing probability/diagram owners and confirmed McKeon-style
   tree reference. Select one original two-event problem and its exact source;
   do not copy restricted handouts or introduce a universal scene graph.
2. Keep joint event masses and stable event identities domain-owned. Marginals
   are sums; conditionals require nonzero conditioning mass. Invalid totals,
   undeclared independence and zero-mass conditioning must return typed gaps.
3. Review one small tree that builds, collapses, conditions and changes branching
   order. Reordering preserves joint probability; conditioning changes the
   reference population; neither reverses causation. Link equations to the same
   quantities before adding visual elaboration.
4. After that visual approval, connect author edits, exact return, required
   context, prompts and static reading through the demonstrated seams. Preserve
   the probability frontend rather than forcing it through the equation binder.
5. Pressure the accepted mechanisms with a second problem, mainly by changing
   source. Measure caller glue and run one bounded live author/repair trial.
   Suggested later comprehension probes: predict posterior direction, explain
   the denominator, and transfer to the second problem. No outcome is claimed yet.

Broader frontend promotion and the lower-undergraduate math waves remain in

The tabled matrix asset, code/Graph3D obligations and public-product deferrals
