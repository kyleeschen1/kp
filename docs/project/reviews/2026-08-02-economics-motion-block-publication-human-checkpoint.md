  text-free, progressively enhanced scrubber apiece.
- Scroll position advances and reverses the local semantic timeline; authored
  holds remain still. Manual interaction temporarily owns the block, and the

  outer stage.

  controls in one transaction without replaying intermediate states.

  retains ordinary links and disabled controls without layout collapse.
- Mathematical prose, graph labels, and verification expressions use compiled
  KaTeX. Semantic truth, renderers, components, events, and URL codecs remain
  framework-neutral; Svelte owns only route orchestration and DOM application.
- Reduced motion suppresses automatic seeking while preserving exact manual

  verification aperture is deliberately omitted.
