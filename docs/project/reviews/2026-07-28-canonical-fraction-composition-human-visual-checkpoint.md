## Diagnosis

This is not a repeat of the old glyph/DOM endpoint misalignment. Native
endpoint ownership, font identity, fit, and handoff all pass. It is a shared
mid-transit clearance gap: linear enter, eliminate, persist, and fan-out paths
are composed before the visible-paint contact evaluator can reject their
unrelated swept intersections.

The fact that the same semantic pairs recur across modes and DPRs is useful:
one generic trajectory/clearance repair should cover them. There is no evidence
for a fraction matcher, notation-specific geometry, operation-specific
coordinates, a new lifecycle, or a second compositor.

## Recommended bounded repair

For slice `s19`, feed certified visible-paint rectangles and row membership
into the existing generic clearance planner before final track sampling. The
planner should produce a typed protected-transit certificate for every
unrelated pair, while semantic fission/fusion contacts remain explicitly
admitted. Reject the scene plan when an unrelated swept intersection remains.

Promotion criteria:

- all nine pairs disappear without pair-specific IDs or fraction branches;
- all 1,296 matrix samples report zero unrelated contacts;
- existing exact contacts, opacity, handoff, layout, rewind, accessibility,
  export, and resource gates remain green;
- no lifecycle, scheduler, geometry vocabulary, runtime, or paint authority is
  added.

Rollback unit: the generic clearance integration and this exact visual gate.
