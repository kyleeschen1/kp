## Diagnosis

This is not a repeat of the old glyph/DOM endpoint misalignment. Native
endpoint ownership, font identity, fit, and handoff all pass. It is a shared
mid-transit clearance gap: linear enter, eliminate, persist, and fan-out paths
are composed before the visible-paint contact evaluator can reject their
unrelated swept intersections.

The fact that the same semantic pairs recur across modes and DPRs is useful:
one generic trajectory/clearance repair should cover them. There is no evidence
for a fraction matcher, notation-specific geometry, operation-specific
coordinates, a new lifecycle, or a second compositor.
