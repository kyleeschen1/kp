# Cross-Language Code Animation Foundation

Date: 2026-08-13
Status: approved
Theseus contract: `run-contract.kp.cross-language-code-animation-foundation-v1`

## Objective

Turn the approved TypeScript free-shipping refactor into a small, tested
cross-language code-animation foundation:

```text
approved TypeScript exemplar
-> Python second caller
-> evidence-based shared contracts
-> bounded Scheme adoption
-> cross-language code-animation library
```

The TypeScript artifact is the canonical visual exemplar. Python is the
structurally different language caller that may justify shared infrastructure.
Scheme may then adopt proven invariants and optical vocabulary without being
forced through a TypeScript/Python source renderer.

The approved execution boundary reaches the Python human checkpoint at slice
17. Slices 18-30 are durably ordered but must not begin until the Python
checkpoint is approved.

## Preservation Boundary

- Preserve TypeScript semantics, score, trajectories, timing, URLs,
  accessibility, source selection, and deterministic seeking.
- Keep native source as the sole settled accessible paint owner.
- Use one deterministic sampled clock; CSS and host frameworks never own time.
- Preserve Scheme's recursive S-expression membrane, binding arcs, branch
  resolution, and collapse/expand choreography.
- Do not touch economics source or generated publication files, unrelated
  untracked documentation, or user-authored content outside this proof.
- Keep presentation changes independently reversible from semantic/runtime
  changes.

## Explicit Deferrals

- CodeMirror and editor refinements;
- public website, public editor, and curriculum-scale work;
- a universal scene graph or universal code renderer;
- catalogue-wide dark-theme promotion;
- new runtime parser dependencies or arbitrary source execution;
- broad Scheme/SICP expansion;
- new lesson layouts; and
- a second transformation topology such as wrap/unwrap.

## Visual Checkpoints And Promotion Criteria

The TypeScript syntax/dark treatment is already approved. Its remaining
presentation correction removes the focused-span background but preserves the
color as `--kp-code-highlight-background` for future motifs.

Python must stop at slice 17 for review of syntax hierarchy, continuity,
settlement, source fit, narration, direct seek, reverse, phone, reduced motion,
and page-level dark-theme behavior. Shared presentation contracts may be
extracted only after that approval.

Promotion beyond the two imperative-language callers requires:

1. both callers preserve source truth and deterministic motion;
2. the second caller is materially cheaper than the first;
3. shared seams contain no TypeScript- or Python-specific concepts;
4. no new clock, scheduler, stage lifecycle, paint authority, or semantic
   store appears; and
5. Scheme can adopt invariants without losing its specialized pedagogy.
