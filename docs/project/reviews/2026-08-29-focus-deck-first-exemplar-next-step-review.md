# Focus Deck First-Exemplar Next-Step Review

Date: 2026-08-29
Status: implemented; awaiting human visual review
Active thread: `../threads/focus-deck.md`

## Recommendation

Build one opt-in Focus Deck projection for the existing log-product Kinetic
Figure, then stop for human review. Reuse the exact current semantic material
and canonical animation so the experiment answers one product question:

> Can a compact, directly navigable deck transmit one expert way of seeing,
> while remaining a searchable projection of ordinary technical writing?

This should be a projection slice, not a new animation or general deck
framework.

## Why This First Animation

The whole-equation log-product equivalence is the best first exemplar because
it already has an approved animation and four reviewed reading states. It offers one
recognition beat, one structural focus beat, one rule-context beat, and one
motion-backed result. The current paragraph, local split, glance-coupled, and
stacked projections create unusually strong comparison evidence.

Its limitation is useful and explicit: it will prove the deck host, not
long-form transformation. The approved `2^x = 7` solve should be the second
caller if the first checkpoint passes.

## Canonical Exemplar Contract

- **Canonical artifact:**
  `animation.algebra.log-product.equivalence-frame`.
- **Host:** an opt-in `focus-deck` projection on the existing isolated
  log-product experiment route.
- **Renderer:** the existing Native KaTeX log-product compositor plus ordinary
  DOM prose.
- **Semantic source of truth:** the existing log-product objects and
  transformation, equivalence-frame occurrence/retention identities, current
  stable passage/state IDs, and their focus targets.
- **Preservation boundary:** the canonical animation, all current experiment
  projections, `kp.article.v1`, flashcard types and projections, Catalogue,
  integration work, and renderer ownership.
- **Rollback unit:** the Focus Deck projection module, local styles, route
  selection branch, and focused tests.
- **Promotion criterion:** human approval of this exemplar followed by a
  structurally different `2^x = 7` caller. Only their demonstrated common
  boundary may become shared infrastructure.

## Proposed Learner Experience

The frame contains a quiet context line, one compact stage, one short passage,
and a small semantic position indicator. It need not imitate a 16:9 slide and
must work as a page view or embed.

| Beat | Stable state | Textual act | Visual act |
| --- | --- | --- | --- |
| `orient` | `ln(xy)` | Name the claim | Show the complete source in normal ink |
| `locate-product` | `ln(xy)` | Identify what is multiplied | Localize attention on `xy`; keep context legible |
| `product-law` | `ln(xy)` | State why the rule applies | Show the rule as contextual support; do not duplicate the target |
| `apply-product-law` | `ln(xy)=ln(x)+ln(y)` | Name the rewrite and result | Retain the left side as a witness; on entry, run the canonical right-side transition, then settle |

The third beat is an armed still state. Advancing to the fourth begins the
rewrite, so the learner never has to guess whether a resting frame is supposed
to be moving. Back returns directly to the source endpoint. Replay, Pause, and
Scrub appear only for the motion-owning beat; Back and Next always navigate
semantic beats. There is no auto-advance.

The template is not permanent stage chrome. It belongs to the `product-law`
beat and can remain available through a quiet context disclosure after the
rewrite, without competing with the settled result.

## Search, Navigation, and Embedding

- Use semantic addresses such as `#beat.product-law`, while retaining a quiet
  ordinal such as `3 / 4` for orientation.
- Browser Back and Forward restore the exact beat and stable motion endpoint.
- A Read action returns to the exact source passage, not merely the Article
  top.
- Keep one real transcript in document order. Native find and selection must
  address the words the learner sees; do not create hidden duplicate prose.
- A find result outside the active beat should select that beat and land on a
  stable endpoint without replaying earlier motion.
- The compact embed uses the same semantic state and controls, omitting only
  Article-level navigation. Static and reduced-motion modes preserve every
  claim and endpoint.

## Bounded Implementation Shape

1. Derive the four Focus Deck beats from the current log-product semantic
   passage/state records. Do not duplicate the animation or create slide-only
   truth.
2. Add one local deck projection with intrinsic sizing, stable stage geometry,
   and a real transcript/source-return seam.
3. Add semantic Back/Next, keyboard navigation, direct URLs, and browser
   history restoration. Navigating a beat samples one deterministic state.
4. Keep scene navigation separate from the existing motion controls. Only the
   apply beat opens the motion gate.
5. Verify static truth, native find/selection, direct seek, reverse,
   interruption, reduced motion, light/dark themes, and a phone viewport with
   focused tests and one scoped visual sheet.
6. Stop for human review. Do not add `2^x = 7`, a shared component, a Markdown
   DSL, automatic deck generation, or flashcard UI in this slice.

## Observable Acceptance Criteria

1. The Focus Deck reuses the approved whole-equation asset, canonical
   log-product operation and endpoints, clock, Native KaTeX renderer, and
   semantic IDs without creating deck-local animation truth.
2. Each beat has one unambiguous attentional owner; contextual text stays
   readable without opacity blur or accumulating annotation.
3. Advancing from `product-law` to `apply-product-law` clearly starts motion;
   landing clearly ends it.
4. Back/Next never doubles as playback, and playback controls never navigate
   the lesson.
5. The current position is visible as both a semantic label and quiet ordinal.
6. Direct links, reload, Back/Forward, reverse, and reduced motion reach the
   correct endpoint without replaying intermediate states.
7. The source text remains searchable, selectable, and accessible as ordinary
   text; the deck does not replace it with canvas or duplicated hidden prose.
8. The frame is legible at phone width and embeddable without adopting a fixed
   presentation aspect ratio.
9. Existing paragraph, stacked, Catalogue, integration, and flashcard tests
   remain unchanged and green.

## Human Checkpoint Questions

- Does each advance feel like one coherent semantic act rather than a slide
  transition?
- Is the rule available at the moment it is needed without becoming permanent
  clutter?
- Is the start and end of the rewrite unmistakable?
- Can the learner move between deck, source passage, and a direct link without
  losing semantic position?
- Does the compact frame feel portable enough to embed, send, and combine with
  other Kinetic Figures?

## Implemented Navigation Refinement

The first visual audit replaced the four equal-width bottom tabs with a
scalable left Steps column. Previous and action-labelled Next controls now sit
prominently beneath the active prose, while replay and scrubbing remain a
separate local control group owned only by the motion beat. At phone width the
Steps column becomes a compact disclosure backed by the same semantic beat
IDs and searchable transcript. Product salience persists through the rule
matching beat instead of releasing before correspondence is established.

These choices remain exemplar-local pending this human checkpoint and the
longer `2^x = 7` pressure caller.
