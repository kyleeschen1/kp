# Semantic Material Motion And Performance Loop Closeout

Date: 2026-07-17
Status: complete
Run contract: `run-contract.kp.semantic-material-motion-performance-v0`

## Outcome

The approved 30-slice loop is complete. KP now treats equation animation as a
governed material system: semantic owners persist, operation-specific
choreography controls change, temporary fragments reconcile through explicit
bundles, and native KaTeX resumes ownership only after exact settlement. The
same contracts drive direct seek, rewind, reduced motion, inspection, and
constrained LLM authoring.

The final promotion matrix contains 18 cells: low, medium, and high complexity
fixtures crossed with full, balanced, and efficient quality and both pinned
Gestalt styles. Every cell preserves the same semantic identity, has compatible
style capabilities, and retains all semantic steps, witnesses, and duration.
The catalog-wide gate remains promoted across 23 required transformation types
without authorizing generic artifact replacement.

## Delivered System

- Initial animation construction is divided into lazy capability packs; Three.js
  is absent from the measured initial request set.
- Diagnostics publish at a bounded cadence, while equation geometry is measured
  into a cache before playback rather than read every animation frame.
- Render quality is frozen for a playback and reduces only surface effects, not
  semantic work. Static cost analysis requests a lower faithful tier or explicit
  pedagogical compression instead of silently dropping steps.
- Canonical operations are versioned, exactly pinned, and executable only
  through trusted primitives. LLM drafts may select operations, roles, lineage,
  salience, provenance, traversal, and epistemic status; they may not author
  coordinates, keyframes, renderer code, or unverified target mathematics.
- Linear solving uses persistent reflow, witnessed annihilation, and successor
  synthesis. The continuity presentation remains the default after the rejected
  experimental morph/cancel treatment was rolled back.
- Radical succession follows the normative opposite-corner transfer with
  independent fragments, one reconciliation bundle, and exact native handoff.
- Distribution uses exclusive fission ownership; factoring uses readiness-gated
  fusion. Dot products, matrix-vector products, and matrix-matrix products use
  semantic index order and work-proportional duration.
- Intentional invalid states are supported as provisional student branches or
  explicit historical replay. They cannot settle as trusted mathematics and
  their disclosure policy remains independent of animation quality.

## Honest Residual Debt

- Measured initial script transfer is 289.35 KB against the 250 KB product
  target. It is substantially below the stored regression baseline, but the
  target is not met and was not widened.
- The 6x-throttled matrix playback p95 is about 50 ms against the 33 ms product
  target. This is retained as explicit low-end-device work; semantic ordering,
  witnesses, duration, and correctness disclosure were not sacrificed to hide
  it.
- A single preflight geometry cache build and overlay measure may occur when
  constrained playback begins. The hot frame loop does not repeatedly measure
  layout, but the performance schema should eventually distinguish preflight
  from per-frame reads directly.
- Human perceptual review remains necessary for a genuinely new visual
  primitive, combination, or Gestalt style. Automated promotion establishes
  semantic and mechanical conformance, not aesthetic gold status.
- KP remains a governed animation compiler, not a general CAS, theorem prover,
  or trusted arbitrary-code renderer.
