# Equation Narrow-Core Iteration Economics Baseline

Date: 2026-08-16
Status: measured pre-refactor baseline for overnight slice `s02`

Stable command: `npm run measure:equation-iteration-economics`

## Result

The equation path is semantically governed but still expensive to extend. Its
14 preservation families currently traverse 39 authority source files and
16,725 source lines. Thirteen of those files contain 22 closed `switch` sites.
Some switches are legitimate closed execution; the following slices must
distinguish generated exhaustive dispatch from caller-specific core edits
rather than optimizing this count blindly.

Function wrapping currently has three direct motion-profile consumers and six
direct reception-plan consumers. That is the concrete symptom behind the
log-product regression: callers can still import parts of a visual word rather
than invoking one compiled motif boundary.

The repository test surface contains 1,333 TypeScript test/spec files and
210,607 lines under `tests/`. The diagnostic scanner finds 190 tests that read
production source and 26 catalogue/inventory/manifest tests with numeric
length assertions. These are candidates, not an automatic deletion list. A
test retires only when a stronger descriptor, generated closure, public
protocol, runtime property, or bundle assertion takes ownership of its promise.

There are 217 named test/check/verify/visual/performance/measure package
scripts. Verification-mode work should route a change to the smallest truthful
subset instead of making every script part of the inner loop.

## Compatibility Denominator

The existing 30 equation surfaces comprise:

- 23 generic compatibility rows and 7 specialized adapters;
- 5 rows with 8 non-semantic transitions;
- 23 rows retaining whole-equation fallback;
- 15 unique local sampler nodes; and
- zero private-clock or CSS-animation authority rows.

The shared-clock result is a preservation requirement. Later reductions must
come from singular authority and adjacent retirement, not by hiding work in a
new clock, eager chunk, or generic fallback.

## Measurement Boundary

The stable command derives equation authority from the existing cost plan,
scans repository-owned TypeScript/Svelte source, and writes full disposable
evidence to `tmp/codex/equation-iteration-economics.json`. Source-pattern
counts are migration diagnostics only. They must not become permanent
source-shape ratchets; slices `s20` and `s21` explicitly retire that testing
style when stronger owners exist.

## Targets

1. Same-family callers should add declarations and bindings without editing a
   handwritten core switch.
2. `function-wrap.v1` should become the only presentation entry point for its
   callers; renderer-specific geometry remains behind its adapter.
3. Every migrated family must delete its bypass and duplicate test authority
   beside the final caller.
4. Test and source-shape counts should fall only as a consequence of stronger
   invariant ownership.
5. Shared clock, semantic identity, native endpoints, lazy loading, and
   accessibility must remain unchanged.
