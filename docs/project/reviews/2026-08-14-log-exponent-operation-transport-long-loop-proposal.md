# Log, Exponent, And Operation-Transport Long-Loop Proposal

Date: 2026-08-14
Status: approved

## Objective

Build one canonical reversible exponent/log animation:

```text
2^x = 7
-> ln(2^x) = ln 7
-> x ln 2 = ln 7
-> x = ln 7 / ln 2
```

Then pressure it with
`ln x - ln y <-> ln(x / y)`. Only after both exemplars pass human
checkpoints may KP test a renderer-neutral operation-transport or homomorphism
witness through the bounded internal caller `T(u + v) = T(u) + T(v)`.

## Canonical Reference And Acceptance

The canonical reference is the native-KaTeX `2^x = 7` catalogue asset. It
passes only when logging both sides and extracting the exponent are visibly
distinct actions; `x` moves continuously from exponent to coefficient; both
log wrappers enter as one balanced operation; no semantic material fades
before reaching its destination; native KaTeX owns exact endpoints; and direct
seek, rewind, interruption, reduced motion, selection, and accessibility all
reach deterministic states.

The structurally different log-quotient caller must move `x` and `y` into
numerator and denominator roles, preserve one wrapper and causally retire the
other, avoid treating the minus glyph as identical to the fraction bar, and
reconstruct the difference exactly on rewind.

## Preservation Boundary

- Preserve all existing catalogue assets and the approved function-wrap,
  exponent, and radical behavior.
- Preserve one deterministic host clock, native settled KaTeX, direct seek and
  rewind, framework-neutral asset authority, lazy loading, accessibility, and
  current catalogue budgets.
- Keep each slice independently reversible. The canonical asset, quotient
  caller, linearity pressure caller, and any shared promotion are separate
  rollback units.

## Allowed Work

- Family-local typed operation specifications and domain assumptions.
- Semantic transformations, correspondence, lineage, lifecycle, salience,
  deterministic motion planning, pure sampling, and native-KaTeX ownership.
- Lazy catalogue assets, exact URLs, review capture, focused visual commands,
  tests, architecture evidence, and project memory.
- One bounded internal linearity caller after both mandatory human approvals.

## Disallowed Work

- A complete exponent/log curriculum, exponential/log graph reflection, full
  matrix or linear-map visualization, public lessons, layout work, LLM
  generation, SRS, authoring interfaces, Graph3D/WebGL, a new runtime or
  renderer, or catalogue-wide migration.
- A universal homomorphism abstraction without approved log exemplars and a
  successful structurally different linearity pressure caller.

Chromium and a stable repo-owned `visual:log-exponent` command at renderer

Commit each completed slice with its Theseus evidence. Retrieve brief context
by default and expand only for source-dependent implementation. Stop with
`HUMAN_CHECKPOINT` after s20 and s25; approval of this proposal does not waive
either visual checkpoint.

## Done Contract

The run is complete when the two log exemplars are approved and deterministic,
the bounded linearity caller either proves or rejects a shared
operation-transport seam, all accepted assets are directly selectable in the
catalogue, release verification passes, and project memory reports the result
without claiming broader curriculum or renderer support.
