Date: 2026-07-18
Status: approved by the accepted hermeneutic tutorial contract and the user's
explicit autonomous implementation boundary
Target: `next-action.kp.tutorial.ftc-gold-exemplar-v0`

## Goal

Build the smallest versioned tutorial kernel demanded by one real exemplar,
then use it to produce a reviewable FTC Part I module that synchronizes graph,
symbols, claims, narration, interaction, and accessibility on KP's existing
shared animation clock. Stop before gold promotion or reuse of new vocabulary
in another domain.

## Verification Cadence

- Focused unit tests after each contract or deterministic model slice.
- Typecheck whenever a public typed contract changes.
- Small browser cohorts only when visible or interactive behavior changes.
- Broad checkpoints after slices 15, 21, 25, and 26.
- Performance runs in isolation from heavy browser or unit jobs.
- Theseus validation and a focused commit after each verified slice.

## Stop Conditions

- Stop before `gold`, trusted publication, BFS, economics, physics, or general
  LLM/upload implementation.
- Stop if a compiler would need to invent a pedagogical relation absent from
  the claim graph.
- Stop if a renderer or scroll position becomes a second semantic clock.
- Stop if an intuition, finite approximation, or concrete example is presented
  as a formal proof or generic theorem without its scope label.
- Stop if accessibility or performance reduction removes causal phases,
  identities, evidence, or narration meaning.
- Stop if arbitrary function entry, learner modeling, gamification, voice
  synthesis, or universal scene infrastructure becomes necessary.

## Expected End State

KP will have a reviewable FTC module in both editor and learner surfaces. A
viewer can move `x`, adjust guided `Delta x`, scrub or rewind, isolate the added
strip, see finite error evidence and convergence, follow attention into the
difference quotient, and reintegrate the graph and equation as `A'(x)=f(x)`.
The module will expose inspectable claims, proof status, provenance, state,
cycles, correspondences, and promotion status, with deterministic accessible
and export projections. It will not yet be gold.
