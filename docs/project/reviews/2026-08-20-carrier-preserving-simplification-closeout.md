# Carrier-Preserving Simplification And Discovery Closeout

Status: complete
Completed: 2026-08-20
Run contract: `run-contract.kp.carrier-preserving-simplification-v4`

## Outcome

KP now distinguishes two visually and semantically different evaluation
families through one governed authoring path:

- **carrier-preserving simplification** keeps one proved semantic object while
  identity syntax yields; and
- **contributor fusion** combines multiple contributors into a new result.

The promoted carrier boundary is intentionally narrow. It covers the reviewed
`2 × 1 → 2` and `x + 0 = 4 → x = 4` callers, the
`carrier-preserving-simplification` family, the
`persistent-carrier-transfer` handoff, and the approved Native KaTeX profile.
Equal-looking glyphs do not establish identity, and no other evaluation family
was promoted.

Authors and tools can now discover equation operations without loading Svelte,
the DOM, or a renderer. One generated catalog supplies friendly names, aliases,
meaning, positive examples, counterexamples, required evidence, and support
state to the Coverage page and CLI. Ordered LaTeX states are narrowed by pure,
extensible rules before a model is involved.

The bounded model exchange receives only those deterministic candidates. Its
response may contain only a candidate alias per adjacency. KP canonicalizes the
choice, checks shortlist membership, and attaches code-owned evidence. Carrier
operations additionally require nominal verified carrier evidence. Invalid or
unavailable choices preserve the last valid plan and return typed clarification
instead of inventing animation authority.

## Mixed Benchmark

The durable benchmark covers three contrasting cases:

| Case | Eligible meaning | Selected family |
| --- | --- | --- |
| `x + 0 = 4 → x = 4` | additive identity removal | carrier preservation |
| `2 × 1 → 2` | identity removal or numeric evaluation | carrier preservation from instructional intent and proof |
| `2 × 3 → 6` | numeric evaluation | contributor fusion |

The middle case is important: syntax legitimately admits two operations. KP
does not pretend deterministic text comparison can choose the pedagogical
meaning. It narrows to the two verified possibilities, lets the bounded planner
choose by intent, and retains all evidence and presentation authority in code.
An attempted contributor-fusion choice for the add-zero adjacency fails closed
and retains the preceding valid plan.
