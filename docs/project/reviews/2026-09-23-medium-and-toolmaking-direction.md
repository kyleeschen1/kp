# Symbolic medium and nonprofit toolmaking

Status: user-stated mission clarification; product hypothesis under discussion
Date: 2026-09-23

## User direction and open questions

Kinetic Press is a nonprofit. The user's primary ambition is to create media
and tools for thought, and they do not expect to compete through a content
library. They are increasingly confident that the distinctive contribution is
semantically backed symbolic transformations/animations that can be inspected
and audited, with graphs and code as secondary products. Whether content is
the right product or audience entry point remains open.

Treat the mission as stated context and the proposed product focus as a serious
hypothesis, not established comparative novelty, adoption, or learning evidence.
This discussion authorizes no new implementation, removal of existing media,
contract cancellation, or automatic continuation through the mechanics review.

## Assessment from current evidence

The [mechanics exemplar](2026-09-23-mechanics-connected-argument.md) adds a
connected argument through two existing checked rails, retaining semantic and
renderer owners. Its remaining question is explanatory usefulness. More pages
of the same form would provide limited engineering information unless they
expose a distinct semantic operation, composition constraint, inspection need,
authoring failure, or consequential use case.

The [repeatability trial](2026-09-22-authoring-repeatability-closeout.md)
demonstrated application of two fraction variations after a shared repair; it
did not demonstrate broad cheap authoring. The mechanics publication also
required host integration. These results support testing marginal tool reuse
directly rather than treating additional authored pages as evidence of it.

Semantic correctness and visible motion are separate contributions. Inspection
should make identities, assumptions, reasons for a step, and the boundary of
validation recoverable. Motion should clarify a correspondence or transformation
that is harder to follow statically. Backing an animation with semantic data
does not by itself establish either benefit for its user.

## Recommended next decision, not an execution queue

Use a small set of reference artifacts to develop and explain the medium. Give
each additional page an explicit information goal; do not pursue content volume
as a default measure of progress. Preserve graph/code work as evidence and
possible consumers without requiring equal expansion across media.

| Candidate | Marginal information | Main cost or uncertainty | Recommendation |
|---|---|---|---|
| Another similar mechanics page | Low unless it pressures a new boundary | Editorial and review effort | Defer by default |
| Review the existing mechanics argument | Whether inspection contributes to a connected argument | Human judgment, not independent learning evidence | Use if helpful; no successor page implied |
| One existing symbolic artifact reused in another workflow | Portability, author effort, audit usefulness | Select a concrete user and workflow first | Strongest next experiment to scope |
| Broad SDK, editor, or new symbolic framework | Unclear before a consumer exposes requirements | High speculative implementation cost | Do not start from this discussion |

A bounded candidate is to take an existing supported derivation, change one
meaningful input or assumption, and produce a reusable inspected artifact in a
second host. Assess source work, engine intervention, recoverable justification,
and what semantic validation actually checks. Compare against its static steps.
This is a proposed experiment, not a claim that the current system already
provides a universal authoring, proof, or audit interface.

A nonprofit can seek impact through tools used in material authored elsewhere.
Possible forms include an embeddable derivation, an authoring tool, or a symbolic
workbench; no form or distribution channel is selected here. Sustainability,
maintenance, usability and adoption remain real constraints. This is local
project reasoning, not a competitive market survey.
