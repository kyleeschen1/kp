## Recommended loop sequence

### Loop 1: fraction pressure and narrow promotion

Use a common-denominator alignment such as
`1/3 + 1/6 -> 2/6 + 1/6` as the structurally different caller. It pressures a
selective equivalence operation inside persistent surrounding syntax rather
than replaying the approved isolated shape. Stop at its human checkpoint. If
approved, promote only the demonstrated shared fraction-fusion, product-
notation, identity, and arrival-cohort contracts.

### Loop 2: common-denominator fraction composition

Complete the first small fraction family: denominator alignment followed by
addition or subtraction, with contributor provenance, denominator conditions,
native fraction structure, direct seek/rewind, and no hidden arithmetic
evaluation. Expose every new operation through the governed authoring entrance
and typed repair path from the outset.

### Loop 3: expanded generation proof

Pressure the authoring goal directly: compile natural-language intents and
ordered LaTeX states that mix balanced operations, logarithms, and the new
fraction operations. Measure exact operation selection, verified-source
binding, first-pass success, repair rate, and silent fallback. Update Coverage
from named evidence rather than adding another dashboard abstraction.

### Loop 4: power, exponent, and root inversion

Build one reversible exemplar where inverse operations require explicit domain
or branch evidence, then a structurally different pressure caller. This tests
whether the compiler can preserve truth such as plus/minus branches and
absolute-value conditions instead of treating inverse notation as a glyph
rewrite.

### Loop 5: substitution, collection, and coalescence

Add one family for replacing a semantic object, collecting like terms, and
coalescing a common factor while preserving lineage. This should reuse the
existing distribution/factoring and contributor-fusion machinery rather than
introduce another motion path.

## Recommendation

Run Loop 1 next. It is the smallest step that converts the approved visual
result into evidence of reusable infrastructure. Do not batch all five loops
into one visual run: Loops 1, 2, and 4 each contain a meaningful choreography
checkpoint. Once Loop 3 passes, natural-language or LaTeX generation will have
been tested against a materially broader, compositional equation vocabulary.
