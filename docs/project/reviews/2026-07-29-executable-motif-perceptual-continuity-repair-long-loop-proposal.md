## Objective

Restore the architectural boundary promised by KP's governed semantic animation
grammar:

```text
verified semantic operation and total role binding
-> versioned executable motif program
-> motif-compatible perceptual continuity plan
-> one exhaustive canonical compositor adapter
-> exact native endpoint settlement
```

The repair must make a motif declaration operational rather than decorative,
make unintended blank or near-blank paint intervals invalid, and make the
animated-clone/native-DOM endpoint handoff observable and equivalent. It will
first restore one user-selected operation-evaluation reference, prove that the
same unchanged program renders `1 + 2 -> 3`, `5 + 2 -> 7`, and
`3/6 -> 1/2`, then migrate the exact-fraction symbolic fission, fusion, and
evaluation segments through executable programs without changing their
mathematics or concrete-view identities.

## Why This Loop Is Current

Slice 12 of the active presentation-compiler continuity repair was rejected
twice at human review:

- the exclusive `shared-zero-area-junction` makes outgoing and incoming paint
  simultaneously zero-sized, creating a perceptual blank pulse even though
  opacity remains one;
- successor-owned target glyphs bypass the existing dense typography-handoff
  microscope immediately before the exact native endpoint;
- the exact-fraction runtime validates `opaque-successor` and
  `operation-evaluation` labels, but both labels reach the same generic native
  successor sampler; and
- the revised browser gate explicitly ignored paint below four square pixels
  and checked travel rather than the required motif phases.

The result is a semantic-label/execution disconnect: types prove that a motif
name is legal without proving that its choreography executes. This is the same
general failure category as an animation reported `ported` from metadata while
its runtime presentation remains a fallback.

The active contract's stop condition has fired. Slices 13-22 must not run under
that contract. Its completed semantic, registry, lineage, continuity-diagnostic,
single-clock, and native-measurement work remains useful evidence; its
zero-area-only execution strategy and slice-12 candidate are not promotion
authority.

## Architectural Contract

### Executable Motif Programs

The bounded repair introduces a sealed renderer-neutral union for the
successor-backed families proved by this loop:

- `operation-evaluation`;
- `identity-fission`; and
- `identity-fusion`.

Each variant contains a version, named phase graph, allowed semantic roles,
material-lineage obligations, context-preservation contract, continuity
requirements, reduced/static behavior, and exact rewind expectations. It
contains no DOM, pixels, keyframes, authored paths, animation-local timing, or
notation text.

The presentation registry returns the verified semantic plan, executable motif
program, and continuity requirements as one inseparable compiled result. The
reader adapter exhaustively dispatches the union. A label without a supported
program becomes an explicit static checkpoint and can never be reported as
animated or ported.

### Perceptual Continuity

Paint continuity becomes a constraint selected under the executable motif. It
does not choose the motif's choreography.

The bounded candidate set is:

- target-style reverse FLIP using measured target paint;
- bounded co-presence at a certified semantic contact; and
- a visible motif-owned carrier when the selected reference requires one.

The comparison is generic and measurement-driven. `shared-zero-area-junction`
may remain valid only for a motif that explicitly declares intentional
vanishing. It cannot be the universal topology for evaluation, fission, or
fusion.

Perceptual continuity proves:

- a motif-specific minimum visible-ink floor;
- no unintended empty or near-empty frame interval;
- bounded adjacent-frame raster and geometry deltas;
- exact style, font, baseline, inner paint, rule, and silhouette authority at
  native endpoints;
- atomic owner transfer without a paint mismatch; and
- direction-, seek-, replay-, browser-, viewport-, and DPR-independent
  sampling.

### Honest Promotion

`ported` and promotion status derive from an evidence certificate containing:

- executable motif-program ID and version;
- exhaustive adapter route;
- phase/role conformance;
- perceptual-continuity result;
- endpoint-equivalence result;
- browser evidence; and
- human exemplar approval when required.

Names, catalog membership, static checkpoints, generic fallbacks, and semantic
plans without executable presentation are insufficient.

## Verification Cadence

- At slice starts, completions, commit boundaries, and every stop, run
  `npm run --silent loop:status`.
- Start each implementation slice with
  `npm run verify:impact -- --path <changed-path>` and run the returned focused
  gate before broader checks.
- Pure type/compiler slices run operation-presentation, architecture,
  inference, and type checks proportionate to their boundary.
- Rendering slices reuse stable repository-owned browser and visual commands;
  extend their committed entrypoints rather than using changing scratch
  scripts.
- The comparison and both exemplar checkpoints live in the existing Animation
  Library with Review capture.
- Broad suites run at adapter, endpoint, generalization, integration, and
  release boundaries rather than after every small pure slice.

## Stop Conditions

Stop immediately if:

- the historical canonical reference cannot be reproduced or the user does not
  select it;
- a motif label can reach animated or ported status without a minted executable
  program and exhaustive adapter route;
- continuity can change program phases, participant roles, or pedagogical
  choreography;
- evaluation, fission, or fusion requires an unintended blank/near-blank frame,
  generic fade, or whole-expression replacement;
- successor-owned clone/native paint cannot pass the endpoint microscope;
- a repair requires notation-, numeral-, lesson-, animation-, or
  viewport-specific renderer code;
- a new production renderer, compositor, runtime, clock, lifecycle, scheduler,
  display page, or WebGL lease is required;
- natural playback differs from seek or rewind, or browser/viewport/DPR
  behavior diverges;
- the selected motif cannot serve all three evaluation callers unchanged;
- exact fraction cannot migrate without changing mathematics, quantity
  identity, concrete-view phase truth, or accessibility;
- an exemplar checkpoint is rejected or unavailable;
- inference, performance, resource, architecture, build, production, or
  neighboring canonical motif gates regress; or
- unrelated user-owned work must be overwritten.

## Explicit Deferrals

- general migration of cancellation, distribution, factoring, substitution,
  radical, matrix, graph, code, or other motif families;
- new motif aesthetics beyond the three proved successor-backed variants;
- a new DOM/FLIP, SVG, canvas, or WebGL backend;
- global animation-library expansion beyond the named callers and exact
  fraction;
- problem-generator, LLM editorial protocol, and text-generation integration;
- economics, physics, arithmetic survey, matrix, graph, calculus, and broader
  curriculum exemplars; and
- unrelated repository pruning.
