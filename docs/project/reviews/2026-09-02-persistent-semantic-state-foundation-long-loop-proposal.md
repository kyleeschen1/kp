## Recommendation

Run the first of the accepted semantic-state long loops as a 30-slice,
nonvisual foundation tranche. It begins by restoring a trustworthy broad test
signal, completes the already accepted unit-scalar helper experiment, and
establishes exact-rational economics parity. Only after those gates pass does
it add executable identity laws and an explicit persistent snapshot kernel.

The loop stops before the typed proxy facade, lazy dependency evaluation,
`at(progress)` interpolation, aggregate timeline integration, Graph2D, KaTeX,
Article, Focus Deck, knowledge objects, procedures, macros, or LLM pressure.
Those remain later independently reviewed loops.

## Why This Loop Is Current

The accepted architecture depends on identity, version, role-binding, alias,
copy, snapshot, and branch behavior being exact before ergonomic proxy or
derived-value machinery can safely hide it. At the same time, the current
Theseus queue contains only the focused unit-scalar helper and reports
`thin-queue`; its refill preview offers older assumption checks rather than the
new accepted direction. No refill candidate has been selected.

This proposal turns the current focused prerequisites into bounded opening
phases of the first genuinely long architectural run. They are not inflated
into framework work: the ledger phase may change only stale expectations, the
helper phase may touch only one internal utility and its two callers, and the
economics phase must retain the exact-rational model as canonical authority.
Each phase has a hard evidence gate before the snapshot kernel begins.

Long mode is justified because the complete tranche crosses repository health
ledgers, typed-math authoring, two pressure callers, the economics-domain
boundary, semantic identity/provenance, scene recovery, TypeScript inference,
and production dependency constraints. Expected effort is approximately
12-20 agent hours, dominated by diagnosis and broad verification rather than
line count. This is an estimate, not a delivery promise.

## Canonical Boundaries

- **Semantic source of truth:** the exact-rational supply-tax contracts and
  model under `domains/economics/`, especially
  `per-unit-tax-welfare.ts` and `per-unit-tax-welfare-model.ts`.
- **Typed pressure callers:**
  `src/experiments/typed-linear-supply-demand/` and the isolated typed circle
  measurement caller used by `tests/typed-circle-measurement-pressure.test.ts`.
- **Existing identity authority:** `src/semantic/semantic-entity-provenance.ts`,
  `src/semantic/correspondence.ts`, and
  `src/semantic/semantic-scene-protocol.ts`.
- **Visible canonical reference:** the approved supply-tax Focus Deck card is
  preservation evidence only. This loop has no host, renderer, CSS, browser,
  or subjective visual scope.
- **Rollback unit:** one verified slice commit. The new internal snapshot
  kernel must be removable without reverting the promoted typed-math facade,
  canonical economics model, or any reviewed animation.

## Acceptance Contract

The loop is successful only if all of the following are true:

1. The complete repository test command passes after every stale ledger item
   is compared with its current canonical owner. No assertion or ceiling is
   weakened merely to obtain green output.
2. The unit-scalar helper either materially reduces the repeated market/circle
   plumbing while preserving inference and diagnostics, or is explicitly
   rejected and removed at its checkpoint. Its mathematical function and
   derivative rules remain caller-authored.
3. The typed market has an explicit parity adapter or shared formula boundary
   for baseline and seller-tax equilibrium, incidence, welfare, units, and
   semantic source identity. Exact-rational economics remains authoritative.
4. The state kernel distinguishes semantic entity, immutable version,
   aggregate snapshot, contextual role binding, state occurrence, author
   alias, display label, and representation.
5. `update`, shared `bind`, `bindCopy`, `introduce`, and `remove` have explicit
   immutable identity and lineage behavior. A derived binding can be declared
   read-only, but its lazy evaluator is deferred.
6. A transaction provides read-your-writes and commits atomically to one
   complete immutable snapshot plus an ordered diagnostic journal. The
   journal is not required to reconstruct a snapshot from genesis.
7. True aliases observe the same revised entity within one transaction;
   copies do not. Prior snapshots and branches remain pinned and unchanged.
8. Stable recovery handles resolve exact objects from any committed snapshot
   without consulting renderer nodes, DOM structure, browser time, or replay.
9. The kernel is internal, framework-neutral, tree-shakable, and bounded by a
   focused TypeScript inference budget. No public facade expansion occurs.
10. Focused, architecture, inference, typecheck, production bundle, complete
    test, and Theseus validation gates pass at closeout.

## Allowed Work

- Exact stale-test expectation and generated-manifest repairs proven against
  canonical production owners
- One internal `defineKpAuthoredUnitScalarMap` helper and only the market and
  circle pressure-caller migrations
- Focused authoring-burden and TypeScript-inference measurement
- An explicit adapter or shared formula boundary between the typed market and
  exact-rational supply-tax authority
- New internal semantic-state contracts, immutable storage, transactions,
  role bindings, change sets, recovery adapters, law tests, negative type
  fixtures, and bounded diagnostics
- Required architecture, bundle, inference, project-memory, and Theseus
  evidence

## Disallowed Work

- A public semantic-state API, global store, general event-sourcing framework,
  runtime `Proxy`, implicit assignment, or import-order registry
- Lazy derived-value evaluation, dependency tracking, cache invalidation,
  cycles, or `at(progress)` state families beyond reserving compatible
  internal contract vocabulary
- Animation, clock, timeline, URL, Article, Focus Deck, stage, renderer,
  Graph2D, KaTeX, CSS, or browser behavior
- Price-floor parity unless the canonical economics model separately adopts
  the typed caller's rationing assumption
- Derived-unit algebra, automatic differentiation, inferred units, inferred
  derivatives, inferred physical-domain predicates, or guessed law evidence
- First-class definitions, claims, procedures, formula packs, macro expansion,
  broad code generation, or LLM authoring
- A general CAS, theorem prover, ontology, HKT/typeclass hierarchy, or
  repository-wide directory rewrite

## Verification And Context Cadence

- **Focused:** run the named unit tests or type fixture plus inspect
  `npm run verify:impact -- --path <changed-path>` before executing its scoped
  recommendation.
- **Standard:** focused proof plus `npm run typecheck` and
  `theseus workspace validate`.
- **Broad:** standard proof plus applicable `npm run check:architecture`,
  `npm run check:inference`, `npm test`, and `npm run build:bundle` gates.
- Every completed slice records Theseus context and verification evidence and
  normally produces one exact-path commit containing implementation, tests,
  and its completed-slice event. A no-code classification still commits its
  durable evidence.
- Start each slice from one brief Theseus context capsule. Escalate to working
  context only when the brief packet cannot answer a source-dependent
  question. Do not reload the historical corpus.
- During execution, derive every progress heartbeat from
  `npm run --silent loop:status` when available and emit it at slice start,
  completion, commit boundaries, and before any stop.

## Contract-Level Stop Conditions

Stop the run immediately if:

- a ledger repair would loosen a ceiling, delete meaningful coverage, or
  change production behavior solely to satisfy a stale test;
- the unit-scalar helper must infer mathematical rules, units, bases,
  equalities, proofs, or physical-domain constraints;
- economics parity requires replacing exact-rational authority, creating a
  second production model, or changing the approved supply-tax artifact;
- entity identity is inferred from JavaScript reference, structural equality,
  glyph equality, renderer nodes, or slot names;
- committed snapshots can mutate, branches leak, partial transactions escape,
  or exact recovery requires replay;
- transaction statement order silently becomes animation or pedagogical
  ordering;
- implementation requires a global mutable registry, import-order authority,
  public proxy API, renderer/runtime dependency, or public facade expansion;
- local inference cannot be bounded without weakening nominal distinctions or
  raising an unrelated global ceiling;
- a new broad failure appears, an inherited failure changes shape, or the
  worktree contains overlapping unowned changes; or
- work would enter any explicitly deferred loop.
