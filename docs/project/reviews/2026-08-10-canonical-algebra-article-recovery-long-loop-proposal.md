## Objective

Generate the compact multi-step algebra article through the already approved
canonical fraction-composition reader animation. The article may select and
control named timeline ranges, but it may not construct a renderer or treat a
shared animation id as proof of presentation parity.

The rejected article implementation loaded
`animation.fraction-composition.two-thirds-solve` into a generic editor player.
That reused semantic data while bypassing the canonical reader descriptor,
structural anchors, certified stage layout, salience projection, native KaTeX
compositor session, and protected transit. This run removes that substitution,
extracts the real canonical stage as a chrome-free embeddable capability, and
makes both the canonical reader and article consume it.

## Canonical Reference And Acceptance

The reference host is `/reader/fraction-composition/`, registered as the sole
`canonical-host` representation for the animation. At identical semantic
samples, the article must expose the same active transformations, phase
progress, stage-layout certificate, salience projection, native endpoints,
protected-transit plan, and exclusive paint ownership.

The article must contain no generic editor animation player and no iframe. Its
transport may window the global clock over a named motion range without
rescaling or rebuilding the underlying animation. Direct seek, replay,
interruption, rewind, semantic focus, reduced motion, URL restoration, static
prose, server-rendered KaTeX, searchability, and no-JavaScript reading remain
intact. One retained live session moves between passages; inactive passages do
not own clocks or sampling loops.

## Scope

Allowed work is limited to the canonical equation reader session and its
fraction-composition descriptor, the algebra Article v1 presenter, range and
URL adapters, focused tests, stable visual evidence, architecture guards, and
durable project control. Preserve the semantic trace, evaluation tree,
animation asset, visual motifs, Article v1 grammar, canonical reader appearance,
economics, Lisp, editor work, and unrelated dirty files.

Disallowed work includes a new animation, a second renderer, iframe reuse,
Svelte state as animation authority, new layout discovery, visual redesign,
Article syntax changes, curriculum expansion, or catalogue-wide promotion.

## Rollback And Promotion

Independently reversible units are: rejection of the generic article presenter;
shared canonical-session extraction; canonical reader migration; first algebra
range binding; and five-range generalization. Durable Theseus evidence is not
rewritten when rejected application code is removed.

Slice 20 is a mandatory `HUMAN_CHECKPOINT`. Slices 21–24 remain locked until
the user approves direct side-by-side article/canonical behavior. Promotion
beyond algebra requires a separately approved second host.
