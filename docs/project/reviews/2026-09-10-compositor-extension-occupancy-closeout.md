## What is now true

plan sets—participates in one issued final scene. Its actual material sampler
supplies required measured paint and derived occupancy together. Inspection
includes ordinary routed tracks and extension paint after ownership partitioning.
The certified ink-knot evaluation's final optical transform occurs inside that
same sample, not in an uninspected post-render wrapper.

Types disallow the old supplemental callback at both construction boundaries.
Runtime authentication rejects copied assemblies, replacement samplers,
incomplete/duplicate participants and incompatible measured context. Geometry
and font invalidation use the existing host/cache boundaries. Native readiness
also counts contribution-owned motion, so identity-only motion cannot be
misclassified because its remaining ordinary tracks are static.

The accepted whole-compound factoring, compact arcs, fusion and ink-glyph
evaluation remain. No new mathematical family, editor, clock, collision
optimizer or universal rendering engine was introduced. This work makes
canonical reuse harder to bypass; it does not itself broaden authorable math.

## Hindsight and next direction

The loop was justified by a real cross-owner bypass, and the second mechanism
exposed why changing factoring alone was insufficient. It also found readiness
accounting that ignored successor-only motion, incomplete source-owner accounting,
and stale release inventories. Those are now explicit shared responsibilities
with regression tests, not per-equation exceptions.

It was expensive relative to visible authoring breadth: no new math capability
was added. The return must now be demonstrated as lower marginal authoring cost,
not assumed from infrastructure volume. Do not extend this repair indefinitely.

execution contract; the user selects the explanation. Broader chains,
assumptions/branches, symbolic–geometric work and later math families remain the
accepted horizon, not an automatically activated queue.
