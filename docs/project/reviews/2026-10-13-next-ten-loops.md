## Recommended order and bounded outcomes

1. **Compose a short elimination argument.** Connect the existing checked swap,
   scale and add operations to collection/expansion. Start with a short integer
   sequence that stays inside collection limits. Finish when two source-authored
   sequences share motion, retain actual derived referents and support seek,
   reversal and cancellation. This closes the gap between a repeatable workbench
   and the composed player's current single unit-addition boundary; no solver.
2. **Make zero rows meaningful.** Carry redundant and inconsistent results
   through collection and expansion, ending in ordinary `0 = 0` or a false
   equality. The workbench already handles these; collection rejects whole-zero
   rows. Finish with both outcomes, provenance and unchanged nonzero callers.
3. **Carry exact fractions through the whole explanation.** Reuse exact rational
   arithmetic already owned by row operations; extend collection presentation
   deliberately. Finish with a normalization and a signed fractional result,
   native endpoints and typed repairs outside the supported range. This removes
   a consequential restriction without creating another arithmetic engine.
4. **Make one step inspectable at two depths.** Offer a compact row-operation
   step and optional local arithmetic detail with exact return. Finish with
   identical checked endpoints and preserved surrounding context. This tests
   whether the medium supports experienced and unfamiliar readers without
   forcing everyone through every beat; no reader-layout redesign.
5. **Measure source-only authoring.** Give the existing packet several unseen,
   bounded examples and record renderer edits, repair quality, authoring effort
   and source size. Improve only repeated demonstrated friction. Finish with a
   reproducible authoring exercise and honest support boundary. This tests the
   toolmaking thesis more directly than another polished hand-authored demo.
6. **Pressure composition outside LA.** Use the existing governed algebra path
   for one distribution/collection explanation with local inspection. Finish
   with shared applicable lifecycle/attention behavior but domain-owned checking
   and typed gaps. This tests transfer without forcing algebra into matrix APIs
   or claiming Algebra I/II coverage.
7. **Connect row-dot and column-combination views.** Show the same small matrix
   product through both readings, maintaining correspondence to the same factors
   and result. Finish with one reversible exemplar and a source variation. This
   exercises the semantic object's explanatory value; it does not authorize a
   global alternate-representation renderer or resume all pouring refinements.
8. **Pressure a different matrix shape.** Choose one consequential third-row or
   rectangular caller, preserving matrix gestalt and ordinary resting notation.
   Finish with measured layout derived from shape and content and explicit
   bounds. This tests whether the current fixed-shape success generalizes without
   beginning arbitrary-size matrices or a universal constraint solver.
9. **Reduce multi-instance preparation cost.** Measure the composed player as
   well as the stage-only harness, then optimize the responsible preparation or
   dormant-instance boundary. Latest collection measurements retain 404 DOM
   elements per instance; ten identical mounts took 123 ms in one run, so repeat
   measurements before attributing causes. Finish with lower measured cost,
   unchanged paint/semantics, and verified disposal. No speculative global cache.
10. **Deliver one reusable explanation in a real document.** Place a composed LA
    explanation in an existing publication path with coherent static reading,
    optional inspection, exact return and repeated references. Finish with a
    second document reusing the source and bounded delivery cost. This tests the
    medium outside the experiment menu without reopening scroll-layout design.
