# Canonical Fraction Composition Promotion Long-Loop Proposal

Date: 2026-07-27
Status: approved in advance by user
Mode: long

## Objective

Promote the existing renderer-neutral fraction-composition pressure test into
one canonical, foldable learner animation for:

```text
2/3(x + 6) = 10
```

The animation must visibly carry the complete `2/3` fraction through
distribution, normalize the resulting numerators, compose the distributed
fraction terms, use verified reverse factoring where the trace requires it,
and finish the exact solve without renderer-owned algebra.

The canonical executable path remains:

```text
verified semantic trace
-> immutable fold projection and certified stage layout
-> canonical native-KaTeX renderer session
-> exact native settled DOM
```

## Why This Loop Is Current

The fraction-composition architecture checkpoint is complete, but it
intentionally added no product route or new visual realization. Meanwhile,
fraction split/merge is canonical and several fraction definitions or older
shared-player animations exist. Promoting the complete composition trace now
tests whether the released construction, folding, layout, motif, and reader
boundaries actually amortize new animations before KP opens the broader exact
quantity-model lane.

## Canonical Reference And Acceptance

- Semantic reference: the accepted 14-state `2/3(x+6)=10` pressure-test trace.
- Motion references: opaque fraction fan-out, fraction split/merge structural
  continuity, foldable distribution fan-out/collection, and native radical
  typography handoff.
- Product reference: the single lazy Animation Library host and fixed,
  functional Review capture launcher.

Promotion requires:

1. exact adjacent-state mathematics and complete semantic lineage;
2. whole-fraction fan-out with no denominator drift or glyph inference;
3. normalization, distributed-sum composition, and reverse factoring derived
   from verified semantic constructors;
4. persistent fraction structure stays opaque; structural fission/fusion never
   falls back to generic source-out/target-in fading;
5. multiplication and addition operators participate in their evaluation
   collapse rather than lingering until the endpoint;
6. expanded, collapsed, automatic, and pinned views project the same trace,
   result, dependencies, checkpoints, accessibility, and export truth;
7. native KaTeX owns every settled checkpoint and retains exact typography;
8. wide and phone presentations are centered, readable, unclipped, and free
   of unrelated visible-paint overlap;
9. play, direct seek, rewind, repeated scrub, resize, and font readiness are
   history-independent;
10. canonical promotion status is produced from evidence rather than an
    authorable `ported` boolean;
11. the product route has one exclusive canonical paint owner;
12. no compositor, runtime, clock, lifecycle category, scheduler category,
    notation-specific geometry, or second semantic artifact is added.

- No fraction-specific matcher, lifecycle, scheduler, route geometry, or CSS

- No whole-equation fade replacement as canonical presentation.

- No broad fraction-family, exact-quantity, matrix, graph, calculus, atlas,
  publication, or repository-wide type migration.
- No LLM-authored mathematics, DOM, pixels, arbitrary timing, or keyframes.
- No changes to pre-existing user-owned dirty roadmap, thread, decision,
  publication, or specification files.

## Preservation Boundary And Rollback

Preserve solve-x, fraction split/merge, radical succession, foldable
distribution, linear-equation, review capture, static/export, accessibility,
production isolation, route budgets, native settlement, one renderer-session
path, one shared clock, and the two-lease WebGL resource policy.

Rollback units:

- `s01-s06`: control, inventory, and proof-carrying semantic contracts;
- `s07-s10`: fold, endpoint, motif, and dry-run compilation;
- `s11-s15`: product route, layout, reader, seams, and library registration;
- `s16-s18`: behavioral, promotion, and human visual evidence;
- `s19-s20`: reviewed repair, release, and closeout.

The smallest visible rollback is the route/descriptor/library registration plus
its exemplar-specific compiler and tests. No completed canonical reader must be
rolled back with it.

## Verification Cadence

- Focused inner loops use the smallest exact semantic, type, compiler, or
  renderer test selected from changed paths.
- Standard boundaries add `npm run typecheck`, architecture checks where
  relevant, and `theseus workspace validate`.
- Broad boundaries use stable browser and visual commands, canonical
  construction/renderer/compositor checks, reader conformance, production
  isolation, and route budgets.
- Release uses the full test suite, typecheck, build, architecture, production
  closure, the approved visual matrix, and Theseus validation.

## Stop Conditions

Stop immediately if exact mathematics, semantic lineage, native typography,
accessibility, export truth, fold truth, or settled DOM authority changes; if
the port needs fraction-specific compositor geometry, a new lifecycle,
scheduler, runtime, clock, WebGL lease, or paint authority; if a type
certificate can be forged or consumed across stale evidence; if another
canonical exemplar regresses; if user-owned dirty files must be changed; or if
the `s18` visual checkpoint is not approved.
