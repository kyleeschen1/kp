# Post-Linear-Algebra Transformation Candidates

Date: 2026-08-02
Status: selection checkpoint; no implementation approved

## Current State

KP has promoted exact fraction quantity, place-value addition, economics
equilibrium, constant-force work-energy, and vector projection. The Svelte 5
catalogue shell is also complete. The matrix-to-linear-map exemplar reached a
reversible visual checkpoint, but its Pour language remains provisional and
linear algebra is now tabled as a distant learner target.

The useful replacement should be earlier pedagogically, visually legible in a
compact stage, and capable of exposing a genuinely different transformation
law. Scores are 1-5; higher authoring, reliability/demo, and reuse are better,
while lower risk is better.

## Recommendation

Prefer **place-value subtraction**, using `402 - 178 = 224`, if the aim is to
learn the most about KP's abstractions. It is early curriculum, reuses the
approved persistent-workspace environment, and pressures the existing exchange
model in reverse. Borrowing introduces dependency and provenance requirements
that addition did not prove, without requiring a new graph stack or advanced
mathematics.

Choose **fraction repartition and equivalence** if the immediate aim is rapid
catalogue breadth with low risk. Choose **function translation, scale, and
reflection** if the aim is a visually compelling graph exemplar using the
approved dimensional-continuity language. Choose **geometric dissection** if
the aim is to pressure a diagram-native transformation family rather than
another equation or graph.

## Transformation Families

The candidates fall into reusable families rather than subject silos:

1. **Preserve identity:** equivalence, repartition, unit conversion.
2. **Move and exchange:** regrouping, borrowing, carrying, transfer.
3. **Split and recombine:** distribution, factoring, partial products,
   dissection.
4. **Rescale:** ratios, rates, percent, unit-aware similarity.
5. **Move a parameterized shape:** translate, reflect, stretch, compress.
6. **Branch and rejoin:** signs, cases, roots, conditional paths.
7. **Refine:** finite approximations converge toward a limiting object.
8. **Accumulate:** local contributions build a persistent total.
9. **Coordinate views:** one state remains identical across symbols, graphs,
   diagrams, and tables.

This classification is the useful abstraction target. KP should still perfect
one exemplar before promoting any family-level motif or API.
