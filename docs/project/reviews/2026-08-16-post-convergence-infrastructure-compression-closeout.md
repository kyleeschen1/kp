Date: 2026-08-16
Status: complete

## Outcome

All 30 approved slices completed. The run proved the equation narrow core is
materially easier for deterministic tools to author against, replaced the last
selected-capability extension switch with typed declarations, split the two
largest mixed-ownership equation modules at demonstrated seams, reduced

redundancy whose complete reachability could be proved.

No visual timing, geometry, choreography, salience, layout, or semantic output
was intentionally changed. The next active work is therefore the already
bounded binary log-product human review, not another infrastructure tranche.

## Authoring And Extension Boundary

`src/authoring/compile-equation-intent.ts` is the narrow direct-import entrance
for governed equation requests. The tool-neutral command exposes the selected
surface vocabulary, accepts JSON/TypeScript intent, and returns either existing
compiled authority or a typed repair result. It does not own geometry, timing,
paint, rendering, or fallback behavior.

The three fixed pressure requests now pass on their first submission because a
tool can discover canonical object IDs and role bindings rather than guessing
aliases. This is a deterministic pipeline result, not yet evidence about live
model quality across vendors or prompts.

Capability loading is now open through immutable declarations and closed
through validation. Equation, graph, economics, Graph3D, programming, and
place-value capabilities retain literal dynamic-import factories and separate
domain packs; adding a declaration no longer requires editing a central
capability switch or eagerly importing every domain.

## Reachability, Pruning, And Tests

The generated reachability graph classifies compiler paths, fallback paths,
manifests, loaders, compatibility entries, and projections from exact roots.
It justified one deletion: the redundant saddle-denominator tween prototype.
The live saddle renderer, editor control, semantic intent, and Graph3D evidence
remain. A second deletion was explicitly deferred because no other candidate
had equally complete replacement evidence.

Manifest, projection, fixture, and test audits replaced stale count and
source-shape assertions only where a stronger exact-set, public-protocol,
runtime-law, generated-freshness, or bundle owner already existed. The run did
not treat test volume or line count as a deletion target.

## Final Economics Snapshot

`npm run measure:equation-iteration-economics` reports 40 authority files and
16,718 authority lines, compared with 39 and 16,906 at baseline. The extra
file count reflects explicit owners and the smaller line total reflects
extraction rather than feature removal. Closed-switch diagnostics remain 14
sites across 9 files because the metric includes legitimate generated-closed
execution; the selected-capability extension switch itself is gone. Private
clock and CSS-animation authority remain zero.

The test inventory is 1,363 files and 213,954 lines, with 200 source-inspection
tests, 27 aggregate ratchets, and 243 named verification scripts. Those totals
remain diagnostic denominators. The new `inner`, `boundary`, and `release`
commands make the truthful path discoverable without deleting useful scoped
aliases during this run.

## The “50k Types” Answer

KP never contained 50,000 unique handwritten types. TypeScript's `Types`
diagnostic counts compiler-internal type objects created while checking the
fixture project: standard-library types, literals, inferred anonymous
structures, unions and intersections, mapped and conditional results, and
generic specializations reachable through imports. An almost empty fixture in
the same compiler environment already creates 27,947 types. The final 52,864
types and 71,006 instantiations therefore measure compiler work, not the number
of concepts or declarations in KP.

## Decision

Close the infrastructure-compression contract. Keep future architecture work
triggered by a named measured blocker. Return to the binary log-product visual
checkpoint and preserve the three-factor and quotient variants as subsequent,
separately authorized pressure only if the binary choreography passes human
review.
