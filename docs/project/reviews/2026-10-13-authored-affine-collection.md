## Repairs and limitations

- Browser execution exposed an existing native-compositor error in both sources:
  semantic connector persistence was incorrectly enough to request a persistent
  horizontal paint axis for a minus becoming a plus. The adapter now compares
  observed paint keys before making that request. Missing observations still
  reach the strict missing-paint guard. Desktop browser regression covers both
  examples and forward/reverse/interrupted scrubbing of the new source.
- At 390px, both examples fail with `Equation stage sequence cannot change layout
  policy.` The phone intent uses two branch rows for distribution/products and
  one equation row thereafter; sequence alignment requires unchanged row roles.
  This is a pre-existing layout-contract incompatibility. No phone support or
  complete responsive certification is claimed. The failing browser cases remain
  executable, without skip or expected-failure annotations. Resolve separately
  by designing the row handoff or explicitly choosing a supported projection;
  do not remove the continuity guard or invent transit geometry here.
- Broad checking found an existing authoring import bypassing the kernel public
  API. The one-line import now uses that public export, with no behavior change.
- Regenerated exact reachability evidence retains all 68 roots and records the
  current file inventory and four previously absent distribute/collect test
  caller entries. This is deterministic inventory, not a raised cost baseline.
