# Catalogue Curation And Cross-Domain Promotion Closeout

Date: 2026-08-01
Status: complete
Contract: `run-contract.kp.catalogue-curation-cross-domain-promotion-v1`

## Outcome

The Animation Library is now one persistent, searchable review shell rather
than a collection of nested browsing surfaces. Ordinary selection changes the
focused artifact without a document reload. The selected animation remains
above the fold with a compact default transport, inline mathematical labels,
an expandable machinery boundary, and Review capture in the lower-left dock.
The approved solve-x exemplar establishes the centered compact equation stage
without forcing every animation family into the same composition.

The catalogue contains 35 concrete assets. Thirty-three paint natively, the
two programming rows expose one explicit missing adapter, no row uses an
iframe, and all rows load. Bounded curation records review evidence without
adding a visible ontology, card wall, or inferred human disposition. The
Jacobian/Hessian presentation remains a retirement candidate, but its unique
semantic and conformance evidence is deliberately retained.

## Promoted Cross-Domain Exemplars

Two exact, human-approved synchronized-model callers are promoted:

- `animation.economics.supply-demand-equilibrium-shift` synchronizes the
  supply-demand model, graph, equation, parameters, and narrative under direct
  seek and rewind;
- `animation.physics.constant-force-work-energy` synchronizes exact work and
  kinetic-energy truth across equation, force diagram, graph, units, and
  narrative without introducing a physics engine.

Together they promote the versioned `kp.graph.dimensional-continuity.v1`
language: warm orthographic 2D planes, sparse construction grids, role-based
line hierarchy, inline KaTeX for mathematical text, and fixed two-decimal
moving readouts over exact semantic values. Static ticks remain integers.
Domain equations, geometry, narrative, units, responsive composition, and
choreography remain local.

Consumer and producer surplus remain optional economics follow-ons.
Deadweight loss requires a distinct inefficiency model and was not smuggled
into the equilibrium exemplar.

## Consolidated API And Motif Boundary

The source-backed audit classifies stable authoring facades, internal platform
contracts, domain adapters, experimental surfaces, compatibility bridges, and
retirement candidates. It promotes only four two-caller seams:

1. reversible synchronized-model projection progress;
2. bounded integer query-parameter encoding with default omission;
3. fixed dimensional-continuity moving-number display policy; and
4. the versioned dimensional-continuity graph profile.

The extraction does not create a shared economics/physics model, parameter
registry, narrative engine, SVG presenter registry, universal renderer, or
universal motif registry. Four zero-caller rendering motif facades were
deleted; the canonical renderer-neutral equation motif vocabulary remains in
`src/animation/motifs/`.

Release authority is nominal and module-owned. The display catalogue can mark
the two exemplars `ported` only through the exact release certificate that
binds both animation identities, both human approvals, the four source-backed
shared contracts, and the graph-language version. A copied lookalike object
cannot mint release evidence.

## Deferred Scope

- The two programming catalogue rows still need the shared execution-trace
  adapter.
- The verified problem-to-animation bridge and deterministic explanation spine
  remain separately approval-gated platform work; full LLM editorial behavior
  is not playback authority.
- Broad catalogue disposition review, public-site presentation, curriculum,
  learner memory, publication expansion, and universal visualization systems
  remain outside this contract.
- API classification is complete, but internal implementation details are not
  frozen. Future promotion still requires caller evidence and a bounded
  migration or last-caller deletion.
