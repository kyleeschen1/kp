## Executed failure, not a theoretical concern

The opt-in integration was exercised on `/reader/fraction-composition/` through
the real canonical reader entry, not another distribution demo. Its reference
case passed; the authored case failed before creating its canonical session:

> distribution fraction-solve.step.distribute requires exactly one total fan-out ownership transfer.

The route already uses the source-native/material/target-native compositor.
The new candidate is **not** certified through that compositor: it failed at
operation presentation planning, so realized-paint continuity could not run.

The registered operation resolves to
`definition.generated.distribution.distribute-multiplication`. Adding this
definition reference is enough to select
`src/animation/distribution-factoring-presentation-plan.ts`, which requires
exactly one transfer. The canonical fractional factor instead has three
authored fan-outs: numerator, denominator, and fraction rule. The original
canonical transformation has no definition ID and does not enter this planner.
Therefore matching asset IDs, equations, correspondence, and timing were
insufficient to establish matching runtime dispatch.

Separately, the attempted development hook imported an experiment from
`src/reader/app/exemplar-entry.ts`. `check:architecture` correctly rejected
that application-to-experiment dependency inversion. Development-only flags
do not make the dependency direction acceptable.

The hook and its experiment entry were removed with a local patch. The reader
entry and canonical browser harness were restored exactly. No user files,
semantic infrastructure, renderer code, canonical lesson, or supply-tax source
were rolled back. The failed experiment is documented here and reduced to a
durable deterministic regression rather than retained as a broken route.

## Why execution stopped

The approved contract explicitly stops for missing canonical operation/motif
support and unsupported paint authority. This is that condition, discovered
by the native integration attempt. G0 remains accepted; G1 has not been reached.
Simplification and canonical supply-tax migration have not started. The
existing supply-tax page still uses its original source, while the separate
authoring-market preview retains the framework-backed economics path.

The long-loop ordering was useful: the structural caller exposed an actual
authority/presentation mismatch before canonical adoption. This is a bounded
integration problem, not evidence against immutable state or authoring-first
architecture. It does disprove the assumption that the registered scalar
distribution definition is immediately interchangeable with the canonical
multipart fraction presentation.
