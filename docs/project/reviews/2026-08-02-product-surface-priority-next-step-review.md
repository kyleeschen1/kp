# Product-Surface Priority Next-Step Review

Date: 2026-08-02
Status: accepted strategic order; no implementation contract active

## Current State

The internal catalogue audit and six-loop convergence tranche have supplied
the evidence that previously blocked product-surface planning: 36 concrete
assets paint natively without iframes, the default catalogue switches in one
persistent shell, selected capabilities load independently, the authoring API
has exact caller authority, the generated solve reaches catalogue and reader
hosts with a deterministic explanation spine, and route budgets are green.

Human review now leaves one small conditional correction. Vector projection is
approved except for an over-broad label attenuation radius around `B` that
fades a non-overlapping line. Generated solve is approved as the first gold
generated session. Graph3D and the programming trace remain useful internal
evidence rather than learner-product priorities.

The accepted long-term product direction adds an Internal Studio and Public
Web while retaining one framework-neutral semantic animation and authoring
engine. Scores are 1-5; higher authoring, reliability, and reuse are better,
while lower slice size and speculative risk are better.

## Recommendation

Keep the stable animation rank as the content spine and interleave only
evidence-producing platform gates. Close vector first. Then use the existing
catalogue—not a greenfield site—as the Svelte 5 exemplar. Require unchanged
asset/runtime truth, persistent navigation, Review draft lifecycle, selected
capability loading, production route budgets, and static/no-JavaScript output.

If that gate passes, pressure it with rank 6 before building editor
infrastructure. Rank 6 supplies a materially different matrix, indexed
evaluation, symbolic, and geometric caller, so a successful host is less likely
to be an accidental fit to the current catalogue.

Internal Studio follows because it proves the framework-neutral authoring
session that every later surface depends on. Public Web follows the portable
publication boundary and should begin with a mission page plus a small curated
lesson set rather than a public mirror of the internal catalogue. M4 and an
internal M5 candidate workflow then make editable or model-produced text safe
and reviewable. The Public Editor comes last and exposes only a constrained
projection of the proven authoring commands.

Ranks 7 and later retain their relative order. This review inserts platform
gates; it does not silently reorder derivative, integral, quadratic, or later
domain exemplars. A future execution proposal should keep each gate reversible
and return to a real content caller before promoting a shared boundary.

## Immediate Acceptance Contract

The next proposed implementation should contain only the vector correction and
checkpoint closeout. Its observable acceptance is:

- diagnose the actual label attenuation or exclusion mechanism;
- `B` no longer attenuates a line when its glyph and line do not overlap;
- true label-line collision protection remains intact;
- wide, narrow, midpoint, settlement, reduced-motion, and static SVG truth
  remain stable;
- the user can inspect the live checkpoint before promotion; and
- generated solve, Graph3D, and programming dispositions are recorded without
  expanding their implementation scope.

## Deferred Within This Direction

- repository-wide package relocation before two application consumers exist;
- public accounts, classrooms, learner memory, or full curriculum;
- arbitrary source execution or rank-23 BFS promotion;
- public model-authored text before M4, gold/negative evidence, and explicit
  human selection;
- a universal renderer, motif registry, or Svelte-owned animation clock;
- public publication of every internally hostable catalogue row.
