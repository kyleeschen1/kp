## Migration Guidance

For each remaining legacy animation:

1. bind every visible selector to authoritative lifecycle and lineage;
2. compile the five-phase envelope and operation-specific dependencies;
3. add salience, traversal, propagation, layout, and motif authorities;
4. realize motion through trusted deterministic primitives;
5. pin a compatible gestalt style and compile its accessibility family;
6. run automated quality, seek, rewind, browser, and human perceptual review;
7. replace the legacy warning only after the generated promotion gate passes.
