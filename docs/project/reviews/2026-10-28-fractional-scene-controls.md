# Fractional scene typography controls

User request: add sliders for scene experiments, lighten KaTeX, and use Gill
Sans for everything else. This is scoped to `/reader/solve-fractional-linear/`;
it is not a new typography default for other readers.

The local panel beneath the equation exposes math thinning (0–0.5px), math size
(14–32px base size), prose size (14–24px), and Reset. Initial settings are 0.12px
thinning, 19.2px math base size, and 17px prose. The panel is collapsible; settings
are temporary and reset on reload. Non-math text uses locally available Gill
Sans, then Gill Sans MT, Calibri or sans-serif. No font files are downloaded or
redistributed. KaTeX retains its native font families and mathematical metrics.

The bundled KaTeX faces have regular/bold weights, not a light face. Thinning
is therefore optical: a small stage-background-colored text stroke trims glyph
ink without changing layout. It is a local solid-background experiment, not
a general font-weight API. Fraction rules and SVG strokes are not text glyphs
and are not thinned by this control. Forced colors/print disable the treatment.

The viewport owns the current stroke, and descendants explicitly inherit it.
This is necessary because material clones snapshot computed styles and CSS
variables: simply reading a body custom property on each clone froze the old
slider value. Browser regression checks exercise existing clones while the
slider changes. Font-size adjustments invalidate canonical capture, clear
legacy material, and use the existing layout scheduler to remeasure. Prose
resizing restores the same semantic playhead through the existing scroll map.

Canonical artifact, semantic authority and registered animations remain the
fractional linear asset and existing mixed reader compositor. Rollback unit:
the route-local controls module/CSS and their loader. No motion parameters,
ownership rules or authoring contracts changed.
