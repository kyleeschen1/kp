## Boundary and execution

Reuse Article v1 semantic references, existing explanation spine/evaluation
structure, domain verified operations, flashcard projections, shared Focus Card
form and native renderer/clock. These are foundations to integrate, not a claim
that nested reasoning already exists. Keep bounded authoring-side records
internal. Distinguish verified evidence from editorial explanation. Preserve
revision, assumptions, semantic referents and return location during extraction.
Prompt answers and disclosure state never own semantic truth. Article v1 stays
frozen; an incompatible schema requirement stops for scope approval.

Canonical visual reference: accepted authored distribution Focus Card at
`/experiments/authoring-distribution-focus-card/`, through its prepared verified
fraction source and native fraction-composition session. New reasoning host is
isolated; no replacement of supply-tax or R1 host. Pin exact artifact, source,
renderer and host in s01 before visible edits; asset-ID equality is insufficient.

Each slice is one independently reversible commit with completed Theseus
evidence. Use brief tracked context per slice, working only when insufficient;
fixed context budgets, no agents, no redundant startup corpus. Scoped checks
inside slices, broad suites at actual integration and release boundaries.
F = focused tests; S = focused tests plus full typecheck and Theseus validation;
B = subsystem/integration checks plus relevant architecture/build/browser gates.
Theseus validation also follows every durable control mutation.

All slices stop for unresolved correctness, fixed-budget violation, new authority
or scope expansion. Repair ordinary in-scope failures without routine approvals.
No merge, deployment, budget increase, new renderer/clock, catalogue migration,
universal ontology/CAS, Article schema change, HTTP write endpoint, untrusted
execution, scheduler, accounts or unrelated subject expansion is authorized.
No external access/spending changes. Missing live-model access is an explicit
evidence gap, never fixture evidence described as a live run.
