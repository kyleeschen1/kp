## Address And Recovery Laws

| Case | Law |
| --- | --- |
| Settled address | Encodes only one generated boundary handle and resolves to the exact retained snapshot object. |
| In-transition member | Encodes one member handle plus canonical exact progress and samples from that member's adjacent settled boundaries. |
| In-transition cohort | Encodes one cohort handle plus canonical exact progress and overlays every declared independent driver over one shared before boundary. |
| Equivalent progress | Equivalent fractions normalize to the same address encoding, equality result, cache key, and transient dependency authority. |
| Direct/nonmonotonic access | Resolution is independent of prior address, direction, mutable cursor, wall time, duration, and cache history. |
| Historical local read | Returns an exact pinned old local value together with current aggregate authority without changing either. |
| Partial restore | Fails with typed guidance; one old object version cannot be spliced into a newer aggregate. |
| Branch continuation | Accepts only a settled source address, retains exact source chain/boundary/snapshot lineage, and creates a distinct immutable chain. |
| Ephemeral branch attempt | Fails closed; sampled state never becomes persistent branch authority. |
| Cache lifecycle | Cache population, reset, disposal, failure, and recreation cannot change equality, history, recovery, or current state. |
