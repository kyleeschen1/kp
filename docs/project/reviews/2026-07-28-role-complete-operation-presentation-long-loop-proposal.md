# Role-Complete Operation Presentation Long-Loop Proposal

Date: 2026-07-28
Status: proposed
Target: `next-action.kp.role-complete-operation-presentation-plans-v0`
Recommended mode: long

## Decision Requested

Approve one 24-slice migration that replaces independently optional equation
presentation hints with one required, role-complete, law-bearing presentation
plan on the canonical reader path. The loop first perfects additive and
multiplicative cancellation in the fraction-composition exemplar and stops for
human visual review. Only after that checkpoint passes does it generalize the
same plan boundary to existing evaluation, balanced-operation, distribution,
factoring, fission/fusion, and structural-succession bindings.

This is a reliability gate before further animation-library expansion. It does
not supersede the approved foldable-tree or domain-expansion sequence.

## Why This Is Current

Several regressions have shared one shape: semantic truth and a visual motif
label are present, but the executable renderer lacks complete participant
roles. The current reader transition plan can independently carry optional
motif, choreography, successor, factoring, and structural-succession fields.
Those fields can drift, and tests can certify the label without certifying the
motion. The latest compound cancellation evidence makes the gap concrete:
two-part cancellation works, while three- and four-selector cancellation
records flatten operands, signs, operators, and artifacts into one undirected
source set.

The durable repair belongs in the existing three-stage execution path:

```text
verified semantic trace
-> ephemeral role-complete presentation plan
-> canonical renderer
```

It must not create another animation runtime or another paint implementation.

## Objective

Make every canonical animated equation transformation resolve to exactly one
verified presentation-plan variant or one explicit static checkpoint. Plans
must classify all affected semantic entities, carry their causal and temporal
laws, and be the sole presentation input consumed by the canonical compositor.
Generated transformations must fail closed when the trusted compiler cannot
produce a complete plan.

## Canonical Exemplar

Animation:
`animation.fraction-composition.two-thirds-solve`

Required cancellation moments:

- additive inverse cancellation: the `+4` and `-4` term bundles follow
  opposing arcs, remain opaque until contact, and collapse together;
- multiplicative inverse cancellation: the outside factor `3` and denominator
  `3` follow opposing arcs while the multiplication operator participates in
  collapse without becoming an orbit operand;
- coefficient cancellation: the existing `2/2` result remains unchanged.

The same semantic animation, settled native KaTeX, accessibility tree, fold
projection, URL state, direct seek, rewind, review capture, and responsive
layouts are preservation requirements.

## Promotion Criteria

The exemplar checkpoint passes only when:

1. every affected selector belongs to exactly one typed presentation role;
2. each cancellation has exactly two verified inverse bundles;
3. orbit bundles use opposite paths to one measured contact;
4. operators and structural artifacts follow their declared collapse/removal
   roles and do not determine orbit direction;
5. cancellation material remains opaque until contact;
6. persistent material translates continuously;
7. source and target native endpoints remain exact;
8. direct seek and rewind are deterministic;
9. phone and wide layouts have no unintended overlap or overflow;
10. browser evidence samples actual owner geometry, not only data attributes;
11. the canonical path has no generic fade fallback;
12. the compositor adds no new lifecycle or operation-specific scheduling
    category.

## Preservation Boundary

- Preserve mathematical ASTs, derivation truth, correspondence provenance,
  semantic IDs, transform order, folding truth, and accessible narration.
- Preserve native KaTeX as settled typography and interaction authority.
- Preserve one canonical compositor and exclusive paint ownership.
- Preserve existing non-migrated compatibility coverage until its owning
  migration slice explicitly replaces it.
- Preserve current exact-version pins and bounded extension-pack policy.
- Preserve the compositor source-size and inference-complexity budgets.

## Explicit Exclusions

- No new algebra operation or pedagogical style.
- No redesign of the equation layout engine.
- No global animation-family rollout beyond the listed existing bindings.
- No LLM-authored DOM, pixel geometry, keyframes, or presentation roles.
- No glyph-equality or screen-position inference of semantic roles.
- No operation-specific compositor branch when the role vocabulary can express
  the behavior generically.
- No deletion of legacy coverage before its canonical replacement passes.

## Rollback Unit

Each slice is one focused commit. Before the exemplar checkpoint, the new plan
compiler is an adapter over the existing canonical session and can be reverted
without changing semantic assets. Each later migration retires its old optional
binding in the same commit that activates the required plan variant; a
migrated transition never paints through two implementations on one frame.

## Verification Cadence

- Focused slices: impacted unit/type tests selected through
  `npm run verify:impact -- --path <path>`.
- Standard boundaries: focused checks plus `npm run typecheck`,
  `npm run check:architecture`, and `npm run check:inference`.
- Exemplar checkpoint:
  `npm run test:browser:fraction-composition`,
  `npm run visual:fraction-composition-canonical`, and the new stable
  motif-fidelity command.
- Release: `npm test`, `npm run build`, all affected scoped browser commands,
  the visual matrix, performance/size budgets, and
  `theseus workspace validate`.

## Stop Conditions

Stop immediately when:

- the exemplar fails human review;
- the plan would require semantic inference from visual geometry;
- a new compositor, lifecycle category, or operation-specific scheduler is
  required;
- the canonical path would retain parallel paint implementations;
- type inference or compositor source-size budgets regress;
- direct seek, rewind, accessibility, or native endpoint authority regresses;
- generated inputs would need authority over selectors, roles, DOM, or paths;
- work expands to new operation semantics or a layout-engine redesign;
- durable evidence cannot be recorded or the Theseus workspace becomes
  invalid.

## Expected Learning

Determine whether one role-complete presentation-plan boundary can eliminate
the recurring class “correct semantic operation and motif label, incorrect
visible realization” while preserving open, exactly pinned extensions and the
single canonical native-KaTeX compositor.
