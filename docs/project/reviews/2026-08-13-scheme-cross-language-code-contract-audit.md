# Scheme cross-language code contract audit

Date: 2026-08-13  
Status: bounded adaptation approved by the active run contract  
Canonical Scheme artifact: factorial of 3 full evaluation

## Decision

Scheme validates the continuity laws but rejects the imperative-language
renderer shape. The factorial artifact may adapt the shared syntax-role and
settlement contracts. It must not adopt flat function-fragment projections,
TypeScript/Python token matching, their source theater, or their score and
geometry.

| Mechanism | Disposition | Exact boundary |
|---|---|---|
| Shared syntax roles and half-open offsets | `adapt` | Scheme atoms and delimiters map to paint roles; syntax-address occurrence IDs and delimiter ownership remain authoritative. |
| Complete fragment source projection | `reject` | Factorial checkpoints are evaluator-derived runtime material, not successive edits to flat source fragments. |
| Settlement order | `adapt` | Binding, branch, structural, and return motifs report the common causal phases without changing their samplers, paths, or timing. |
| Settlement exceptions | `adapt` | Only exact transition/material-scoped semantic deletion and reduced-motion endpoint jumps are authorized initially. |
| Evaluator trace and machine state | `preserve-specialized` | Build-time trace, environments, continuations, value lineage, and branch causality stay Scheme-owned. |
| Recursive S-expression choreography | `preserve-specialized` | Membranes, contents-before-parent folding, parent-before-contents expansion, waiting shells, binding arcs, and deepest-first return remain unchanged. |
| Native code ownership | `reuse` | Searchable native DOM remains accessible; transient overlays remain inert and text-free. |
| Imperative token theater | `reject` | Scheme expressions are not flattened into TypeScript/Python function snapshots or identified by glyph equality. |

## Observable preservation boundary

The following must remain byte- or behavior-equivalent through slices s27-s29:

- the canonical factorial source, occurrence IDs, delimiter IDs, trace, score,
  checkpoint IDs, and 30-second timing;
- lambda opening, argument-to-parameter binding arcs, occurrence propagation,
  branch selection, recursive collapse/expansion, waiting multiplication
  shells, base case, and deepest-first return;
- direct seek, rewind, responsive compaction, reduced-motion settled endpoints,
  searchable code, and the existing tutorial URLs; and
- one deterministic host clock with no evaluator, parser, or trace shipped as
  new browser authority.

## Authorized implementation order

1. Add a Scheme syntax adapter over the shared paint-only token protocol.
2. Add motif-local settlement adapters that validate common causal laws.
3. Keep renderer and choreography geometry local; expose only validated phase
   and native-owner evidence to the host.
4. Reuse the existing library host seam if the factorial artifact is not yet
   directly selectable there.

Any change to evaluator events, pedagogical beat order, visual trajectory,
timing, or recursive containment is outside this adaptation and must stop the
run rather than be hidden as consolidation.
