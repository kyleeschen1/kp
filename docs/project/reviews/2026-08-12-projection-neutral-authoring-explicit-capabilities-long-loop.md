Date: 2026-08-12
Status: complete

## Objective

Continue KP's convergence tranche after Animation Station retirement by making
whole-file Article editing independent of economics layout, separating the two
remaining scroll-layout implementations without selecting a winner, replacing
algebra's import-time choreography registration with explicit capability
inputs, and restoring an honest broad verification baseline.

## Verification Policy

- Focused checks for inventories, pure helpers, source maps, and typed tables.
- Standard checks add typecheck and Theseus validation for subsystem changes.
- Broad checks cover routing, persistence, package loading, rendering,
  production builds, and integration boundaries.
- Browser checks cover editor persistence, no-reload preview, route switching,
  responsive editor access, and remaining layout geometry.
- Existing broad failures must be classified before they can be treated as
  advisory. New unexplained failures stop the run.

## Commit Cadence And Rollback

Each numbered slice is independently verified and committed. A deletion lands
only after its replacement and reachability proof. Each commit is the default
rollback unit; capability deletion may be reverted without undoing Article
authoring work, and layout separation may be reverted without restoring
Animation Station.

## Preservation Boundary

- user-modified `content/lessons/economics-demand-shift.kp.md` and its generated
  publication;
- `kp.article.v1` grammar and versioned vignette imports;
- canonical economics and algebra semantic truth;
- deterministic clocks, direct seek, rewind, and native settled rendering;
- current visible layout appearance except exact preservation repairs required
  by dependency separation;
- continued availability of Inline Sticky and Two Columns; and
- unrelated untracked project documents.

## Disallowed Work

No new layout experiment, layout retirement, TypeScript or Python lesson,
Graph3D promotion, SvelteKit migration, compatibility-wide rewrite, curriculum
expansion, or aesthetic redesign. This contract records evidence for later
decisions; it does not make those decisions.

## Stop Conditions

Stop on unexplained semantic or visual regression, invalid historical
provenance, production bundle growth without a bounded reason, loss of static
or accessible truth, need for a second clock/runtime/editor, a required
subjective design choice, unsafe source persistence, or work outside the
approved preservation boundary.

## Done Contract

The loop is complete when economics has one projection-neutral whole-file
editor, scroll layouts no longer depend on one another accidentally, algebra
capabilities are explicit and import-order independent, Station stays retired,
release verification is honest, and the next convergence action is bounded by
fresh evidence.
