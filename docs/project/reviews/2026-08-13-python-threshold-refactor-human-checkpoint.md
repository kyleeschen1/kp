This is the mandatory second-caller checkpoint for the approved TypeScript
free-shipping refactor. It asks whether the same pedagogical motion survives a

## What to review

The Python vignette teaches the same novice-scale claim: two copies of
`total >= 50` can drift apart, while one named
`qualifies_for_free_shipping` rule keeps the price and message consistent.
The authored 14-second sequence is:

1. orient to the duplicated rule in the price and message functions;
2. introduce the helper as a real source location;
3. move both complete threshold expressions into that helper;
4. let the helper own the rule before either caller changes;
5. propagate the helper call to the price function;
6. propagate it to the message function; and
7. settle on one source of truth with unchanged results at 49, 50, and 75.

## Architecture delta

The second caller reuses the existing semantic asset, transformation,
correspondence, lineage, authored score, deterministic timeline, player,
programming pack, catalogue, stable URL, and review-capture seams. It adds:

- a build-only Python standard-library AST/token frontend that emits checked-in
  plain data and never executes learner source;
- Python-owned semantic identities, behavior proof, source projections,
  syntax roles, motion validation, and renderer;
- one native accessible source owner plus aria-hidden intermediate token
  theater; and
- one stable browser pressure command covering wide, phone, reduced motion,
  seek, rewind, accessibility, capture, layout shift, long tasks, and resource
  closure.

No package, browser parser, arbitrary execution path, clock, scheduler, stage
lifecycle, scene graph, semantic store, iframe, Canvas fallback, or SVG
fallback was added. The local renderer uses the shared context-specific HTML
text and attribute encoders rather than defining another `escapeHTML` helper.

The current programming capability registers its specialized adapters as one
lazy pack. Selecting that pack therefore fetches the Python caller alongside
the other programming adapters. This is a real post-checkpoint comparison
candidate, not an initial-page regression and not yet evidence for a broader
capability split.

## Recommendation and decision boundary

TypeScript artifact. If the semantic story, trajectories, source readability,
