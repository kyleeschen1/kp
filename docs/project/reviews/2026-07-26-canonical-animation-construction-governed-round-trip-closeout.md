# Canonical animation construction and governed round-trip closeout

Date: 2026-07-26
Outcome: PASS
Run contract:
`run-contract.kp.canonical-animation-construction-governed-round-trip-v1`

## Decision

KP now has one canonical semantic-to-renderer construction path for governed
equation animations and one exclusively migrated product exemplar: the
fraction split/merge reader. The path compiles verified semantic refs,
operations, roles, lineage, explanatory intent, composition, and checkpoints
into an immutable construction; presentation remains ephemeral; native KaTeX
DOM remains the settled semantic and typography authority.

This closes the implementation fork without pretending all historical
animations have already migrated. Existing non-migrated equation animations
remain compatibility and reference coverage. They are guidance and protected
behavior, not peer canonical destinations. Each future product transition must
move to the canonical session and bypass its superseded paint in one reviewed,
reversible unit.

## Architecture consequences

1. The durable animation path is canonical semantic trace, immutable
   construction, ephemeral presentation planning, and rendering—not multiple
   animation runtimes.
2. A provider can select verified meaning and pedagogical intent but cannot
   own mathematics, DOM, glyphs, layout, timing, typography, accessibility, or
   renderer state.
3. Native DOM is not an alternative renderer. It is the endpoint semantic,
   interaction, and typography authority used by the canonical session.
4. Native continuity, atom transit, and checkpoint settlement are internal
   capabilities of one renderer session, not public routing choices.
5. Composition retains every operation on the shared clock. Compression may
   shorten presentation but cannot hide semantic work.
6. Fixtures prove reuse; product promotion remains exemplar-by-exemplar and
   human-reviewed.
7. The general concept-authoring barrel stays small. Canonical-animation
   construction uses its dedicated public API so unrelated authoring and
   inference consumers do not pay for the cohort.

## LLM boundary

The governed model boundary accepts exact references to approved semantic
sources and operations plus explanation and composition intent. KP verifies the
math, roles, normal forms, laws, and lineage, then compiles presentation. Models
cannot emit unverified targets, LaTeX truth, DOM, HTML, selectors, glyph
matches, geometry, paths, keyframes, timing tables, CSS, fonts, accessibility
markup, export code, or renderer state.
