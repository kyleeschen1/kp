Date: 2026-08-02

## Why this loop is current

The integrated economics lesson proved continuous prose, a persistent graph,
semantic controls, and attention projection, but its crossing-triggered clock
does not remain synchronized with viewport motion and it cannot yet compose
multiple independently controlled animation steps. The user has accepted a
motion-block model, a second economics interpretation animation, local stage
composition motifs, semantic deep links, a progressively enhanced TOC and
scrubber, a stronger reading pointer, graph-plane label backings, and a low-JS
framework-neutral publication boundary.

This loop implements only that economics discovery exemplar and records the
standards it pressures. The approved decision is
`../decisions/2026-08-02-kp-motion-blocks-and-progressive-tutorial-navigation.md`.

## Canonical reference and boundaries

- **Reference:** the current economics tutorial, approved economics graph, and
  stable prose cadence.
- **Observable acceptance:** two stable local motion blocks, continuous
  viewport-derived progress, exact cumulative state, reversible stage
  composition, graph-plane labels, solid reading pointer, semantic deep links,
  usable pre-upgrade controls/navigation, and bounded performance.
- **Preservation:** exact economics model and asset, dimensional-continuity
  graph language, fixed moving-number display, persistent stage, phone dock,
  Review capture, exploration parameter, inline server-rendered KaTeX, and
  tabled matrix frontier.
- **Rollback:** every slice is an independently reversible commit; new motifs
  remain economics-local until a later approved second caller.
- **Promotion:** objective checks may continue through the full exemplar, but
  visual acceptance and any shared reader/motif promotion stop for human
  review after slice 28.

## Verification and cadence

Inner slices use the smallest affected unit or single-browser proof. Boundary
slices run the economics tutorial tests, Svelte/type checks, architecture and
promotion-memory gates. The final boundary includes:

- `npm run test:economics-demand-shift-tutorial`;
- `npm run visual:economics-demand-shift-tutorial`;
- the stable tutorial performance command created in slice 26;
- `npm run typecheck`;
- `npm run build`;
- `npm run check:architecture`;
- `npm run check:promotion-memory`;
- `npm test`;
- `git diff --check`; and
- `theseus workspace validate`.

## Explicit deferrals

- solve-x second-caller implementation and all shared-contract promotion;
- SvelteKit, Public Web, Internal Editor, and Public Editor;
- catalogue-wide motion blocks, TOC, scroll seeking, or component rollout;
- a universal scene graph, layout engine, or motif registry;
- consumer/producer-surplus and deadweight-loss instruction;
- client-side KaTeX compilation, live LLM prose, or runtime editorial calls;
- matrix/linear-algebra resumption or promotion-ledger reranking; and
- arbitrary-progress permanent URLs beyond an explicitly noncanonical review
  tool.

## Contract stop conditions

Stop on source-of-truth conflict, competing execution authority, unavoidable
overlap with user-owned unrelated files, exact economics disagreement,
nondeterministic cumulative state, scroll/manual discontinuity, required eager
heavy capability, widened performance target, framework ownership of semantic
truth, missing durable verification, or the final required human visual
checkpoint.
