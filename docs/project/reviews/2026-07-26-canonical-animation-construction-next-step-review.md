## Recommendation

Propose exactly one product exemplar for
`x^(1/2) -> sqrt(x)`-style radical succession. It is the strongest next test
because it combines ordinary glyphs, a structural rule, a radical path, an
index, and representational lineage while already passing the governed fixture
and compositor proof. The product loop should preserve the current semantic
asset and native reader DOM, migrate only one transition, and stop for
wide/phone and full/reduced visual review before any radical-family promotion.

The unit-exponent absorption exemplar is the recommended follower because it
tests elimination with less structural pressure. Distribution/factoring then
tests higher-cardinality composition and structured subtree authority.
Derivative/secant-to-tangent remains the first serious equation-plus-graph
bridge after those symbolic checkpoints.

This is a reviewed recommendation, not an approved run contract. No next-action
or implementation queue is created by this closeout.
