# Glyph compositor promotion long-loop proposal

Date: 2026-07-25

Status: approved

Theseus target: `workflow.kp.delivery`

## Objective

Resolve or precisely bound the final-frame jerk in the approved
`\frac{x}{2}+\frac{y}{2}\rightarrow\frac{x+y}{2}` full-scene compositor, then
test the same operation-neutral architecture on inverse fraction splitting,
radical/exponent representational succession, one real equation-reader card,
and one compressed compound transformation.

The loop must keep exact native KaTeX as settled visual and semantic authority.
It may add one generic material-to-native alignment correction if dense
endpoint evidence supports it. It may not add fraction, radical, operation, or
viewport exceptions.

## Why this loop is current

The completed full-scene fraction loop proved total paint-atom ownership,
semantic-constrained reconciliation, structural-rule motion, stateless direct
seek, reverse playback, inert material clones, and exact native endpoints. The
user approved the result and specifically retained one visible risk: a small
jerk at the final atomic handoff from material clones to native target DOM.

That risk is generic and can propagate to every notation family, so the
endpoint microscope is the bounded prerequisite. Inverse fraction splitting
then tests multiplicity and rule bifurcation without introducing a new
operation category. Radical succession tests genuinely different structural
ink. Only after those proofs may the loop place the compositor behind one real
reader card and one compound presentation.

## Canonical references and observable acceptance

1. Endpoint handoff: the approved “Merge equal native denominators” card on
   `/glyph-reconciliation-experiment.html`. Dense samples from 96% through
   100% must distinguish clone geometry from native-target settlement and
   either remove the visible jerk with one common correction or retain a
   measured bounded residual.
2. Inverse split: the existing governed fraction fan-out semantics for
   `\frac{x+y}{2}\rightarrow\frac{x}{2}+\frac{y}{2}`. One source denominator
   and rule must split into two target structures through the existing
   lifecycle vocabulary.
3. Radical succession: the existing governed exponent-radical semantics for
   `x^{1/2}\rightarrow\sqrt{x}`. Radical path/rule/index paint must be totally
   inventoried and reconciled without radical-specific compositor behavior.
4. Reader integration: one existing gold equation-reader card. Native
   accessibility, annotation, hover, Cloze, static-JS playback, and export
   seams must remain authoritative.
5. Compound presentation: one existing compound semantic trace, compressed
   into a readable multi-operation transformation with optional drill-down and
   no new lifecycle or scheduling category.

Promotion requires deterministic seek and rewind, exact finite endpoints,
one visible owner for every paint atom, generic lifecycle coverage, wide and
phone containment, and no regression in production closures or payload and
frame budgets.

## Preservation boundary

- Preserve canonical semantic trees, operation lineage, multiplicity,
  provenance, selectors, clocks, and reverse laws.
- Preserve native KaTeX as settled visual, interaction, accessibility, and
  export authority.
- Preserve cards, Cloze, branching data, hover, annotations, review inbox,
  static-JS execution, and optional headless compilation.
- Keep DOM handles, computed styles, paint rectangles, baselines, tracks,
  keyframes, and renderer plans ephemeral.
- Preserve existing solve-x, branch, crowded, fraction, radical, reader, and
  production behavior outside each explicitly named exemplar.
- Preserve all unrelated user-authored dirty-worktree changes.

## Rollback unit

Each slice is one independently reversible commit. Endpoint instrumentation,
one generic correction, each exemplar route, the reader adapter, and the
compound presentation remain separable. Reverting any promotion slice must not
remove the canonical semantic assets or the already approved fraction
compositor.

## Allowed work

- Stable dense endpoint capture and comparison tooling for the existing
  experiment route.
- Ephemeral clone/native paint rectangles, baselines, rule geometry, wrapper
  transforms, and computed-style fingerprints.
- At most one generic common alignment correction at the
  material-to-native handoff.
- Existing total scene observation, reconciliation, lifecycle, track, and
  sampler extensions that are notation- and operation-neutral.
- Only the inverse fraction split, exponent-to-radical succession, one reader
  card, and one compound trace exemplars.
- Focused unit/browser/visual/performance tooling, architecture ratchets,
  project-memory closeout, and Theseus evidence.

## Disallowed work

- Fraction-, radical-, operation-, viewport-, card-, or expression-specific
  offsets, timing, matchers, lifecycle categories, or schedulers.
- Durable renderer geometry, DOM state, computed styles, keyframes, or backend
  plans.
- Global reader, branch, crowded, radical-family, text, code, diagram, or
  production-family rollout.
- Semantic, accessibility, hover, focus, annotation, or Cloze authority on
  moving clones.
- Full Manim/video export, Python runtime, CAS, live LLM APIs, dynamic
  packages, curriculum expansion, or unrelated visual redesign.
- Changes to unrelated dirty-worktree project documents.

## Verification cadence

- Inspect `npm run verify:impact -- --path <changed-path>` before using its run
  mode.
- Use focused pure tests for telemetry, correlation, correction consensus,
  reconciliation, tracks, and scene composition.
- Add typecheck and `theseus workspace validate` at standard boundaries.
- Extend committed stable browser/visual entrypoints rather than introducing
  changing scratch-script approvals.
- Use real Chromium for paint/style observation, ownership, native settlement,
  accessibility, direct seek, rewind, and responsive checks.
- Run contact sheets and broad impacted/release gates at slices 10, 16, 22,
  25, and 28 rather than after every narrow helper.

## Hard stop conditions

1. Any fraction-, radical-, operation-, viewport-, expression-, or card-specific
   offset, matcher, lifecycle, track, or scheduler is required.
2. Clone/native identity depends on visual equality or DOM order instead of
   canonical reconciliation lineage.
3. The endpoint correction cannot be expressed as one bounded common
   scene-level correction, or it changes native DOM.
4. Any painted source or target atom remains implicit, unowned, duplicated, or
   unstable.
5. DOM nodes, computed styles, geometry, tracks, keyframes, or backend plans
   enter durable semantic or reader artifacts.
6. Moving clones become accessibility, hover, focus, annotation, Cloze, or
   export authority.
7. A promoted exemplar introduces a notation- or operation-specific lifecycle
   or scheduling category.
8. The retained endpoint residual grows beyond its measured bound or becomes a
   semantic/accessibility defect.
9. Performance, payload, accessibility, semantic, reader, review, production,
   static-JS, export, seek, rewind, or responsive checks regress.
10. Work broadens beyond the four named exemplars or touches unrelated dirty
    worktree changes.
11. A required automated or visual gate fails without one bounded generic
    correction.

## Done contract

The loop is complete only when all 28 slices have terminal states; the endpoint
jerk is either removed by one generic correction or retained with a precise
stable bound; inverse split and radical succession use only the existing
generic compositor vocabulary; one reader card and one compound presentation
are proven without semantic or export authority moving into clones; broad
release evidence passes; and remaining rollout work is explicitly deferred.

## Explicit deferrals

- Global equation-reader or production-family rollout.
- Branching and crowded-radical adoption beyond the one radical succession.
- Text, code, Lisp, diagram, and non-KaTeX compositor work.
- General compound-operation authoring or curriculum rollout.
- Full Manim/media export, Python runtime, CAS, live LLM APIs, dynamic
  packages, and unrelated platform work.
