# KP Project Recovery And Direction Next-Step Review

Date: 2026-08-11
Status: recommendation; no strategic pivot selected

## Why This Review Exists

The current algebra animation works, but repeated visual revisions and visible
regressions have made progress feel slower and less cumulative than the project
record suggests. That frustration is evidence about the development process:
KP has accumulated substantial semantic, runtime, publication, and authoring
capability, while the number of learner experiences that feel indisputably
finished remains small. The gap is real and should change how progress is
measured.

The immediate checkpoint feedback is narrower. The initial fraction
distribution has too much startup latency: low-amplitude anticipation occupies
the opening, the preview reflow appears to pause, and the visible branching
action arrives late. The next implementation loop should correct that one
profile and return to human review without reopening layout or architecture.

## What Is Already Durable

- Article v1 is frozen and supports complete searchable static publication,
  editing, saving, semantic references, and interactive projection.
- Fraction composition uses one canonical semantic trace, retained native
  KaTeX session, renderer, transport, and shared deterministic clock.
- Economics SVG and native KaTeX already share a framework-neutral salience
  seam without sharing renderer-specific paint or domain truth.
- The catalogue has a single persistent shell and a substantial set of real
  native assets rather than iframe representations.

These are meaningful foundations, but they do not substitute for a finished
learner-facing proof. The next phase should make visible completion and revision
speed first-class metrics.

## Recommended Recovery Sequence

1. **One bounded correction now.** Fix only the distribution's startup rhythm,
   preserving all semantic, renderer, endpoint, Article, layout, and clock
   boundaries. Stop at the current visual checkpoint.
2. **Finish one proof, not another platform layer.** If the revised motion is
   accepted, complete one compact algebra explanation whose success can be
   judged end to end: understandable prose, unmistakable focus, calm canonical
   motion, direct seeking, editing, review capture, and one portable projection.
3. **Measure iteration rather than infrastructure volume.** Track time from a
   human visual note to a reviewed correction, number of unexpected regressions,
   and whether a change is local to choreography data. A pacing note like this
   should become a small profile edit, not a renderer investigation.
4. **Use a recovery sprint only when evidence calls for it.** If another
   canonical behavior regresses, pause new visual work and audit exemplar
   preservation, timing visualization, review capture, and focused browser
   checks before adding content.
5. **Choose the next product proof deliberately.** After the algebra proof,
   either test content throughput with a small related lesson tranche or test
   portability with a reusable embed/card. Do not attempt both in the same loop.

## Reframe

The central thesis has not been disproved. The working canonical algebra
animation demonstrates that semantic identity, direct seek, native typography,
and explanation projections can coexist. The present difficulty is turning a
capable system into a small number of experiences with convincing editorial
finish. That is a narrower problem than inventing KP, but it requires stronger
scope discipline and a different definition of progress.

The healthiest near-term goal is not “build the curriculum” or “solve layout.”
It is: make one short explanation unmistakably good, make the next revision to
it cheap, and prove the same artifact survives one additional context.

- Curriculum expansion, public-site work, and a general presentation grammar
