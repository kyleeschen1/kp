## Outcome

from the existing governed semantic construction, uses the same descriptor-
selected canonical equation session as the fraction exemplar, and settles into
native KaTeX DOM. The user approved the repaired visual result.

```text

```

The older editor radical and unmigrated equation animations remain named
compatibility and reference evidence. They are not a second product default and
never paint alongside a migrated canonical transition.

## Generic Repairs Retained

The persistent endpoint jerk was traced to a generic paint-oracle mismatch, not
radical-specific geometry. The repair now:

- normalizes visible ink instead of comparing Range line boxes;
- keeps native KaTeX clones through the source-side typography handoff;
- captures with the loaded document font and inline-baseline calibration;
- gates the first canvas frame as well as the native endpoint;
- falls back to structural clones when an endpoint produces no valid paint;
- preserves solid structural succession without fission/fusion fading.

These contracts make the observed font swap and endpoint jump reproducibly
testable. They do not make visual defects mathematically impossible, but they
prevent the known failure class from silently passing the canonical browser
matrix.

## Resource Boundary

Structural WebGL sessions now acquire from a lazy two-context lease pool.
Sessions release leases at native endpoints and on disposal, waiters resume
when capacity returns, context loss frees the lease, and native DOM remains the
fallback when no slot is available. This bounds per-page WebGL pressure without
adding a compositor, lifecycle, scheduler, or notation-specific category.

## Promotion Cost Result

Fraction and radical readers now share one lesson-promotion compiler and one
descriptor factory. Lesson semantics, annotation authority, and content remain
lesson-owned.

The existing governed unit-exponent animation compiled through that kit in test
space with:

- no product route;
- zero canonical compositor-core changes;
- zero lifecycle or scheduler categories;
- zero notation-specific geometry;
- zero runtime artifacts;
- only focused proof and durable evidence.

That is the intended steady-state cost for another structurally supported
equation adoption. A future exemplar that exceeds it must identify a genuinely
missing generic invariant rather than accumulating a local motion recipe.

## Current Focus And Next Action

The next recommended product proposal is the already accepted foldable
distribution and like-term collection exemplar:

```text
3(x + 2) + 2(x - 1) -> 5x + 4
```

Its purpose is visible library expansion plus one new compositional pressure:
expanded, collapsed, automatic, and pinned presentations over the same
immutable transformation tree. It should reuse distribution one-to-many
lineage, collection many-to-one lineage, canonical timing, native settlement,
and the current compositor. Fold state must remain a deterministic projection,
not a second trace or runtime.

The next proposal should freeze one reviewed exemplar, the fold/disclosure
contract, non-crowding acceptance criteria, preservation boundary, and smallest
rollback unit. It should stop for visual review before generalizing folding or
collection across families. It is a proposal target, not implementation
authorization.
