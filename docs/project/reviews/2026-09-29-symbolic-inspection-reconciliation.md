# Symbolic inspection: authority reconciliation

The imported runtime handoff is a proposal corpus, not a replacement architecture.
This run implements only the approved inspection/reuse envelope.

| Requirement | Responsible existing boundary | Bounded work |
|---|---|---|
| Stable identity and occurrences | Asset objects/selectors; semantic entity provenance | Project existing addresses; never infer identity from text |
| Transformations and validity | Domain operation and transformation validators | Expose checks actually executed, separate from declared laws |
| Fan-out and reverse lookup | Rich correspondence map | Read-only occurrence queries; reverse lookup is not a reverse mathematical proof |
| Inspection and selection | Reader semantic focus, native selector bindings | One opt-in host; no second global selection store |
| Revision safety | Prepared source version pins | Bind evidence and selections to one immutable snapshot |
| Static escape | Existing native KaTeX endpoints | Rendering support never implies semantic execution support |
| Library and metadata | Existing object registry and operation specs | No new global registry or reinterpretation of vignette |
| Relations versus computation | Existing semantic-state derived graph | Inspection adds no recomputation edges |

Distribution's canonical operation records roles, source/target patterns,
factor-copy cardinality and lineage. `validateKpSemanticTransformation` checks
reference existence and lifecycle shapes. Neither is a general algebra proof.
Declared assumptions and law references must remain declarations unless their
owner provides executed evidence. Unknown conditions do not become permission
to execute an unsupported transformation.

The exact preview restorer rejects a changed serialized animation. Preserve
that boundary: inspect its restored artifact rather than relaxing it into a
general importer. A later source variation must use its responsible authoring
owner. Source provenance can identify an artifact and revision without claiming
that every selector has a richer entity provenance record.

Deferred: general context/ontology systems, Jacobian and induction fixtures,
generic matching or solving, library-wide backlinks, flashcards and LLM search.
Factoring pressure follows the mandatory human inspection review. The existing
mechanics explanation checkpoint remains independent and unaccepted.

canonical system vocabulary. This establishes owner candidates, not new

cadence uses `git diff --check` and Theseus validation rather than a full suite.
