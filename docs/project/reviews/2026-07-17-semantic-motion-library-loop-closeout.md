# Semantic Motion Animation Library Loop Closeout

Date: 2026-07-17
Status: complete
Run contract: `run-contract.kp.animation.semantic-motion-library-loop-v1`

## Outcome

The approved 28-slice loop is complete. It was the right loop in hindsight:
the largest quality gap was not a shortage of easing functions, but a shortage
of explicit semantic roles, material lineage, operation-specific choreography,
and catalog-wide promotion evidence. KP now treats symbolic parts as persistent
objects that focus, reflow, branch, travel, coalesce, change representation,
settle into native KaTeX, and release focus on one reversible clock.

The promotion gate covers 23 required transformation types across 17 concrete
animations and 26 transformation instances. All 29 operations exposed to the
constrained LLM authoring catalog have exact pack identity, role contracts,
trusted core compositions, transform types, and existing visual motifs. The
gate rejects a missing family, generic replacement, incomplete semantic token
motion, design-diagnostic issues, and broken seek/rewind laws.

## Delivered Improvements

- Nested animation scrolling has a measured catalog-wide invariant. Responsive
  native equation fitting preserves KaTeX metrics, glyph ink, shadows, and
  traveling tokens without whole-equation `transform: scale(...)` or clipping.
- Linear solves preserve equation invariants through preview, monotone reflow,
  independent operand travel, semantic change, native recognition, and focus
  release.
- Derivative power and sum rules, and antiderivative power rules, expose the
  originating exponent or operator as the source of coefficients, successor
  exponents, and termwise fan-out.
- Rational-exponent-to-radical succession retains independent fragments,
  transfers them on opposite-corner diagonal arcs, and reconciles through one
  material owner before native settlement.
- Distribution copies a persistent factor into addend products; factoring is
  its explicit fan-in inverse. Branch order and motion remain semantically
  authored rather than inferred from glyph proximity.
- Fractions and exponent laws now advertise operation-specific visual verbs:
  factor split, common-factor extraction, unit absorption, factor peeling, and
  unit-exponent absorption. Their dedicated causal clocks own the detailed
  phases while the shared token renderer supplies one compatible
  preview/change/outro envelope.
- Identity absorption and negative inequality scaling expose their causal
  operator and relation changes before native settlement.
- Dot products author products and partial sums in index order. Matrix-vector
  rows and matrix-matrix cells compose those persistent dot-product
  representations without whole-matrix scaling.
- Organic choreography remains a substitutable gestalt style, not a semantic
  requirement. Accessibility projections preserve causal phase order without
  requiring depth as meaning.
- The LLM v2 compiler resolves promoted semantic operations rather than motion
  instructions. Models can name pinned operations, roles, salience, lineage,
  provenance, and epistemic status; KP retains geometry, paths, timing, and
  renderer authority.

## What This Unlocks

- Student prompts can target a governed library of meaningful symbolic
  operations instead of asking a model to invent keyframes.
- Uploaded LaTeX steps can be aligned through explicit roles, lineage, and
  operation packs, then previewed through the same editor player.
- Code-explanation diagrams can use the same semantic scene, salience, and
  epistemic contracts while adding domain-specific operation packs.
- New canonical operations can be proposed, reviewed, conformance-tested, and
  promoted without widening the trusted renderer grammar or changing old exact
  pins.

## Residual Risks And Honest Boundaries

- The browser overflow audit reports 178 instances of visible KaTeX ink spill
  on equation objects. These are not nested scrollbars or clipped content, but
  they remain a useful regression signal for font and viewport changes.
- Some comparison and presentation assets still use whole-equation fallback
  behavior, including Jacobian/Hessian, FTC, Fourier, and programming-oriented
  comparisons. They were outside this approved operation-family cohort.
- The governed compiler boundary exists, but the live prompt/upload parser,
  model-provider integration, review UI, acceptance workflow, and project
  persistence pipeline are not implemented yet.
- Catalog promotion proves semantic contracts, deterministic sampling, and
  browser geometry. Human perceptual review remains necessary for genuinely
  novel generated derivations and for tuning organic stagger, arcs, and focus
  strength across devices.
- KP is not a general computer algebra system. It can compile registered
  operations and reject typed gaps; it does not prove arbitrary user-supplied
  equalities or silently authorize an unknown rewrite.

## Recommended Next Focus

Build the ingestion-and-review product proof on this promoted boundary:

1. accept a student prompt or uploaded LaTeX derivation;
2. ask the model for exact operation pins, role bindings, lineage, salience,
   provenance, and epistemic status only;
3. compile locally and return path-specific repair gaps;
4. preview the result in full, reduced, static, and narrated modes; and
5. require human acceptance before insertion or operation-pack promotion.

Use one valid multi-step derivation and one intentionally incorrect derivation
as the first acceptance cohort. That will exercise both semantic motion and
the already-supported invalid-state disclosure contract end to end.
