## What authors can now do

An author supplies ordinary bounded LaTeX, declared real scalar symbols and
editorial explanation. The owning distributive-law verifier checks the exact
ordered common-factor rewrite. A verified revision feeds the canonical native
factoring Focus Card, full/compact readings, prediction/reconstruction checks,
exact-position return and an immutable local static edition. Invalid edits retain
the last valid displayed revision; export uses that displayed revision, not an
unapplied draft.

The accepted primary is `ab+ac` → `a(b+c)`. The second problem, `2x+2y` →
`2(x+y)`, adds only source JSON: no production TypeScript, bespoke renderer,
caller-specific geometry or independent clock. Both have two stops and one
transition, continuous control and animated button/arrow navigation.

The canonical presentation binding now requires matching verified content,
revision and the complete operation plan. Its private authority and runtime
authentication prevent ordinary callers from substituting raw candidates,
serialized proof flags or unrelated choreography. Runtime and negative type
tests cover forgery and stale bindings. Actual compositor checks cover exercised
continuant paint, exclusive ownership, native/material seams and direct reversal;
these are stronger evidence than matching an asset ID or a synthetic frame law.
They do not certify every KaTeX mechanism or every mathematical family.

## Scope, hindsight and next useful milestone

This loop was worthwhile: the hard integration problem was not inventing another
factoring animation, but ensuring ordinary authored mathematics actually reached
the complete canonical presentation. Initial partial-mechanism reuse did not
preserve that presentation. The repaired typed binding, canonical timing and
cross-browser grouping reception now carry both callers; the second required no
renderer glue. The integration and verification cost was substantial relative
to the narrow mathematical result. The next milestone must demonstrate improved
marginal reuse, not justify another independent implementation.

Supported authoring remains one ordered two-product rewrite with declared
single-letter addends and a declared-letter or single-digit factor, including
zero. Multidigit/composite factors, reordered terms, general polynomial factoring,
functions, powers and broader algebra are not implicitly supported. Valid math
may still receive an explicit unsupported-presentation repair. Editorial prose is
not proof. Static editions contain reading/self-checks, not live animation;
immutable historical editions do not silently change with later shared templates.
No deployment, physical-device certification or learning-outcome claim occurred.

The next recommended proposal follows the already accepted composed-algebra
direction: preserve a compound factor through
`2(x+3)+3(x+3)` → `(2+3)(x+3)` → `5(x+3)`. First expose the compound-factor and
grouped-paint gap through the same authenticated pipeline, then compose factoring
with canonical evaluation and preserve checkpoints, readings, extraction and
practice across the chain. Pressure a second structurally different chain before
promotion. Prefer this to more hand-built single-step examples or a universal CAS.
Later assumptions/branches and symbolic–geometric explanations remain ordered
horizon work, not authority to expand this release.
