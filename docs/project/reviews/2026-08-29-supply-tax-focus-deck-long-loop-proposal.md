# Supply-Tax Focus Deck Long-Loop Proposal

Status: approved 2026-08-29
Target: `workflow.kp.delivery`

## Objective

Build one bounded, document-backed Focus Deck at
`/experiments/kinetic-figure/supply-tax/` that explains how imposing a
positive per-unit tax from an initial zero-tax equilibrium shifts the
buyer-facing supply schedule, creates a buyer/seller price wedge, lowers
quantity, redistributes consumer and producer surplus into government revenue,
and leaves deadweight loss.

The exemplar tests a semantic-snap interaction: the learner navigates stable,
addressable attentional beats while the existing continuous reader clock owns
the deterministic interpolation between adjacent endpoints. Rapid repeated
navigation may compress transit and distant jumps restore a settled endpoint,
but neither creates a second clock nor makes an intermediate frame semantic
authority.

## Canonical Boundary

- Artifact: a new bounded per-unit-tax economics animation asset and vignette
- Host: the Focus Deck experiment route at
  `/experiments/kinetic-figure/supply-tax/`
- Renderer: native SVG graph with KaTeX labels
- Semantic source: a new exact-rational economics tax-and-welfare model under
  `domains/economics/`
- Article source: one `kp.article.v1` Markdown document whose prose is emitted
  exactly once as searchable semantic HTML
- Acceptance: exact taxed equilibrium and welfare laws; eight stable beats;
  adjacent forward/reverse transit; rapid-repeat coalescing; direct distant
  seek; native-find-to-beat restoration; reduced-motion and phone behavior;
  one scoped visual contact sheet
- Preservation: existing demand-shift semantics and routes, log-product and
  delta-epsilon Focus Decks, the integration Rule Application checkpoint,
  shared clock authority, Article v1, and unrelated worktree changes
- Rollback: one exact-path commit per verified slice; the new model, asset,
  Article, route, renderer, tests, and additive registrations remain removable
- Promotion: stop at the completed tax exemplar's human visual checkpoint.
  Shared Focus Deck extraction, a generalized welfare renderer, and catalogue
  rollout remain separate decisions.

## Allowed Work

- Exact-rational tax equilibrium and welfare truth
- Semantic objects, correspondence, lineage, sampled frames, and one bounded
  animation asset
- One eight-beat pedagogical score and Article-backed Focus Deck projection
- Native SVG, KaTeX labels, semantic salience, and the existing reader clock
- Adjacent, reverse, replay, rapid-repeat, distant-seek, URL, native-find,
  reduced-motion, accessibility, responsive, and visual evidence
- Additive route, package script, test, and project-memory updates required by
  the exemplar

## Disallowed Work

- Destructive changes to the existing demand-shift model or lesson
- A shared Focus Deck component or promoted Context/Inspect lens
- A generalized Graph2D, tax, welfare, or surplus authoring grammar
- Positive-tax-to-higher-tax scenarios, nonlinear curves, elasticity,
  incidence controls, sliders, calculators, or arbitrary tax models
- Custom search, duplicate hidden prose, or a deck-local animation clock
- Changes to the log-product, delta-epsilon, integration, gallery, flashcard,
  Graph3D, or code exemplars except bounded preservation tests
- Broad cross-browser release certification before the visual checkpoint

## Stop Conditions

Stop if exact market-clearing or welfare identities fail; if graph geometry
must become economic truth; if original supply cannot remain available as
marginal-cost evidence; if direct seek must replay history; if rapid
navigation creates half-states; if native find requires duplicate hidden
prose or custom interception; if the work requires a shared deck component,
new clock, destructive demand-shift migration, or unrelated dirty-file
ownership; or when the final human visual checkpoint is reached.
