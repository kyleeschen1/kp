# Regression Family Classification

Date: 2026-08-12  
Scope: durable evidence from the algebra Article recovery, Scheme factorial
exemplar, shared fraction host, recent convergence work, and current catalogue
settlement failure.

## Finding

Recent failures do not support the claim that KP is simply too large to evolve.
They cluster into five repeatable contract failures. The repo already contains
most of the right semantic and runtime machinery; regressions occur when a new
caller selects a nearby representation, infers identity from appearance, or
adds lifecycle work outside the canonical authority.

## Systemic Causes

1. **Identity is overloaded.** Asset ID, semantic transformation identity,
   canonical host identity, visual material identity, and renderer instance
   identity are distinct. Bugs appear when one is accepted as evidence for
   another.
2. **Nearby APIs remain selectable.** A fresh caller can still find generic
   players, metadata recipes, internal modules, and compatibility decoders that
   appear plausible. Guidance alone cannot reliably disambiguate them.
3. **Tests sometimes certify a substrate as if they certified an experience.**
   Typed traces and deterministic clocks are durable truth, but cannot approve
   a motif or layout. Conversely, visual tests should not rediscover semantic
   or ownership rules that can fail at compile time.
4. **Lifecycle ownership is less visible than semantic ownership.** Async
   capability settlement, observers, stage measurement, and host mounting can
   mutate geometry even when the semantic sampler remains pure.

## Required Gate Shape

- Use types and architecture checks for authority, identity, representation,
  serialization, and forbidden fallback.
- Use focused unit tests for pure sampling, direct seek, reverse, terminal
  dispositions, and typed failure.
- Use one browser exemplar for native settlement, reservation, paint ownership,
  accessibility, and lifecycle.
- Use human review early for communication, pacing, salience, and choreography;
  only then promote a motif to shared infrastructure.
- Make the canonical authoring facade and representation registry easier to
  discover than internal alternatives, and reject obsolete paths rather than
  relying on prose warnings.

## Consequence For This Loop

The remaining slices should not attempt broad simplification. They should make
the distinctions above executable: one extension path, explicit authorities,
complete compatibility evidence, reserved settlement, typed presentation
profiles, public-seam ratchets, and fresh-model generation tests. If those
gates hold, repository size becomes a manageable vocabulary cost instead of an
ambiguity multiplier.
