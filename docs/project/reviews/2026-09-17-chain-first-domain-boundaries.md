# Cross-domain authoring boundaries

The fraction chain extends one algebra-owned task. Existing Bayes and mechanics
authorities remain distinct; no shared equation parser grants them mathematics.

| Domain | Existing entry / accepted evidence | Rejected pressure | Remaining gap |
| --- | --- | --- | --- |
| Algebra | `author:check` task `equation.fraction-chain`; exact written rational adjacencies | Bayes/physics source, symbolic assumptions, missing steps | Arbitrary algebra and broad visual certification |
| Binary probability | `author:check` task `bayes.binary`; retained prior `1/3`, likelihoods `1/4,3/4` | Prior `4/3`, impossible condition with both likelihoods zero, foreign-domain source | General probability-model inference; equation chains do not establish model assumptions |
| Mechanics | Existing `checkMomentumEnergyDerivation`; positive mass, Euclidean velocity vector, momentum defined as mass times velocity | Merely real mass, scalar velocity, independent momentum and foreign-domain source | No mechanics task in current `author:check` inventory; no arbitrary physical-model inference |

The plan anticipated an existing mechanics discovery task. Inspection found the
checker and host, but no such task. The probe uses that real checker and proves
an invented `mechanics.momentum-energy` task fails before reading source. It does
not add a new task, silently route through algebra or label this absent seam
implemented. Mechanics retains `physics.derivation.unsupported-source` and its
field paths. Bayes retains its own diagnostics and algebra its fraction repairs.

`tests/fraction-chain-domain-boundaries.test.ts` executes these boundaries through
the existing entrypoints. The broader `tests/authoring-entrypoint-hardening.test.ts`
also pressures every listed task against every other task's example. No renderer,
domain engine or new model assumption was changed in this slice. Economics and
programming coverage remain the existing separate tasks; these probes do not
certify their curricula or offer cross-subject inference parity.
