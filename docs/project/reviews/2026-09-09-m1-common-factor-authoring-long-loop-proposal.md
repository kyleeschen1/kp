## Outcome and why now

Make one ordinary algebra deduction authorable, verifiable, animated and reusable:
`ab + ac` → `a(b + c)`, with explicitly declared real scalar symbols. An author
edits the source, receives located repairs for invalid steps, applies a verified
revision, and obtains a Focus Card, reading, bounded practice and local static
edition from that revision. After one combined editorial/visual approval, prove
reuse with `2x + 2y` → `2(x + y)`, not another hand-built renderer.

This is M1a, not completion of the algebra/precalculus family. R1–R4B are complete;
R4B proved source-owned explanation reuse in Bayes. The next useful pressure is
whether the math authoring frontend can connect notation, actual semantic proof
and existing motion without confusing a plausible operation label with authority.

Evidence inspected for this proposal:

- `2026-09-09-authored-explanation-coherence-closeout.md`: recorded positive,
  invalid and unsupported-notation compiler probes. Explicit-star invalid
  factorizations also produced compiled candidates; this did not exercise or
  establish acceptance by downstream verified rendering or publication.
- `src/authoring/equation-series-governed-authoring-registry.ts`: validators exist
  for both-sides, logarithm-base and fraction families, but not common factoring.
- `src/authoring/equation-series-governed-source.ts`: evidence selection explicitly
  does not mint proof; family validators must authenticate their contracts.
- `src/experiments/reusable-reasoning/equation-author-check.ts`: the current
  equation-reasoning checker compiles against a distribution projection. Factoring
  cannot honestly be advertised as source-only reuse of that host today.

The high-value change is a verified authoring path, not a new factoring animation
engine. Existing distribution/factoring operation declarations and presentation
mechanisms are dependencies to inspect and reuse, not certification by name.

Alternative priorities: a catalog-wide algebra rollout has more coverage but
would multiply unproven integration; another Bayes lesson offers lower risk but
little new boundary evidence; a universal parser/CAS has disproportionate scope.
The bounded common-factor path best combines author value, reusable authority,
regression protection and a visible deliverable.

## Scope and boundaries

Long mode, 24 independently verifiable slices, likely many hours across approval
boundaries. Planning allowance roughly 8–16 active hours, not a time guarantee;
the highest uncertainty is reusing the actual compositor and revisioned reading
host without a broad migration.

Allow one closed two-product/common-factor operation over declared real scalars
and exact supported numeric coefficients. Preserve factor/addend order and stable
occurrence identity. Establish truth by the owning distributive-law machinery;
do not use floating-point sampling, rendered-string equality or authored law IDs
as proof. Factoring does not divide by the factor and must not require it nonzero.

Support only demonstrated ordinary LaTeX: declared single-letter symbols,
numeric coefficients, addition, parentheses and explicit multiplication notation.
Retain original source spelling separately from normalized semantics. Do not
globally reinterpret multi-letter identifiers or function application. Ambiguous,
unsupported and mathematically invalid inputs return distinct located repairs.

Reuse the equation-series frontend, governed-source seam, existing domain proof
owner, Article/projection ownership, native KaTeX compositor, shared Focus Card
scaffold and semantic input. A narrow versioned/discriminated factoring source
and host adapter are allowed where existing distribution-only contracts cannot
represent the task. Do not widen the old source in place or mislabel factoring as
distribution. Keep existing callers and their byte/revision contracts intact.

Proposed visible host: an opt-in factoring selection within
`http://localhost:8000/experiments/reusable-reasoning/`, preserving its default
equation/code examples. This is a target, not a claim that it already exists.
Before visible edits, s01 must record the exact existing artifact IDs and actual
renderer path; s12 introduces a distinct factoring artifact ID, not an alias of
the distribution asset. Semantic truth is a verified factoring derivation and its
revision, not the host, KaTeX markup or an explicit-request candidate.

Primary acceptance: understandable common-factor convergence into exact native
`a(b+c)`, clear two-endpoint navigation (two stops, one transition), continuous
forward/reverse gesture control, visible button/arrow motion, immediate coherent
position indication, no duplicate ink ownership, and consistent explanation and
answers. No invented extra teaching stops solely to make a longer animation.

Preservation: tax, code, Bayes, existing equation reasoning, fonts, passage layout,
input behavior, v1 publication and semantic authority. Reuse existing motion
language; do not introduce salience treatments or tune global motion curves.
The smallest visual rollback unit is the opt-in factoring adapter/source commit;
presentation rollback must not undo verified semantic protections.

## Execution agreement

One focused commit per completed slice, implementation and Theseus receipts
together. The reviewed proposal owns rationale; the approved Theseus contract
will own exact order, progress and evidence. No duplicate phase-plan tree.
Use brief context receipts, escalate to working only for the current boundary;
record extra reads and close every issued receipt. No subagents or external model
calls. Retain the existing branch and single port-8000 server; no merge or deploy.

Verification notation below:

- F (focused): specified deterministic tests and `git diff --check`.
- S (standard): F plus `npm run typecheck` and Theseus workspace validation.
- B (broad): S plus affected integration/architecture/production checks. Full
  suite and supported-browser matrix are release gates, not every spike.
- V: one canonical Chromium runtime smoke/contact sheet through a committed
  scope-specific command; human judgment remains separate.

Proposed stable commands, to be created in the named slices, are
`npm run test:common-factor-authoring` (s03),
`npm run visual:common-factor-authoring` (s12),
`npm run visual:common-factor-authoring:cohort` (s22), and
`npm run check:common-factor-workflow` (s21). They are not available checks yet.
Use existing impact selection and reuse repo-owned browser entrypoints. Screenshots
are disposable; commands and tests own durable evidence.

For every row, commit boundary C means one scoped commit after its specified
proof passes; G means stop only for lost semantic/safety authority, a required
proof unavailable within scope, material scope expansion, user pause, or the
explicit visual checkpoint. Repairable in-scope test failures are repaired, not
waived or treated as approval requests. All costs retain complete consumers and
negative type tests; measured TypeScript cost repairs follow standing automatic
approval with explicit amendments where needed. No other budget waivers.

## Human checkpoints and promotion

Only initial approval and s15 are planned user decisions. Continue automatically
through routine nonvisual work and after s15 acceptance. Batch all subjective
views into that one packet. A later materially new visual mechanism requires a
new judgment, but unchanged visuals do not need reapproval.

Before s15, prove durable semantics, lifecycle, deterministic sampling, native
endpoints and accessibility, with one cheap actual compositor canary. Do not build
a dense aesthetic certification suite before the user selects the exemplar.
After acceptance, add regressions, pressure the numeric caller and run the
supported-browser cohort. Promotion is limited to the demonstrated common-factor
task and executed mechanism signatures, not all substitution/collection/factoring.

## Explicit deferrals and stop conditions

No general polynomial factoring, reordering/commutativity solver, arbitrary
multi-letter/function inference, nonlinear solving, cancellation/division,
trigonometry/calculus/linear-algebra expansion, universal semantic schema or CAS.
No global renderer/clock/salience changes, new motif grammar, catalog-wide API
migration, external LLM calls, account/SRS features, public publishing, physical
device certification claims, comprehension study claims, Theseus package repair,
subagents, merge or automatic next loop. The waiting Lisp tranche is not resumed.

If bounded factoring cannot traverse the existing mechanism or equation
publication owner without one of those expansions, record the exact repair gap
and propose an amendment. Do not substitute a generic fade, reverse an unrelated
animation, infer proof from a declaration or silently ship a static-only task.
