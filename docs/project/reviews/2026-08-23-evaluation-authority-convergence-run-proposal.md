# Evaluation Authority Convergence Run Proposal

Status: approved 2026-08-23
Target: `workflow.kp.delivery`

## Objective

Make compiler-owned evaluation presentation authority survive unchanged from
verified operation semantics through the generic equation host and Native
KaTeX paint. The canonical checkpoint is the embedded `3 - 1 -> 2` transition
in `animation.generated.calculus.derivative.power-rule-x-cubed` using the
existing ink-knot contributor-fusion realization.

## Canonical Boundary

- Artifact: `animation.generated.calculus.derivative.power-rule-x-cubed`
- Host: generic Catalogue equation surface
- Renderer: Native KaTeX
- Semantic source: the compiled governance-v2 subtraction transition and its
  verified selector correspondence
- Acceptance: one compiler-minted evaluation-family certificate reaches the
  renderer; `3 - 1 -> 2` uses actual ink-knot paint; incompatible or
  unsupported selections fail with a typed repair gap; runtime code cannot
  reselect a family from a transform kind or asset id
- Preservation: the first derivative-power beat, semantic endpoints, shared
  clock, existing product/quotient/sum and carrier-preserving callers, and
  unrelated worktree changes
- Rollback: one focused commit per verified slice
- Promotion: stop after the derivative contact sheet. A structurally different
  subtraction caller and catalogue-wide promotion remain separate decisions.

## Allowed Work

- Evaluation authority and family-profile types, registries, validation, and
  presentation-plan propagation
- Generic equation and shared Native KaTeX contributor-fusion integration
- Derivative decrement presentation and salience composition
- Focused semantic, architecture, browser, and visual evidence
- Generated inventories only when their owning generators require refresh

## Disallowed Work

- Ink-knot timing, geometry, opacity, or optical-profile retuning
- A second subtraction caller or catalogue-wide subtraction promotion
- Changes to the first derivative-power transition
- Unrelated animation, lesson, product-layout, economics, or documentation work
- Caller-authored family, renderer, keyframe, timing, or geometry authority

## Stop Conditions

Stop when any slice requires a new visual motif, caller-specific Native KaTeX
offset, duplicated paint owner, public authoring compatibility break, change
to an already promoted evaluation caller, unexplained preservation failure,
or work outside the allowed boundary. Always stop at the final human visual
checkpoint before a second caller or broader promotion.

## Approved Scope Amendment — 2026-08-23

Slice s18 exposed that the already-promoted standalone operation-evaluation
host rejects its static canonical carrier scene before the certified
contributor-fusion renderer can establish executable motion. It also still
reselects the family from the transformation kind at runtime. The user
approved one narrow exception to the promoted-caller stop condition: repair
that lifecycle and authority boundary so direct arithmetic receives a
compiler-minted family certificate and the certified family renderer supplies
the motion evidence required for readiness. Preserve the caller's semantic
endpoints, existing ink-knot optical profile, timing, geometry, and intended
visual result. This amendment does not authorize subtraction promotion, a
second subtraction caller, or any motif retuning.
