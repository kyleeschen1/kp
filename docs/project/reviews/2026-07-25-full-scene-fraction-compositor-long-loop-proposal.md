# Full-scene fraction compositor long-loop proposal

Date: 2026-07-25

Status: approved

Theseus target: `workflow.kp.delivery`

## Objective

Replace the focal-fragment-only KaTeX experiment with one total,
semantic-lineage-constrained rendered-notation scene compositor, proven on:

`\frac{x}{2}+\frac{y}{2}\longrightarrow\frac{x+y}{2}`.

The first slice adds local play and timeline controls to every experiment card
so later visual review does not depend on the controls at the top of the page.
The loop then inventories every painted fragment, reconciles every source and
target fragment, gives one inert material scene exclusive visual ownership
during transit, and hands the complete scene to exact native target notation.

## Why this loop is current

The completed real-KaTeX experiment proved exact focal-fragment observation,
semantic-lineage binding, inert cloning, and native settlement. It did not
animate whole expressions. Fraction, branch, and crowded cases reveal complete
target subtrees while only focal glyphs move, and the crowded case explicitly
uses checkpoint settlement. More scheduler tuning cannot fix missing scene
coverage.

The immediate dependency is therefore a total rendered-scene model. Geometry
scheduling follows only after every painted source and target fragment has an
explicit lifecycle.

## Canonical reference and acceptance

The canonical reference is the existing native KaTeX fraction source and
target on `/glyph-reconciliation-experiment.html`.

Observable acceptance requires:

1. Every card has a local play button and timeline slider synchronized to the
   shared deterministic progress.
2. Every painted source and target fragment has one explicit persistent,
   transform, merge, split, introduction, elimination, or unsupported
   disposition.
3. At `t=0`, exact native source notation owns all visible ink.
4. For every `0<t<1`, one inert material scene owns all visible equation ink;
   complete native endpoint trees do not leak through.
5. Persistent `x` and `y`, both denominator `2` fragments, both fraction rules,
   the plus sign, and structural spacing move or depart continuously.
6. No whole subtree appears, disappears, or jumps at animation start.
7. The complete material scene coincides with the native target before one
   atomic handoff, within the existing one-CSS-pixel tolerance and without a
   size, weight, or baseline flash.
8. Direct seek, rewind, wide, phone, reduced motion, Cloze, hover, annotation,
   accessibility, and static-JS execution retain their existing contracts.
9. The implementation adds no fraction-specific matcher or scheduler and
   replaces case-shaped compositor APIs rather than accumulating another path.
10. Human review approves the normal-speed wide and phone exemplar before
    branching, radicals, compound traces, or production-family rollout.

## Preservation boundary

- Preserve canonical semantic source and target trees, operation lineage,
  multiplicity, provenance, selectors, clocks, and reverse laws.
- Preserve native KaTeX as settled visual and semantic authority.
- Preserve cards/Cloze, branching data, accessibility, hover, annotations,
  review inbox, static-JS execution, and optional headless compilation.
- Keep measured fragments, DOM handles, geometry, tracks, and renderer plans
  ephemeral and absent from durable animation artifacts.
- Preserve the existing solve-x, branch, crowded, reader, and production
  behavior outside the isolated experiment route.
- Preserve unrelated user-authored roadmap, thread, decision, and design files
  already present in the dirty worktree.

## Rollback unit

Each slice is one focused commit. The complete compositor experiment can be
removed by reverting the isolated fraction route integration and generic
renderer-session modules without changing canonical semantic assets or
production readers.

## Allowed work

- Local play/timeline controls for each experiment card.
- Ephemeral rendered-scene and paint-atom observation contracts.
- Semantic ownership projection from canonical renderer annotations.
- One lineage-constrained total reconciler and one hierarchical scene plan.
- Generic glyph, rule, group, merge, introduction, and elimination tracks.
- One deterministic JS scene sampler and existing headless-plan compatibility.
- Exclusive active-scene ownership and exact atomic native settlement.
- Integration of only the canonical fraction merge exemplar.
- Stable focused browser/visual tooling, wide/phone evidence, performance
  measurement, architecture ratchets, project-memory closeout, and Theseus
  evidence.

## Disallowed work

- Fraction-, quadratic-, branch-, radical-, viewport-, or operation-specific
  matching and scheduling.
- Branch, crowded radical, compound trace, text/code, or production-family
  compositor rollout before the human checkpoint.
- Durable glyph geometry, keyframes, DOM state, backend plans, or a second
  semantic animation artifact.
- Accessibility or interaction authority on moving visual clones.
- Full Manim export, Python runtime, video encoding, CAS, live LLM APIs,
  dynamic packages, curriculum expansion, or unrelated visual redesign.
- Repair of the separate radical native-handoff residual.

## Verification cadence

- Inspect `npm run verify:impact -- --path <changed-path>` before using its run
  mode.
- Use focused pure tests for contracts, reconciliation, hierarchy, and tracks.
- Add typecheck and `theseus workspace validate` at standard boundaries.
- Reuse and extend the committed
  `npm run visual:glyph-reconciliation-experiment` entrypoint.
- Use real Chromium checks for paint observation, ownership, continuity,
  accessibility, controls, and exact native settlement.
- Run production build, closures, performance, review-log audit, broad impacted
  tests, stable captures, and workspace validation at slice 20.

## Hard stop conditions

1. Any required operation-, fraction-, radical-, branch-, or viewport-specific
   matcher, lifecycle, or scheduler.
2. Painted atoms cannot be enumerated without scattered brittle KaTeX
   heuristics.
3. Visual equality must establish semantic lineage.
4. Any painted source or target atom remains implicit or unassigned.
5. DOM nodes, measurements, tracks, keyframes, or backend plans enter durable
   animation artifacts.
6. Moving clones become accessibility, hover, focus, annotation, or Cloze
   authority.
7. Full-scene handoff retains a visible size, weight, baseline, or position
   jump after one bounded common correction.
8. Performance or payload budgets require case-specific optimization or
   relaxed product checks.
9. Existing solve-x, branch, crowded, reader, production, review, static-JS,
   semantic, seek, or rewind behavior regresses.
10. Work enters radicals, branching rollout, compound symbolic traces,
    text/code, production families, CAS, Manim, live LLMs, or unrelated scope.
11. Work cannot be separated from unrelated user-authored dirty-worktree
    changes.
12. A required verification gate fails without one bounded common correction.

## Done contract

The approved loop ends at the slice-20 human checkpoint. It is complete only
when every slice has a terminal state, every canonical fraction source and
target paint atom is explicitly reconciled, one inert scene owns all transit
ink, exact native settlement and semantic affordances are preserved, the
implementation remains complexity-negative and operation-neutral, release
evidence is committed, and the user can review the exemplar using controls on
its own card.

- Radical WebGL/native-handoff repair.
