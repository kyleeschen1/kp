# Semantic visual salience theme long-loop proposal

Status: approved by the user on 2026-08-05

## Objective

Turn the visual language in `docs/kinetic_press_visual_salience_handoff.md`
into a small semantic theme and salience system. Perfect that system on the
economics demand-shift tutorial, stop for human visual review, and only then
pressure-test the approved boundary on a structurally different multi-step
fraction-composition algebra caller.

New Computer Modern Mono Book is a completed preflight choice in commit
`df11107a`. It is the default non-KaTeX face; KaTeX retains its native fonts
and metrics.

## Canonical exemplar and acceptance

The canonical exemplar is the economics demand-shift tutorial in its accepted
two-column layout. The canonical visual reference is the handoff document.

Observable acceptance criteria:

- dark mode retains `#0d0e1c` and light mode retains `#f4f1e9` as their page
  backgrounds;
- existing greys, reds, and blues move to their closest handoff-palette
  equivalents without adding an unrelated palette family;
- semantic roles select a bounded state vocabulary, while theme adapters own
  concrete color, opacity, stroke, fill, and text recipes;
- foreground, context, focus, ghost, entering, and withdrawing treatments are
  coherent across prose, KaTeX companions, SVG graph paint, controls, and
  review surfaces without overriding KaTeX internals;
- focus remains legible in dark and light themes, on wide and phone layouts,
  in reduced motion, and in forced/high contrast fallbacks;
- direct seek, rewind, semantic object identity, graph truth, and scroll
  ownership remain unchanged;
- the approved economics motif can serve fraction-composition algebra without
  importing economics semantics or duplicating the theme system.

## Preservation boundary

Preserve economics mathematics, graph geometry, animation timing, scroll
scrubbing, route and URL semantics, lesson prose, review capture, layout
tuners, progressive static output, and renderer ownership. Preserve the
framework-neutral animation and semantic models. Lisp is explicitly outside
this run because its visual language is not ready to become a second caller.

The 24 known broad-suite failures in the catalogue and governance cohort are
baseline debt outside this run. Focused economics checks, typography checks,
typecheck, and production build were green at issuance. The run must not grow
the broad failure count or touch the unrelated failing ownership files.

## Rollback unit

Each slice is one independently reversible commit. Economics palette and state
application remain behind exemplar-local adapters until the mandatory review.
Shared promotion is its own post-approval slice, so rejecting the treatment
does not require undoing semantic models, graph infrastructure, or the
typography preflight.

## Stop conditions

- Stop at `HUMAN_CHECKPOINT` after s19. Slices s20-s28 require fresh approval
  of the economics exemplar, even though the overall contract was approved.
- Stop if the treatment requires changing mathematics, graph geometry, lesson
  prose, scroll ownership, native KaTeX metrics, or animation timing.
- Stop if a second palette or caller-specific recipe matrix is required rather
  than extending a semantic role.
- Stop if economics state cannot be reconstructed directly from semantic state
  or if forward and rewind differ.
- Stop if a required focused verification cannot be repaired inside the
  current slice and rollback boundary.
- Stop if unrelated dirty worktree files or the known catalogue baseline would
  need to be changed.
