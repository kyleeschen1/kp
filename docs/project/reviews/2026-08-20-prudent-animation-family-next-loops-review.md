## Context

Equation convergence has produced a canonical compiler, approved homomorphic
decomposition, balanced operations, ink-knot contributor fusion,
carrier-preserving identity simplification, Native KaTeX mechanism
conformance, and bounded mixed-family generation. Continuing to polish every
older equation caller now has lower marginal value than proving that KP can
add new families without recreating infrastructure.

The desired pace is neither catalogue-wide expansion nor one more indefinite
consolidation phase. Alternate one visual exemplar with one pressure/promotion
loop, then change families.

## Recommended Six Loops

### Loop 1 — Graph2D translation exemplar

Build one horizontal translation of a parabola, synchronized with its symbolic
parameter change. Add only semantic truth, deterministic sampling, one local
Graph2D recipe, a catalogue URL, and cheap preservation checks. Stop for visual
review before extracting a general family.

### Loop 2 — Graph2D pressure and narrow promotion

After approval, translate a structurally different curve such as sine. Extract
the domain-owned horizontal-translation operation and shared recipe; verify
direct seek, reverse, theme, accessibility, and supported browsers; expose the
operation through capability discovery. Do not silently include reflection,
stretch, or discontinuous-domain handling.

### Loop 3 — TypeScript code-wrap exemplar

Animate a stable expression becoming the argument of a new function call. The
TypeScript frontend owns syntax and legality, while the existing code renderer
owns measured token motion. Stop for visual review before making the operation
language-neutral.

### Loop 4 — Python pressure and code-family promotion

Apply the same semantic wrapping intent through Python. Extract only stable
expression lineage, introduced wrapper roles, request/host sequencing, and
deterministic playback. Keep parsing, binding, concrete syntax, highlighting,
and renderer optics language-owned. Register the two supported frontends and
return typed gaps for unsupported languages.

### Loop 5 — Power/root branching exemplar

Build one real-domain `x² = 9 → x = ±3` animation with explicit branch
identity, domain evidence, native endpoints, and a single attentional decision.
Stop for review; do not generalize to arbitrary radicals, complex roots, or
extraneous-solution checking yet.

### Loop 6 — Root inversion pressure and narrow promotion

Pressure the candidate with an odd-power or inverse-direction caller. Extract
only the branch/domain semantics and presentation boundary both callers prove,
then register governed natural-language and ordered-LaTeX discovery. Unsupported
domains and branch structures must remain typed gaps.

## Cadence After These Six

Re-rank geometric dissection, matrix-vector composition, and the
difference-quotient/tangent bridge. Matrix becomes prudent when a bounded
domain frontend and corpus can be proposed without reviving the unapproved
Pour choreography or making linear algebra the project center.
