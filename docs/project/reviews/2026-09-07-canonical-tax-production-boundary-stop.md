within existing infrastructure. It also preserves sibling owners and defers
broader publication work. Shipping this page now entails production ownership
promotion of its complete four-card dependency set and a build/runtime Article
boundary, not merely injecting the already-approved tax source. Routine failing
tests remain preapproved for repair; this stop does not revoke that standing rule.
It identifies the additional cross-card publication scope before changing it.

exact four-card page. Inventory the full runtime and type-only closure; move only
demonstrated shared implementations into existing production ownership zones;
keep experiment entrypoints as callers rather than production dependencies;

delivery, preview convergence, release and G3 gates. Do not introduce a public
API family, catalogue rollout, renderer, clock, deployment or general publisher.
