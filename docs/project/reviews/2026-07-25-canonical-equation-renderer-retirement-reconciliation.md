## Canonical migration rule

Future migrations are per exemplar and per transition:

1. compile the existing semantic trace and renderer-neutral plans;
2. prove the canonical session preserves the transition's behavior and native
   semantic authority;
3. pass a visual checkpoint;
4. remove or bypass that transition's compatibility paint in the same rollback
   unit;
5. leave other transitions untouched until their own proof.

This rule gives KP one canonical destination without pretending that
unmigrated catalog coverage has already moved.
