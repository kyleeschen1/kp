# Symbolic Materiality Log-Homomorphism Long-Loop Proposal

Date: 2026-08-22
Status: approved 2026-08-22
Target: `workflow.kp.delivery`

## Objective

Produce a reviewable inline-scale material-depth variant of
`ln(xy) -> ln(x) + ln(y)` that makes symbolic causality feel physical without
changing the accepted log-product semantics.

Kinetic Press should develop a visual signature of **symbolic materiality**:
flat, searchable semantic glyphs governed by consistent physical laws. Symbols
remain still while inspected and become physical while acting. The experiment
tests conservation of symbolic material, semantic gravity toward the native
baseline, causal contact, subtree rigidity, operation-specific topology, and
exact calm settlement.

This is an exemplar-local discovery pass. It records a vision and tests one
renderer treatment; it does not promote a universal style or type family.

## Canonical reference and acceptance

- Canonical exemplar: `animation.algebra.log-product.product-to-sum`.
- Canonical behavior: the approved flat Native KaTeX log-product animation.
- Experimental selector: existing `focus=elevated` development mode.
- Comparators: `focus=flat` and `focus=no-depth`.
- Typography: local inline-scale KaTeX experiment with generous stage space.

The learner should experience one causal chain:

```text
native rest
-> cohesive source-shell activation
-> operator penetration without false glyph persistence
-> direct factor release
-> target enclosure reception through canonical function wrapping
-> generated target syntax resolution
-> exact native settlement
```

The experiment passes only when the material version is more intelligible,
not merely more impressive. Persistent factors must remain effortless to
follow; generated target logarithm applications must not look like copied
source identities; one event must dominate attention at a time; inline glyphs
must remain crisp; and terminal ownership must have no snap.

## Preservation boundary

Preserve the semantic law, occurrence identities, correspondence map, native
endpoint ownership, catalogue identity, deterministic clock, existing flat
presentation, direct seek, rewind, interruption, reduced motion, accessibility
truth, and canonical function-wrap reception.

The rollback unit is the decision record, local material-depth presentation
plan/projector, local CSS treatment, and associated log-product evidence.

## Allowed work

- Record the symbolic-materiality experiment and its physical laws.
- Add an exemplar-local pure depth presentation plan and role bindings.
- Add local inline-scale styling and material treatment.
- Use existing semantic phases, material owners, focus modes, and Native KaTeX
  endpoints.
- Extend focused log-product tests and the stable visual capture command.
- Add one narrowly optional, inert-by-default renderer presentation field only
  if the existing material-frame contract cannot express the treatment.

## Disallowed work

- No semantic-law, identity, correspondence, endpoint, or clock changes.
- No replacement of the approved flat animation.
- No universal 2.5D renderer, published global style, or catalogue rollout.
- No factoring, quotient, three-factor, Lisp, graph, public-site, or layout
  expansion.
- No WebGL glyphs or broad bundle/runtime refactor.
- No promotion before the required human checkpoint.

## Verification and cadence

- Focused inner loop: pure tests, `npm run test:log-product`, and impact-selected
  checks.
- Visual discovery: extend and reuse `npm run visual:log-product`; do not create
  an ad hoc browser authority.
- Standard boundaries: project typecheck and `theseus workspace validate`.
- Final checkpoint: log-product tests, focused Chromium evidence, contact
  sheet, impact-selected checks, typecheck, and workspace validation.
- Commit after each verified slice, staging exact paths only.

## Stop conditions

Stop if the experiment changes accepted semantics or flat behavior; requires
a new clock, semantic operation, or broad generic renderer; cannot preserve
exact native endpoints; creates false source-to-successor identity; introduces
per-frame layout reads or unacceptable paint cost; overlaps unrelated user
changes; or reaches the required human visual checkpoint.

## Explicit deferrals

Factoring pressure, quotient pressure, three-factor pressure, shared material
semantics, published gestalt styles, cross-renderer promotion, real 3D text,
reader layout, public delivery, curriculum, and LLM authoring remain deferred.
