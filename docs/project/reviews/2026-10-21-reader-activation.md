Scope: the approved [bounded investigation](../2026-10-21-reader-activation-investigation.md).
Existing canonical tax source, SVG host and three deferred companions are the

## Diagnosis

`npm run build:bundle -- --sourcemap` followed by `npm run
audit:architecture-cost -- --browser --tax-only --activation --tax-profile`
separately attributes startup, the first tax transition, and each deferred card.
Profiles are instrumented evidence, not ordinary latency measurements. Generated
helpers without maps retain explicit unmapped labels; inclusive samples overlap.

Three 6x startup profiles attribute 317–322 ms inclusive to swept camera fitting
for the surface-contour companion, before its interactive capability activates.
The fit projects thousands of points and recomputes the unchanged camera basis
for every point. Complete warm Node authority preparations measure medians
42.42 / 47.19 / 15.44 ms for fields (1,2), (.25,4), (4,.25), respectively.
`npm run measure:camera-fit` reports exact fitted-plan digests for preservation.

Startup also forces layout while setting the initial native scroll position.
The first-transition profile includes 198–219 ms inclusive in logarithm native
preparation; that work is not wholly tax-animation work. Later activation windows
can include a previously started companion transition, so their whole-window
CPU must not be attributed solely to the newly activated card. Preserve the
current visibility/interaction policy in this pass.

The audit initially failed before browser execution because enumerating all
tracked repository paths exceeded the subprocess buffer. It now enumerates
only the four roots already selected by the old filter; an actual Git parity
test guards complete membership. The next attempt encountered a generated helper
without a map; explicit unmapped accounting repairs that tool assumption.
Both errors are investigation-tool failures, not reader regressions. Three
profiling/inventory tests and Node typechecking pass.
