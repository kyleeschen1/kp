Where Should Token Identity Come From?

Semantic token motion needs stable IDs before WebGL can interpolate positions.

Example: same symbol, different visual position
x2 + 2x + 1
source tokens: x#a, x#b
->
(x + 1)(x + 1)
target tokens: x#a, x#b
A

Generated From Math AST

The semantic expression tree owns IDs. Rendering emits token metadata, and transitions match by semantic path. Good default; strongest contract for authored KP math.

B

Explicit Author IDs

Authors tag tokens or subexpressions directly. Maximum control for lessons, but heavier authoring burden and easier to make inconsistent.

C

Hybrid: AST IDs + Overrides

Auto-generate stable IDs from the semantic tree, then allow explicit aliases for pedagogical matches. More code, but likely the right long-term model.

My recommendation

Use the hybrid model, but build V1 with generated AST IDs first. Add author overrides only after the measurement and WebGL overlay path works.
