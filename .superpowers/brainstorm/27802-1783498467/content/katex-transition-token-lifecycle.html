Token Lifecycle During a Transition

Semantic matches move. Unmatched source/target tokens need a predictable default behavior.

Example transition
x2 + 2x + 1
matched: x tokens; removed or regrouped: plus/operator structure
->
(x + 1)(x + 1)
matched tokens land at target boxes; new structure appears around them
A

Move Matches, Crossfade Unmatched

Matched tokens interpolate position/scale/opacity. Source-only tokens fade out in place; target-only tokens fade in at target positions. Best default for clarity and implementation scope.

B

Attach Unmatched To Nearest Semantic Anchor

New or removed structure grows out of nearby matched tokens. More expressive, but requires extra graph relationships and more edge-case design.

C

Morph Everything

Every source visual gets paired with some target visual. Can look magical, but false matches can make math meaning harder to follow.

Recommendation

Use option A as the V1 rule. Add anchor-based entrances later where authored lessons need stronger storytelling.
